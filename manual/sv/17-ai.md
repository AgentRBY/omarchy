# AI

Omarchy behandlar AI-kodningsagenter som förstklassiga medborgare, men den väljer ingen favorit åt dig. I stället kommer varje större kodningsagent-CLI förkopplad som en lazy-laddad startare. Startarna är små [mise](https://mise.jdx.dev/)-hanterade stubbar i `~/.local/bin/`, så ingenting laddas ner förrän första gången du faktiskt kör en. Hermes är undantaget: ingenting stubbas för den, och att välja den installerar Hermes Desktop, som _Skrivbordsappar_ nedan förklarar. Anropa någon av dessa och autentisera när du uppmanas:

| Command    | Agent                                                            |
|------------|------------------------------------------------------------------|
| `claude`   | [Claude Code](https://code.claude.com/docs/en/overview)          |
| `codex`    | [OpenAI Codex](https://github.com/openai/codex)                  |
| `opencode` | [OpenCode](https://opencode.ai/)                                 |
| `agy`      | [Google Antigravity CLI](https://github.com/google-antigravity/antigravity-cli) |
| `copilot`  | [GitHub Copilot CLI](https://github.com/github/copilot-cli)      |
| `crush`    | [Crush](https://github.com/charmbracelet/crush)                  |
| `grok`     | [Grok Build](https://x.ai/build) from xAI                        |
| `pi`       | [Mario Zechner's Pi](https://github.com/badlogic/pi-mono)        |
| `omp`      | [Oh My Pi](https://github.com/can1357/oh-my-pi)                  |
| `ori`      | [Ori](https://openrouter.ai/docs/guides/ori/harness), OpenRouter's harness |
| `hermes`   | [Hermes](https://hermes-agent.nousresearch.com/), Nous Research's agent  |
| `muse`     | [Muse Code](https://dev.meta.ai), Meta's coding agent           |
| `cursor-agent` | [Cursor CLI](https://cursor.com/cli)                         |

`ori` är den udda: den kör de andra harnesserna mot OpenRouters hela modellkatalog, så `ori claude`, `ori codex` eller `ori opencode` startar dessa agenter på vilken modell du än pekar dem på, och `ori code` är Oris egen agent.

För att wrappa en ytterligare CLI på samma sätt, kör `omarchy-mise-install <package> [command-name]`. Stubbarna hålls aktuella tillsammans med allt annat mise hanterar när du kör `omarchy update` (eller aliaset `mup`).

`grok` installeras via mises förstaparts `grok`-paket, på samma sätt som `claude` och `codex`. Kör `grok`, eller välj den under _Setup > Defaults > Agent_. Hoppa över `curl | bash`-installatören på x.ai. Den vägen lägger en andra kopia i `~/.grok/bin`, lägger den först på `PATH` och skriver över Omarchys wrapper.

### Standardagenten

Välj din standardagent med `omarchy default agent <name>` eller under _Setup > Defaults > Agent_ i Omarchy-menyn (`Super + Space`). Om agenten inte är installerad ännu installeras den först när du väljer den. En färsk Omarchy bjuder in dig att göra det valet med en engångsavisering.

Att välja Claude försöker också konfigurera dess webbläsartillägg för Chromium, Chrome, Brave, Brave Origin och Edge. Tilläggskonfigurationen gäller alla användare och kan be om ditt systemlösenord; att avbryta eller en misslyckad tilläggsinstallation väljer och startar ändå Claude. Starta om din webbläsare, aktivera tillägget om du uppmanas och logga in på Claude för att slutföra anslutningen. Kör `/chrome` i Claude för att kontrollera anslutningen. Firefox och Zen stöder inte det här tillägget. Om Claude redan var din standard innan denna konfiguration lades till, välj den igen för att installera tillägget.

[Muse Code](https://dev.meta.ai) — Metas `muse` — använder en förinstallerad mise-stubb som de andra agenterna. Att välja den som standard installerar Metas officiella startare via mises HTTP-backend. Startaren verifierar och uppdaterar den inbyggda binären för din maskin.

När du väl har valt startar `Super + Shift + Ctrl + A` standardagenten i ett dedikerat terminalfönster (eller tar upp väljaren om du inte har valt ännu). Du kan också starta den rakt in i en uppgift med `omarchy agent prompt "Review this project"`. Agenter som startas så här körs obevakade i deras respektive fråga-inte-lägen, så var redo för att de faktiskt gör saker! Och eftersom agenter vägrar att komma ihåg förtroende för din hemkatalog startar startar från `$HOME` i `~/Work` i stället.

Det finns också terminalgenvägar: `a` kör standardagenten inline i den aktuella terminalen, medan `c`, `cx` och `cy` startar OpenCode, Claude Code och Codex direkt (återigen i deras autogadkännande lägen). Temaförändringar synkroniseras också till agenterna: Claude Code, Pi, OpenCode och Hermes (när Omarchy väl har installerat den) följer alla med när du byter Omarchy-tema.

### Agentpanelen

Menyfältet har en agentikon. Innan du har konfigurerat en agent guidar dess panel dig genom att logga in på Claude, Codex eller Grok, och den första blir din standardagent. Efter det sätter panelen varje prenumeration på en sida: varje agent och konto med sin plan, en mätare för var och en av dess 5-timmars sessions- och veckogränser med tiden till återställning (hovra för exakt procent), eller det återstående förbetalda saldot, under en rad som roterar genom vad du har använt över alla dem, som tokens den här veckan och din mest använda modell. Under _Make something_ erbjuder den startprompts för ett nytt tema, plugin eller app som överlämnar uppgiften till din standardagent. Appar byggs så som Omarchys egna Hype, Monologue och Omacut är, i C++ och Qt Quick, efter omarchy-app-agentskillen, och kompilatorn och Qt-bitarna de behöver kommer installerade. Claude Code, Codex, Grok och Fireworks täcks direkt ur lådan.

Vänsterklicka på fältikonen för panelen, högerklicka för att starta din standardagent. Användningsregisterna bakom den regenereras var 15:e minut av `omarchy agent usage-update`, och panelen kan till och med slå samman användning från dina andra maskiner via en synkad mapp. Se README under `$OMARCHY_PATH/shell/plugins/agents/` för de fullständiga inställningarna.

### Flera prenumerationer

Om du betalar för mer än en Claude-, Codex- eller Grok-plan — en personlig Max och en på jobbet, till exempel — kan Omarchy hålla dem alla inloggade och flytta mellan dem. Lägg till en prenumeration med + i agentpanelen, som guidar dig igenom det precis där, eller med `omarchy agent account add claude Work` (eller `codex`, eller `grok`). Den installerar CLI:t om det saknas. Det första kontot för en leverantör loggar in via din vanliga webbläsare, precis där CLI:t alltid tittar. Varje konto efter det loggar in via ett privat fönster, så att kontot din webbläsare redan är inloggad på inte plockas upp av misstag; logga in där som kontot du lägger till, och stäng först alla privata fönster du redan hade öppna. Logga aldrig ut från CLI:t för att göra detta: att logga ut återkallar den sparade inloggningen, och det kontot skulle behöva läggas till igen.

Ett konto per leverantör är aktivt, och varje ny session startar som det: `cx`, `cy`, en enkel `claude`, `codex` eller `grok`, allt som startas via `omarchy agent`, och skript eller redigerare som hittar CLI:t på `PATH`. Växla med `omarchy agent account use work` (och tillbaka med `omarchy agent account use main`), eller i panelen genom att trycka på ett kontos nummer och sedan `Enter` (eller klicka på dess Använd-knapp). Sessioner som redan körs stannar på kontot de startade med. Konversationshistorik, inställningar, skills och plugins delas över kontona, så `claude --continue` i samma mapp plockar upp där du lämnade på det nya kontot.

Med mer än ett konto visar panelen varje kontos gränser sida vid sida, med det aktiva markerat. Som standard aviserar Omarchy dig när det aktiva kontot passerar 95 % av en gräns, och att klicka på aviseringen växlar till kontot med mest utrymme. Hovra ett kontos rad i panelen och klicka på Autoswitch som visas bredvid Använd (eller tryck på `m`), eller kör `omarchy agent account mode auto`, för att låta det växla på egen hand i stället; medan det är på tar Autoswitch Används plats, och att klicka på den igen går tillbaka till att avisera. Lägg till ett nummer för att ändra tröskeln, som i `omarchy agent account mode auto 90`. Om varje konto är över tröskeln hör du om det en gång, tillsammans med vilket konto som frigörs först. Medan ett aktivt konto är inom 15 poäng från sin tröskel (80 % som standard) kontrolleras dess gränser var tredje minut snarare än var 15:e.

`omarchy agent account list` visar varje konto och dess senaste gränser, `omarchy agent account remove work` glömmer ett, och `omarchy agent account rename primary Hey` byter namn på ett (eller klicka på ett kontos namn i panelen). Dessa kommandon arbetar på din standardagents konton; för att nå den andra leverantören, namnge den först, som i `omarchy agent account use codex side`. Inloggningen du redan hade i `~/.claude` eller `~/.codex` är _Main_-kontot och stannar där den är. Ett konto som lämnats oanvänt i mer än ungefär åtta timmar kan visa _Sign-in required_; klicka på det för att logga in det kontot igen direkt i panelen, eller starta en session i det, vilket uppdaterar inloggningen på egen hand. MCP-servrar du hade när ett konto lades till följer med till det, men sådana du lägger till senare med `claude mcp add` når bara kontot du lade till dem i. Claude Desktop och verktyg konfigurerade med en absolut sökväg till en CLI-binär följer inte växlingen. En explicit `CLAUDE_CONFIG_DIR`, `CODEX_HOME` eller `GROK_HOME` har företräde framför det valda kontot.

### Kraschdiagnos

Omarchy bevakar systemd-coredump för processkrascher. När något segfaultar får du en "Process crashed"-avisering — klicka på den så överlämnas kraschen till din standardagent tillsammans med Omarchys diagnose-crash-skill, som guidar agenten genom att fastställa fakta från core-dumpen och besluta om kraschen är värd att rapportera uppströms. Du kan också köra den för hand mot valfri PID från `coredumpctl list` med `omarchy agent crash <pid>`.

Bevakningen är på som standard. Stäng av den under _Trigger > Toggle > Crash Capture_ (eller med `omarchy toggle crash-capture`) så slutar aviseringarna; `omarchy agent crash <pid>` fungerar fortfarande för hand.

Krascher kan också tystas ett program i taget, vilket är vad diagnosen erbjuder dig i slutet. `omarchy crash mute hyprland` stoppar aviseringarna för bara det programmet, `omarchy crash mute hyprland off` tar tillbaka dem, och `omarchy crash mute` på egen hand listar vad du har tystat. Den tar binärens sökväg lika gärna som dess namn, så `omarchy crash mute /usr/bin/hyprland` gör samma sak. Citera ett namn med ett mellanslag i det, som i `omarchy crash mute 'Some App'`. Allting annat aviserar fortfarande, och det tystade programmet kraschar fortfarande — detta döljer påminnelsen, det fixar ingenting.

### Skrivbordsappar

Menyn _Install > AI_ innehåller också några grafiska AI-appar: ChatGPT-skrivbordsappen, Claude-skrivbordsappen (Anthropics Linux-beta, med flikarna Chat, Cowork och Claude Code), Grok Bot för att chatta med xAI:s modeller, Hermes Desktop, OpenClaw och Perplexity-skrivbordsappen. Grok Bot är skrivbords-chattappen. Kodningsagenten är kommandot `grok`.

Hermes Desktop är den att känna till, eftersom en maskin har en Hermes, och det är appens: Hermes installeras bara någonsin via appen, och kommandot `hermes` som standardagenten kör är appens. Att välja Hermes som standardagent installerar samma sak som posten _Install > AI_ gör: paketet och en Hermes-runtime under `~/.hermes` konfigurerad av Hermes egen installatör, vilket tar några minuter första gången. Den runtime:n är den enda Hermes som terminalkommandot `hermes`, standardagenten och appen alla använder, och den uppdaterar sig själv med `hermes update` snarare än att vänta på en Omarchy-release. Att installera den ger också Hermes Omarchy-temat som ett skin med namnet `omarchy`, som varje Hermes-yta följer när du byter teman; välj ett annat under Hermes Appearance-inställningar eller med `/skin` om du hellre vill att den inte ska det, så lämnar Omarchy det valet i fred. Att ta bort appen under _Remove > AI_ stänger Hermes först, gateway inkluderad, tar den runtime:n med sig och behåller dina chattar, minnen och skills Hermes skrev för sig själv om du inte säger annat: den frågar, med nej som standard, om de datan och dina anslutningsinställningar ska följa med också.

OpenClaws skrivbordsupplevelse är dess Control UI, som öppnas som en webbapp backad av sin egen lokala gateway. OpenClaw bor i `~/.openclaw` och uppdaterar sig själv: använd Control UI:s "Update Gateway"-knapp eller kör `openclaw update`, så startar gatewayen om på den nya versionen. Omarchy väljer bara vilken release en färsk installation börjar från. Att ta bort OpenClaw under _Remove > AI_ tar gateway-tjänsten och appen med sig och frågar sedan om `~/.openclaw` ska följa med också, eftersom den innehåller dina chattar och inloggningsuppgifter tillsammans med OpenClaw själv och de plugin-runtimes den laddar ner; standard behåller den, och att installera OpenClaw igen plockar upp den igen.

### Lokala LLM:er

Omarchy rekommenderar två sätt att köra lokala LLM-modeller: LM Studio och Ollama. LM Studio tillhandahåller ett GUI-gränssnitt för att hitta modeller med öppna vikter, installera dem och köra dem. Det är ett utmärkt sätt att komma igång enkelt. Ollama erbjuder ett CLI för att göra detsamma. Men om du är ny på lokala modeller skulle jag börja med LM Studio. Du kan installera någondera under _Install > AI_ i Omarchy-menyn.

### Omarchy Skill

Agent-skills hjälper AI att använda specifika verktyg på ett specifikt sätt, och Omarchy levereras med en standard-skill för att skräddarsy systemet. Som att justera din Hyprland-konfiguration, justera fältet eller till och med skapa ett nytt tema från grunden. Den är symlänkad in i skill-katalogerna för Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` och varje `~/.hermes/profiles/*/skills`) och den generiska platsen `~/.agents/skills`, så de flesta harnesser plockar upp den automatiskt.

Men du bör behandla den här skilen som experimentell. Olika modeller använder den till olika effekt. Det är bäst att köra i planläge först, så att du har en uppfattning om vad agenten skulle vilja ändra. Och var sedan redo att rulla tillbaka ändringar eller till och med anropa `omarchy reinstall configs`, om agenten ställer till med en röra av allting.
