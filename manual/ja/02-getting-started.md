# はじめに

Omarchy は ISO を使ってインストールします。ドライブ全体を使うフルディスクインストールか、ドライブの未割り当て領域に Omarchy を入れる空き領域インストールかを選択できます。後者は Windows や別の OS とデュアルブートする方法です（[デュアルブートインストール](50-dual-boot-install.md) を参照。なお、事前に Windows で BitLocker を無効にする必要があります）。いずれの場合も、インストールはデフォルトで完全暗号化となり、フルディスクのオプションでは選択したドライブが消去されるので、既存のドライブを使う前に必ずバックアップを取ってください！

まず [Omarchy ISO をダウンロード](https://omarchy.org/) して、USB メモリに書き込み（Mac/Windows では [balenaEtcher](https://etcher.balena.io/)、Linux では [caligula](https://github.com/ifd3f/caligula) を使います）、そのメモリから起動してください。

_BIOS で Secure Boot や TPM を無効にしなければなりません。Omarchy をインストールできるようにするには、これらを無効にする必要があります。これらは Windows と Microsoft 傘下の Linux ディストリビューション向けの Microsoft のセキュリティスキームです。_

次に設定の質問に答え、このように確認してください：

 ![install-config](images/install-config.webp)

次にインストール先のドライブを選択し、あとは座ってインストールのショーを見ていてください。最速の最新マシンでは 1 分未満で完了することもありますが、古いコンピューターでも 5 分以上かかることはないはずです。

 ![install-done](images/install-done.webp)

これで Omarchy の準備ができました！

### 有線または 2.4ghz のキーボードを使ってください！

フルディスク暗号化では、起動時に Bluetooth キーボードからパスワードを入力できません。PC で BIOS に入るのに Bluetooth キーボードが使えないのと同じです。2.4ghz ドングルを使うか、ケーブル接続のキーボードが必要です（レイテンシの面でもそちらの方がずっと快適です！）。個人的には [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard) が大好きです！

### 別のオーナー向けにインストールする

家族、新しい従業員、買い手など、他の人のためにマシンをセットアップしている場合、個人的な質問にその人の代わりに答えるべきではありません。インストーラーの最初の画面（キーボード選択）で `Ctrl + C` を押すと、Omarchy は代わりに別のオーナー向けにマシンを準備することを提案します。システムはすぐにインストールされますが、キーボードレイアウト、ユーザー名、パスワードといった個人的なセットアップはすべて、マシンが初めて起動するまで先送りされます。ドライブは引き続きデフォルトで暗号化され、新しいオーナーがその初回起動時に選んだパスワードが暗号化パスワードにもなります。（すでに使っているマシンも再インストールなしに引き渡せます。[コンピューターのリセット](48-security.md) を参照してください。）

### 無人インストール

ISO は、2 台目のドライブで設定を渡されれば、キーボードもウィザードもなしに、完全に単独でインストールすることもできます。これが Omarchy を VM やフリートマシンのベースイメージとして扱う方法です。[無人インストール](51-unattended-installs.md) を参照してください。

### 暗号化なしのインストール

Omarchy はデフォルトで暗号化してインストールされます。紛失や盗難の可能性があるコンピューターにとって、安全で責任ある選択です。ハードウェアにアクセスできる誰かにデータを取得されたくはないでしょう！

しかし、保護されたコンピューターへのリモート Omarchy インストールや、機密データのない使い捨てインストールといった特殊な事情では、暗号化なしでインストールしたい場合があります。ディスクフォーマットの確認画面で `Ctrl + C` を押すと、暗号化なしのインストールに切り替えられます。

### 言語

Omarchy は 50 の言語に対応しています。omarchy.org と同じセットで、デフォルトは英語です。切り替えるには、Omarchy メニューを開いて _設定 > 言語_ へ行くか、ターミナルで `omarchy language <code>` を実行してください（`omarchy language list` でコード一覧を表示します）。メニュー、デスクトップ、Omarchy 自身の通知はすぐに言語が変わり、システムロケールもそれに合わせて設定されるので、他のアプリケーションは次回ログイン時に追従します。

### 困ったときのヘルプ

困ったときは、通常 [コミュニティ Discord](https://omarchy.org/discord) の _#omarchy-help_ チャンネルで、手助けしてくれる人が見つかります。
