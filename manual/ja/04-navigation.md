# 移動

Omarchy のすべてはキーボード経由で行われます。_すべてです！_ システムが最初に起動したとき、マウスだけでは文字通り何もできません。でも `Super + Space` を押して Omarchy メニューを表示すれば、そこからほぼ何でもできます。

ただし Omarchy メニューは、ほとんどの場合システムを操作する主な方法であることすら意図されていません。もっと速くできます！ 最も重要なアプリケーションはすべて個別のホットキーに直接バインドされています。ターミナルは `Super + Return` で、ブラウザは `Super + Shift + Return` で起動します。一方をやった後にもう一方をやってみてください。Hyprland のタイリングの魔法が実際に動くのを見るでしょう：

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

次に `Super + J` を押すと、横並びではなく上下に重ねられます：

 ![navigation-stacked](images/navigation-stacked.webp)

もう一度 `Super + J` を押すと横並びの位置に戻ります。次にブラウザ上で `Super + Shift + Arrow Right` を試してウィンドウを入れ替えてください。

次に `Super + Ctrl + T` でアクティビティモニターを起動してください。フローティングウィンドウとして表示されます。`Super + T` でタイリングできます（もう一度押すと再びフローティングになります）。次に `Super + Shift + F` を押してファイルマネージャーを開いてください。きれいな 4 分割のセットアップになります：

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

アクティブにしたいウィンドウ間は `Super + Arrow` で移動します。フォーカスが切り替わり、カーソルが新しいアプリケーションの中央へ移動します。

`Super + Shift + 2` を押すと、現在フォーカスされているアプリケーションが 2 番目のワークスペースへ移動します。`Super + Shift + 1` で戻します。（そして `Super + Shift + Alt + 2` は、現在フォーカスされているアプリケーションを 2 番目のワークスペースへ、そちらへ切り替えることなく移動します）。

`Super` を押したままマウスでウィンドウをクリックすると、その配置を並べ替えられます。`Super` を押したままマウスの右ボタンを使うと、ウィンドウを自由にリサイズできます。

ウィンドウは `Super + W` または `Super + Q` で閉じます（すべてのウィンドウは `Ctrl + Alt + Delete` で閉じます）。

`Super + F` で全画面にも、`Super + Alt + F` で全幅（トップバーを残したまま）にも、`Super + Ctrl + F` でウィンドウ内全画面（YouTube に最適です！）にもできます。

### Dwindle とスクローリングレイアウト

Omarchy のデフォルトレイアウトは dwindle と呼ばれます。単一のワークスペースで開いたすべてのウィンドウを、縮小しなければならなくても、常に表示し続けます。

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

しかし、ウィンドウがディスプレイの見える端を超えて横並びに配置されるスクローリングレイアウトにワークスペースを変えることもできます。`Super + L` で単一のワークスペースをこのレイアウトに変えます。

もう一度 `Super + L` を押すとワークスペースがフローティングになり、ウィンドウが自由に重なって自分で配置できるようになり、3 回目で dwindle に戻ります。`Super + Alt + L` は逆の順序で回ります。そもそもフローティングしているウィンドウ、`Super + T` で出したものや、常にフローティングで開くアプリは、ワークスペースがタイリングに戻ってもフローティングのままです。トップバーは今いるワークスペースをそのレイアウトでマークします：dwindle は四角、スクローリングは円、フローティングは三角です。そのマークをクリックしてもレイアウトが切り替わります。

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

選択はワークスペースごとで、保持されます。だからワークスペース 1 はブラウジング用に dwindle、ワークスペース 2 はコード用にスクローリングにしておけば、再起動後もそのまま戻ってきます。

スクローリングレイアウトをデフォルトにしたい場合は、`~/.config/hypr/looknfeel.lua` で設定できます：

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### フローティングワークスペース

フローティングワークスペースは伝統的なデスクトップのように機能します：ウィンドウが重なり、自分で移動やサイズ変更をします。各ウィンドウにはテーマの色のタイトルバーが付き、最小化、最大化、閉じるボタンがあります。`Super + M` でもフォーカスされたウィンドウを最小化できます。最小化されたウィンドウは Dock で待ち、そのアプリをクリックすると戻ってきます。ウィンドウをクリックすると前面に出ます。どの端や角からでもリサイズできます。タイトルバーをダブルクリックすると、トップバーを表示したままウィンドウを最大化し、もう一度で元のサイズに戻ります。

フローティングワークスペースは Dock も表示します。ピン留めしたアプリ、実行中のすべてのもの、そしてアプリボタンの後ろにあるすべてのアプリのグリッドがあり、`Super + Alt + Space` と Omarchy メニューの _アプリ_ でも開けます。グリッド上のアプリを右クリックするか、`Delete` を押すとアンインストールできます。アプリをクリックすると開くか、そのウィンドウを前面に出し、もう一度クリックするとそのウィンドウ群を順に切り替えます。中クリックで新しいウィンドウを開きます。Dock 沿いにアイコンをドラッグすると移動し、実行中のアプリを他のアプリの間にドラッグするとそこに留まります。右クリックでアプリを Dock に保持したり、外したり、終了したりできます。Dock は全画面ウィンドウの邪魔にならないよう退きます。アプリボタンを右クリックすると Dock を別の端へ移動したり、ポインターがその端に到達するまで隠したりできます。その位置は _実行 > 外観 > Dock > Dock Position_ の下にもあり、ターミナルからは `omarchy dock position left` と `omarchy dock autohide on` で両方設定できます。Dock に保持したアプリは、実行中でない間は薄く表示されます。

新しいワークスペースと、`Super + L` で独自のレイアウトを与えていないワークスペースは、デフォルトレイアウトを使います。デフォルトを変更すると、ウィンドウのないすべてのワークスペースがそれにリセットされますが、ウィンドウのあるものは現在のレイアウトを保持します。_実行 > 外観 > Workspace Layout_ の下で選んでください：Tiling、Scrolling、Floating です。ターミナルからは `omarchy-hyprland-workspace-layout-default scrolling` で設定します。

### ウィンドウのグループ化

ウィンドウは `Super + G` でグループ化できます。グループに入ったら、その状態で起動するすべてのウィンドウがそのグループに属します。こうしたグループ化されたウィンドウ間は `Super + Ctrl + Arrow Left/Right` で移動でき、`Super + Alt + 1/2/3/4` で順序通りにグループ内のウィンドウへ直接移動できます。

`Super + Alt + G` でウィンドウをグループから出すか、もう一度 `Super + G` を押してグループ全体を解散できます。最後に、`Super + Alt + Arrows` でグループ外のウィンドウを中へ移動できます。

### ウィンドウのポップ

`Super + O` でウィンドウをワークスペースの割り当てから切り離せます。どのワークスペースへ行ってもついてくるフローティングウィンドウとして固定されます。動画プレーヤーなどに最適です。

 ![navigation-popped-window](images/navigation-popped-window.webp)

### スクラッチパッドワークスペース

最後に、Quake コンソールのように、今いるワークスペースの上にドロップダウンする特別なスクラッチパッドワークスペースがあります。`Super + Grave` または `Super + S` で切り替え、`Super + Shift + Grave` または `Super + Alt + S` でそこにウィンドウを配置します。

エージェントを実行しているターミナルや、現在のワークスペースを離れずに素早く操作したいコントロールに特に向いています。スクラッチパッドからウィンドウを移動するには、`Super + Shift + 1` のようなもので別のワークスペースへ直接送ってください。

スクラッチパッドが単一のウィンドウを保持している間は、画面全体に広がるのではなく、中央のパネルとしてドロップダウンします。2 つ目のアプリを置くと全幅に戻り、2 つが横並びに座るスペースができます。

### 慣れるまで少し時間がかかります！

このようにデスクトップを移動することに慣れるまで少し時間がかかりますが、一度慣れてしまえば、伝統的なマウス駆動のデスクトップ体験に戻るのは難しくなるでしょう！
