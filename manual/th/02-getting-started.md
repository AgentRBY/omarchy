# เริ่มต้นใช้งาน

Omarchy ติดตั้งจากไฟล์ ISO คุณเลือกได้ระหว่างการติดตั้งแบบเต็มดิสก์ ซึ่งจะยึดทั้งไดรฟ์ไว้ หรือการติดตั้งในพื้นที่ว่าง ซึ่งจะติดตั้ง Omarchy ลงในพื้นที่ที่ยังไม่ได้จัดสรรบนไดรฟ์ — นี่คือวิธีทำ dual boot ควบคู่กับ Windows หรือระบบปฏิบัติการอื่น (ดู [การติดตั้งแบบ dual-boot](50-dual-boot-install.md) — โปรดทราบว่าคุณต้องปิด BitLocker ใน Windows ก่อน) ไม่ว่าจะวิธีไหน การติดตั้งจะใช้การเข้ารหัสเต็มรูปแบบเป็นค่าเริ่มต้น และตัวเลือกแบบเต็มดิสก์จะล้างไดรฟ์ที่เลือก ดังนั้นโปรดสำรองข้อมูลก่อนใช้ไดรฟ์ที่มีอยู่!

[ดาวน์โหลดไฟล์ ISO ของ Omarchy](https://omarchy.org/) ก่อน จากนั้นเขียนลง USB (ใช้ [balenaEtcher](https://etcher.balena.io/) บน Mac/Windows หรือ [caligula](https://github.com/ifd3f/caligula) บน Linux) แล้วบูตจาก USB นั้น

_คุณต้องปิด Secure Boot และ/หรือ TPM ใน BIOS คุณต้องปิดสิ่งเหล่านี้จึงจะติดตั้ง Omarchy ได้ พวกมันเป็นระบบความปลอดภัยของ Microsoft ที่ออกแบบมาสำหรับ Windows และดิสทริบิวชัน Linux ที่สังกัด Microsoft_

จากนั้นตอบคำถามการกำหนดค่าและยืนยันดังนี้:

 ![install-config](images/install-config.webp)

จากนั้นเลือกไดรฟ์สำหรับการติดตั้ง แล้วนั่งดูการติดตั้งดำเนินไปอย่างเพลิดเพลิน มันทำเสร็จได้ภายในเวลาไม่ถึงหนึ่งนาทีบนเครื่องยุคใหม่ที่เร็วที่สุด แต่ก็ไม่ควรใช้เวลานานกว่า 5 นาทีแม้บนคอมพิวเตอร์รุ่นเก่า

### ใช้คีย์บอร์ดแบบมีสายหรือ 2.4ghz!

การเข้ารหัสเต็มดิสก์จะไม่ให้คุณป้อนรหัสผ่านจากคีย์บอร์ด Bluetooth ตอนเริ่มเครื่อง เหมือนกับที่คุณใช้คีย์บอร์ด Bluetooth เข้า BIOS บน PC ไม่ได้ คุณต้องใช้คีย์บอร์ดที่เชื่อมต่อด้วยดองเกิล 2.4ghz หรือสายเคเบิล (ซึ่งดีกว่ามากในแง่ความหน่วงอยู่แล้ว!) ส่วนตัวผมชอบ [Lofree Flow84](https://www.lofree.co/products/lofree-flow-the-smoothest-mechanical-keyboard) มาก!

### ติดตั้งเพื่อเจ้าของคนอื่น

ถ้าคุณกำลังตั้งเครื่องให้คนอื่น — สมาชิกในครอบครัว พนักงานใหม่ ผู้ซื้อ — คุณไม่ควรตอบคำถามส่วนตัวแทนพวกเขา กด `Ctrl + C` บนหน้าจอแรกสุดของตัวติดตั้ง (การเลือกคีย์บอร์ด) แล้ว Omarchy จะเสนอให้เตรียมเครื่องสำหรับเจ้าของคนอื่นแทน ระบบจะติดตั้งทันที แต่การตั้งค่าส่วนตัวทั้งหมด — เค้าโครงแป้นพิมพ์ ชื่อผู้ใช้ รหัสผ่าน — จะถูกเลื่อนไปจนถึงตอนที่เครื่องบูตครั้งแรก ไดรฟ์ยังคงเข้ารหัสเป็นค่าเริ่มต้น และรหัสผ่านที่เจ้าของคนใหม่เลือกตอนบูตครั้งแรกนั้นจะกลายเป็นรหัสผ่านการเข้ารหัสด้วย (เครื่องที่คุณใช้งานมาแล้วก็ส่งต่อได้โดยไม่ต้องติดตั้งใหม่เช่นกัน — ดู [การรีเซ็ตเครื่องคอมพิวเตอร์](48-security.md))

### การติดตั้งแบบไม่ต้องเฝ้า

ไฟล์ ISO ยังติดตั้งเองได้ทั้งหมด — ไม่ต้องใช้คีย์บอร์ด ไม่มีวิซาร์ด — เมื่อได้รับการกำหนดค่าบนไดรฟ์ที่สอง นี่คือวิธีใช้ Omarchy เป็นอิมเมจพื้นฐานสำหรับ VM และเครื่องในองค์กร ดู [การติดตั้งแบบไม่ต้องเฝ้า](51-unattended-installs.md)

### การติดตั้งแบบไม่มีการเข้ารหัส

ตามค่าเริ่มต้น Omarchy ติดตั้งพร้อมการเข้ารหัส นี่คือทางเลือกที่ปลอดภัยและมีความรับผิดชอบสำหรับคอมพิวเตอร์ที่อาจสูญหายหรือถูกขโมยได้ คุณไม่ต้องการให้ใครก็ตามที่มีฮาร์ดแวร์ของคุณเข้าถึงข้อมูลของคุณได้!

แต่ในสถานการณ์พิเศษ เช่น การติดตั้ง Omarchy จากระยะไกลบนเครื่องที่ได้รับการป้องกัน หรือการติดตั้งชั่วคราวที่ไม่มีข้อมูลสำคัญ คุณอาจต้องการติดตั้งโดยไม่มีการเข้ารหัส คุณสามารถกด `Ctrl + C` ที่หน้ายืนยันการฟอร์แมตดิสก์เพื่อเปลี่ยนไปติดตั้งโดยไม่มีการเข้ารหัส

### ภาษา

Omarchy พูดได้ 50 ภาษา — ชุดเดียวกับ omarchy.org — และภาษาอังกฤษเป็นค่าเริ่มต้น หากต้องการเปลี่ยน เปิดเมนู Omarchy แล้วไปที่ _ตั้งค่า > ภาษา_ หรือรัน `omarchy language <code>` ในเทอร์มินัล (`omarchy language list` แสดงรหัสต่าง ๆ) เมนู เดสก์ท็อป และการแจ้งเตือนของ Omarchy เองจะเปลี่ยนภาษาทันที และ locale ของระบบจะถูกตั้งให้ตรงกัน ดังนั้นแอปพลิเคชันอื่น ๆ ของคุณจะเปลี่ยนตามในครั้งต่อไปที่คุณเข้าสู่ระบบ
