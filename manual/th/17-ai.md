# AI

Omarchy ปฏิบัติต่อเอเจนต์เขียนโค้ดด้วย AI เสมือนพลเมืองชั้นหนึ่ง แต่มันไม่ได้เลือกรายการโปรดให้คุณ ทุก ๆ CLI ของเอเจนต์เขียนโค้ดรายใหญ่มาพร้อมกันเป็นตัวเรียกใช้ที่โหลดแบบไม่รีบแทน ตัวเปิดใช้เป็น stub เล็ก ๆ ที่จัดการด้วย [mise](https://mise.jdx.dev/) ใน `~/.local/bin/` ดังนั้นจึงไม่มีอะไรถูกดาวน์โหลดจนกว่าคุณจะรันตัวใดตัวหนึ่งครั้งแรกจริง ๆ Hermes เป็นข้อยกเว้น: ไม่มีอะไรถูก stub ไว้สำหรับมัน และการเลือกมันจะติดตั้ง Hermes Desktop ดังที่ _แอปเดสก์ท็อป_ ด้านล่างอธิบาย เรียกใช้ตัวใดตัวหนึ่งและยืนยันตัวตนเมื่อได้รับแจ้ง:

| คำสั่ง    | เอเจนต์                                                            |
|------------|------------------------------------------------------------------|
| `claude`   | [Claude Code](https://code.claude.com/docs/en/overview)          |
| `codex`    | [OpenAI Codex](https://github.com/openai/codex)                  |
| `opencode` | [OpenCode](https://opencode.ai/)                                 |
| `agy`      | [Google Antigravity CLI](https://github.com/google-antigravity/antigravity-cli) |
| `copilot`  | [GitHub Copilot CLI](https://github.com/github/copilot-cli)      |
| `crush`    | [Crush](https://github.com/charmbracelet/crush)                  |
| `grok`     | [Grok Build](https://x.ai/build) from xAI                        |
| `pi`       | [Mario Zechner's Pi](https://github.com/badlogic/pi-mono)        |
| `omp`      | [Oh My Pi](https://github.com/can1357/oh-my-pi)                  |
| `ori`      | [Ori](https://openrouter.ai/docs/guides/ori/harness), OpenRouter's harness |
| `hermes`   | [Hermes](https://hermes-agent.nousresearch.com/), Nous Research's agent  |
| `muse`     | [Muse Code](https://dev.meta.ai), Meta's coding agent           |
| `cursor-agent` | [Cursor CLI](https://cursor.com/cli)                         |

`ori` คือตัวที่แปลกออกไป: มันรันระบบนำร่องอื่น ๆ เทียบกับแคตตาล็อกโมเดลทั้งหมดของ OpenRouter ดังนั้น `ori claude` `ori codex` หรือ `ori opencode` จึงเริ่มเอเจนต์เหล่านั้นบนโมเดลไหนก็ตามที่คุณชี้ให้ และ `ori code` คือเอเจนต์ของ Ori เอง

หากต้องการห่อ CLI เพิ่มเติมในแบบเดียวกัน รัน `omarchy-mise-install <package> [command-name]` stub ต่าง ๆ จะได้รับการดูแลให้เป็นปัจจุบันพร้อมกับทุกสิ่งอื่น ๆ ที่ mise จัดการ เมื่อคุณรัน `omarchy update` (หรือนามแฝง `mup`)

`grok` ติดตั้งผ่านแพ็กเกจ `grok` ฝ่ายแรกของ mise ในแบบเดียวกับ `claude` และ `codex` รัน `grok` หรือเลือกมันภายใต้ _ตั้งค่า > ค่าเริ่มต้น > เอเจนต์_ ข้ามตัวติดตั้ง `curl | bash` บน x.ai ไป เส้นทางนั้นวางสำเนาที่สองใน `~/.grok/bin` แซงหน้ามันบน `PATH` และเขียนทับโปรแกรมครอบของ Omarchy

### เอเจนต์เริ่มต้น

เลือกเอเจนต์เริ่มต้นของคุณด้วย `omarchy default agent <name>` หรือภายใต้ _ตั้งค่า > ค่าเริ่มต้น > เอเจนต์_ ในเมนู Omarchy (`Super + Space`) ถ้าเอเจนต์นั้นยังไม่ได้ติดตั้ง การเลือกมันจะติดตั้งมันก่อน Omarchy ใหม่จะเชิญคุณให้ทำการตัดสินใจครั้งนี้ด้วยการแจ้งเตือนเพียงครั้งเดียว

การเลือก Claude ยังพยายามตั้งค่าส่วนขยายเบราว์เซอร์ของมันสำหรับ Chromium Chrome Brave Brave Origin และ Edge ด้วย การตั้งค่าส่วนขยายนั้นนำไปใช้กับผู้ใช้ทุกคนและอาจขอรหัสผ่านระบบของคุณ การยกเลิกหรือการติดตั้งส่วนขยายที่ล้มเหลวยังคงเลือกและเปิดใช้ Claude อยู่ รีสตาร์ตเบราว์เซอร์ของคุณ เปิดใช้ส่วนขยายหากได้รับแจ้ง และเข้าสู่ระบบ Claude เพื่อเชื่อมต่อมันให้เสร็จ รัน `/chrome` ใน Claude เพื่อตรวจการเชื่อมต่อ Firefox และ Zen ไม่รองรับส่วนขยายนี้ ถ้า Claude เคยเป็นตัวเลือกเริ่มต้นของคุณก่อนการตั้งค่านี้ถูกเพิ่ม เลือกมันอีกครั้งเพื่อติดตั้งส่วนขยาย

[Muse Code](https://dev.meta.ai) — `muse` ของ Meta — ใช้ mise stub ที่ติดตั้งไว้ล่วงหน้าเหมือนเอเจนต์อื่น ๆ การเลือกมันเป็นเอเจนต์เริ่มต้นจะติดตั้งโปรแกรมเปิดใช้ทางการของ Meta ผ่านแบ็กเอนด์ HTTP ของ mise โปรแกรมเปิดใช้จะตรวจสอบและอัปเดตไบนารีพื้นฐานสำหรับเครื่องของคุณ

เมื่อคุณเลือกแล้ว `Super + Shift + Ctrl + A` จะเปิดใช้เอเจนต์เริ่มต้นในหน้าต่างเทอร์มินัลแยกเฉพาะ (หรือเรียกตัวเลือกขึ้นมาหากคุณยังไม่ได้เลือก) คุณยังสั่งมันตรงเข้างานด้วย `omarchy agent prompt "Review this project"` เอเจนต์ที่เปิดใช้แบบนี้จะรันโดยไม่มีคนเฝ้าในโหมดที่ถูกใช้ให้ทำต่อไปอย่าหยุดถามของแต่ละตัว ดังนั้นเตรียมตัวรับมือให้พวกมันทำอะไรจริง ๆ! และเนื่องจากเอเจนต์ปฏิเสธที่จะจำความเชื่อถือสำหรับไดเรกทอรีบ้านของคุณ การเปิดจาก `$HOME` จะไปเริ่มที่ `~/Work` แทน

ยังมีปุ่มลัดเทอร์มินัลด้วย: `a` รันเอเจนต์เริ่มต้นแบบอินไลน์ในเทอร์มินัลปัจจุบัน ขณะที่ `c` `cx` และ `cy` เริ่ม OpenCode Claude Code และ Codex โดยตรง (อีกครั้งในโหมดการอนุมัติอัตโนมัติของพวกมัน) การเปลี่ยนธีมยังซิงค์ไปยังเอเจนต์ด้วย: Claude Code Pi OpenCode และ Hermes (เมื่อ Omarchy ได้ติดตั้งมันแล้ว) ทั้งหมดจะเปลี่ยนตามเมื่อคุณเปลี่ยนธีม Omarchy

### แผงเอเจนต์

แถบบนมีไอคอนเอเจนต์ ก่อนที่คุณจะตั้งค่าเอเจนต์ แผงของมันจะพาคุณผ่านการเข้าสู่ระบบ Claude Codex หรือ Grok และตัวแรกจะกลายมาเป็นเอเจนต์เริ่มต้นของคุณ หลังจากนั้น แผงจะใส่ทุกการสมัครรับไว้ในหน้าเดียว: ทุกเอเจนต์และบัญชีพร้อมแผนของมัน ตัวชี้วัดสำหรับแต่ละตัวของข้อจำกัดเซสชัน 5 ชั่วโมงและรายสัปดาห์พร้อมเวลาจนกว่ารีเซ็ตของมัน (ชี้ดูเปอร์เซ็นต์ที่แน่นอน) หรือยอดคงเหลือที่ชำระล่วงหน้าที่เหลืออยู่ ภายใต้หนึ่งบรรทัดที่หมุนเวียนผ่านสิ่งที่คุณได้ใช้ในทุก ๆ ตัวของพวกมัน เช่น โทเค็นในสัปดาห์นี้ และโมเดลที่ใช้มากสุดของคุณ ภายใต้ _สร้างอะไรบางอย่าง_ มันนำเสนอพรอมต์เริ่มต้นสำหรับธีม ปลั๊กอิน หรือแอปใหม่ ที่มอบหมายงานนั้นให้เอเจนต์เริ่มต้นของคุณ แอปถูกสร้างในวิธีที่แอปของ Omarchy เอง อย่าง Hype Monologue และ Omacut ถูกสร้างขึ้น ด้วย C++ และ Qt Quick โดยทำตามสกิลเอเจนต์ omarchy-app และคอมไพเลอร์และชิ้นส่วน Qt ที่พวกเขาต้องการก็ได้รับการติดตั้งไว้แล้ว Claude Code Codex Grok และ Fireworks ได้รับการครอบคลุมตั้งแต่แกะกล่อง

คลิกซ้ายที่ไอคอนแถบสำหรับแผง คลิกขวาเพื่อเปิดเอเจนต์เริ่มต้นของคุณ บันทึกการใช้งานที่อยู่เบื้องหลังมันถูกสร้างขึ้นใหม่ทุก 15 นาทีโดย `omarchy agent usage-update` และแผงยังผสานการใช้งานจากเครื่องอื่น ๆ ของคุณผ่านโฟลเดอร์ที่ซิงค์ได้ด้วย ดู README ภายใต้ `$OMARCHY_PATH/shell/plugins/agents/` สำหรับการตั้งค่าเต็มรูปแบบ

### การสมัครรับหลายแบบ

หากคุณจ่ายสำหรับแผน Claude Codex หรือ Grok มากกว่าหนึ่งแบบ — Max ส่วนตัวและที่ทำงานหนึ่งแบบ เป็นต้น — Omarchy จะเก็บพวกมันทั้งหมดให้เข้าสู่ระบบอยู่และย้ายไปมาระหว่างพวกมันได้ เพิ่มการสมัครรับด้วย + ในแผงเอเจนต์ ซึ่งจะพาคุณผ่านมันทันที หรือด้วย `omarchy agent account add claude Work` (หรือ `codex` หรือ `grok`) มันจะติดตั้ง CLI หากขาดอยู่ บัญชีแรกสำหรับผู้ให้บริการจะเข้าสู่ระบบผ่านเบราว์เซอร์ปกติของคุณ ตรงที่ CLI ใช้เสมอ ทุกบัญชีหลังนั้นจะเข้าสู่ระบบผ่านหน้าต่างส่วนตัว ดังนั้นบัญชีที่เบราว์เซอร์ของคุณเข้าสู่ระบบอยู่แล้วจะไม่ถูกหยิบไปใช้โดยไม่ตั้งใจ เข้าสู่ระบบที่นั่นเป็นบัญชีที่คุณกำลังเพิ่ม และปิดหน้าต่างส่วนตัวใด ๆ ที่คุณเปิดไว้แล้วก่อน อย่าเข้าสู่ระบบออกจาก CLI เพื่อทำสิ่งนี้เด็ดขาด การออกจากระบบเป็นการเพิกถอนการเข้าสู่ระบบที่บันทึกไว้ และบัญชีนั้นจะต้องถูกเพิ่มเข้ามาใหม่

หนึ่งบัญชีต่อผู้ให้บริการที่ใช้งานอยู่ และเซสชันใหม่ทุกตัวจะเริ่มเป็นบัญชีนั้น: `cx` `cy` `claude` ธรรมดา `codex` หรือ `grok` อะไรก็ตามที่เปิดผ่าน `omarchy agent` และสคริปต์หรือโปรแกรมแก้ไขที่หา CLI บน `PATH` สลับด้วย `omarchy agent account use work` (และกลับด้วย `omarchy agent account use main`) หรือในแผงโดยการกดหมายเลขของบัญชีแล้วกด `Enter` (หรือคลิกปุ่ม Use ของมัน) เซสชันที่กำลังรันอยู่แล้วจะอยู่กับบัญชีที่พวกมันเริ่มไว้ ประวัติการสนทนา การตั้งค่า สกิล และปลั๊กอินมีการแชร์ข้ามบัญชี ดังนั้น `claude --continue` ในโฟลเดอร์เดียวกันจะดำเนินการต่อจากที่ที่คุณหยุดไปบนบัญชีใหม่

ด้วยมากกว่าหนึ่งบัญชี แผงจะแสดงข้อจำกัดของแต่ละบัญชีเคียงข้างกัน พร้อมเครื่องหมายทำบัญชีที่ใช้งานอยู่ ตามค่าเริ่มต้น Omarchy จะแจ้งเตือนคุณเมื่อบัญชีที่ใช้งานอยู่ผ่าน 95% ของข้อจำกัด และการคลิกการแจ้งเตือนจะสลับไปยังบัญชีที่มีพื้นที่มากที่สุด ชี้ที่บรรทัดของบัญชีในแผงและคลิก Autoswitch ที่ปรากฏถัดจาก Use (หรือกด `m`) หรือรัน `omarchy agent account mode auto` เพื่อให้มันสลับด้วยตัวมันเองแทน ในขณะที่มันเปิดอยู่ Autoswitch จะเข้ามาแทน Use และการคลิกมันอีกครั้งจะกลับไปเป็นแจ้งเตือน เพิ่มตัวเลขเพื่อเปลี่ยนเกณฑ์ เช่นใน `omarchy agent account mode auto 90` ถ้าทุกบัญชีอยู่เหนือเกณฑ์ คุณจะได้ยินเกี่ยวกับมันครั้งเดียว พร้อมกับบัญชีไหนที่จะว่างก่อน ขณะที่บัญชีที่ใช้งานอยู่ภายใน 15 จุดของเกณฑ์ของมัน (80% เป็นค่าเริ่มต้น) ข้อจำกัดของมันจะได้รับการตรวจสอบทุกสามนาทีแทนทุก 15 นาที

`omarchy agent account list` แสดงทุกบัญชีและข้อจำกัดล่าสุดของมัน `omarchy agent account remove work` ลืมหนึ่งบัญชี และ `omarchy agent account rename primary Hey` เปลี่ยนชื่อหนึ่งบัญชี (หรือคลิกชื่อบัญชีในแผง) คำสั่งเหล่านี้ทำงานกับบัญชีของเอเจนต์เริ่มต้นของคุณ หากต้องการไปถึงผู้ให้บริการรายอื่น ให้ตั้งชื่อมันก่อน เช่นใน `omarchy agent account use codex side` บัญชีที่คุณเข้าสู่ระบบไว้แล้วใน `~/.claude` หรือ `~/.codex` คือบัญชี _Main_ และอยู่กับที่เป็นปกติ บัญชีที่ไม่ได้ใช้มากกว่าประมาณแปดชั่วโมงสามารถแสดง _Sign-in required_ คลิกมันเพื่อลงชื่อเข้าบัญชีนั้นอีกครั้งในแผง ในแบบโดยตรง หรือเริ่มเซสชันในบัญชีนั้นซึ่งจะรีเฟรชการเข้าสู่ระบบด้วยตัวเอง เซิร์ฟเวอร์ MCP ที่คุณมีตอนที่บัญชีถูกเพิ่มจะตามมาด้วย แต่ตัวที่คุณเพิ่มทีหลังด้วย `claude mcp add` จะไปถึงเฉพาะบัญชีที่คุณเพิ่มมันเข้าไปเท่านั้น Claude Desktop และเครื่องมือที่ตั้งค่าด้วยพาธสัมบูรณ์ไปยังไบนารี CLI จะไม่ตามไปเมื่อสลับ ตัวแปร `CLAUDE_CONFIG_DIR` `CODEX_HOME` หรือ `GROK_HOME` อย่างชัดแจ้งมีลำดับความสำคัญเหนือบัญชีที่เลือก

### การวินิจฉัยการขัดข้อง

Omarchy เฝ้าดู systemd-coredump สำหรับการขัดข้องของกระบวนการ เมื่อมีอะไร segfault คุณจะได้รับการแจ้งเตือน "Process crashed" — คลิกมัน แล้วการขัดข้องจะถูกมอบให้กับเอเจนต์เริ่มต้นของคุณพร้อมสกิล diagnose-crash ของ Omarchy ซึ่งจะพาเอเจนต์ไปผ่านการรวบรวมข้อเท็จจริงจาก core dump และตัดสินว่าการขัดข้องนั้นคุ้มค่าที่จะรายงานไปยังต้นทางหรือไม่ คุณยังรันมันด้วยมือกับ PID ใดก็ตามจาก `coredumpctl list` ด้วย `omarchy agent crash <pid>`

การเฝ้าดูเปิดอยู่เป็นค่าเริ่มต้น ปิดมันภายใต้ _สั่งการ > สลับ > บันทึกการขัดข้อง_ (หรือด้วย `omarchy toggle crash-capture`) และการแจ้งเตือนจะหยุด `omarchy agent crash <pid>` ยังคงใช้งานได้ด้วยมือ

การขัดข้องยังถูกปิดเสียงทีละโปรแกรม ซึ่งคือสิ่งที่การวินิจฉัยเสนอให้คุณในตอนท้าย `omarchy crash mute hyprland` หยุดการแจ้งเตือนสำหรับโปรแกรมนั้นเพียงอย่างเดียว `omarchy crash mute hyprland off` นำพวกมันกลับมา และ `omarchy crash mute` เดี่ยว ๆ แสดงรายการสิ่งที่คุณได้ปิดเสียง มันใช้พาธของไบนารีพอ ๆ กับชื่อของมัน ดังนั้น `omarchy crash mute /usr/bin/hyprland` ทำสิ่งเดียวกัน พันชื่อที่มีเว้นวรรคในนั้นเช่น `omarchy crash mute 'Some App'` ทุกสิ่งอื่นยังคงแจ้งเตือน และโปรแกรมที่ปิดเสียงยังคงขัดข้อง — นี่คือการซ่อนตัวเตือนความจำ มันไม่ได้แก้ปัญหาอะไรเลย

### แอปเดสก์ท็อป

เมนู _ติดตั้ง > AI_ ยังมีแอป AI เชิงกราฟิกไม่กี่ตัว: แอปเดสก์ท็อป ChatGPT แอปเดสก์ท็อป Claude (เบต้า Linux ของ Anthropic พร้อมแท็บ Chat Cowork และ Claude Code) Grok Bot สำหรับการสนทนากับโมเดลของ xAI Hermes Desktop OpenClaw และแอปเดสก์ท็อป Perplexity Grok Bot คือแอปแชตเดสก์ท็อป ส่วนเอเจนต์เขียนโค้ดคือคำสั่ง `grok`

Hermes Desktop เป็นหนึ่งในนั้นที่ควรรู้ เพราะเครื่องหนึ่งเครื่องหนึ่งมี Hermes หนึ่งตัวเดียว และมันคือตัวของแอป: Hermes จะได้รับการติดตั้งผ่านแอปเท่านั้น และคำสั่ง `hermes` ที่เอเจนต์เริ่มต้นรันคือคำสั่งของแอป การเลือก Hermes เป็นเอเจนต์เริ่มต้นจะติดตั้งสิ่งเดียวกันกับที่รายการ _ติดตั้ง > AI_ ทำ: ตัวแพ็กเกจ และรันไทม์ Hermes ภายใต้ `~/.hermes` ที่ตั้งขึ้นโดยตัวติดตั้งของ Hermes เอง ซึ่งใช้เวลาไม่กี่นาทีในครั้งแรก รันไทม์นั้นคือสิ่งหนึ่งเดียวกันที่คำสั่ง `hermes` ในเทอร์มินัล เอเจนต์เริ่มต้นและแอปใช้ร่วมกัน และมันอัปเดตตัวเองด้วย `hermes update` แทนที่จะรอการเผยแพร่ Omarchy การติดตั้งมันยังมอบธีม Omarchy ให้กับ Hermes เป็นสกินชื่อ `omarchy` ที่พื้นผิว Hermes ทุกตัวจะตามการใช้ของคุณเมื่อคุณเปลี่ยนธีม เลือกอีกแบบภายใต้การตั้งค่า Appearance ของ Hermes หรือด้วย `/skin` หากคุณอยากให้มันไม่ทำแบบนั้น และ Omarchy จะทิ้งตัวเลือกนั้นไว้ การถอนแอปภายใต้ _นำออก > AI_ จะปิด Hermes ก่อน รวมถึงเกตเวย์ นำรันไทม์นั้นออกไปด้วย และเก็บแชทของคุณ ความทรงจำของคุณ และสกิลที่ Hermes เขียนให้ตัวเอง เว้นแต่ว่าคุณจะบอกมันเป็นอย่างอื่น: มันจะถามโดยที่คงเป็นไม่ ว่าข้อมูลเหล่านั้นและการตั้งค่าการเชื่อมต่อของคุณควรหายไปด้วยเช่นกันหรือไม่

ประสบการณ์เดสก์ท็อปของ OpenClaw คือ Control UI ของมัน ซึ่งจะเปิดเป็นเว็บแอปที่รองรับโดยเกตเวย์ท้องถิ่นของมันเอง OpenClaw อยู่ใน `~/.openclaw` และอัปเดตตัวเอง: ใช้ปุ่ม "Update Gateway" ของ Control UI หรือรัน `openclaw update` และเกตเวย์จะรีสตาร์ตบนเวอร์ชันใหม่ Omarchy เพียงแค่เลือกการเปิดตัวที่การติดตั้งใหม่เริ่มจากตรงนั้น การถอน OpenClaw ภายใต้ _นำออก > AI_ จะนำบริการเกตเวย์และแอปออกไปด้วย จากนั้นจะถามว่า `~/.openclaw` ควรหายไปด้วยหรือไม่ เนื่องจากมันบรรจุแชทของคุณและข้อมูลรับรองของคุณพร้อมกับ OpenClaw เองและรันไทม์ปลั๊กอินที่มันดาวน์โหลด ค่าเริ่มต้นคือเก็บเสมอ และการติดตั้ง OpenClaw อีกครั้งจะหยิบมันกลับมา

### LLM ในเครื่อง

Omarchy แนะนำสองวิธีในการรันโมเดล LLM ในเครื่อง: LM Studio และ Ollama LM Studio มีอินเทอร์เฟซแบบ GUI สำหรับการค้นหาโมเดลแบบเปิดน้ำหนัก การติดตั้ง และการใช้งานพวกมัน นี่คือวิธีที่ดีที่สุดในการเริ่มต้นได้ง่าย Ollama มี CLI ที่ทำคล้าย ๆ กัน แต่ถ้าคุณเพิ่งเริ่มใช้โมเดลในเครื่อง ผมจะเริ่มจาก LM Studio คุณสามารถติดตั้งอย่างใดอย่างหนึ่งภายใต้ _ติดตั้ง > AI_ ในเมนู Omarchy

### สกิล Omarchy

สกิลของเอเจนต์ช่วยให้ AI ใช้เครื่องมือเฉพาะในวิธีเฉพาะได้ และ Omarchy ส่งมาพร้อมสกิลเริ่มต้นสำหรับการปรับแต่งระบบ เช่นปรับแต่งคอนฟิก Hyprland ของคุณ ปรับเปลี่ยนแถบ หรือแม้แต่สร้างธีมใหม่ตั้งแต่ศูนย์ มันถูกเชื่อมโยงเป็น symlink ไปยังไดเรกทอรีสกิลสำหรับ Claude Code (`~/.claude/skills`) Codex (`~/.codex/skills`) Pi (`~/.pi/agent/skills`) Antigravity (`~/.gemini/config/skills`) Hermes (`~/.hermes/skills` และ `~/.hermes/profiles/*/skills` แต่ละอัน) และตำแหน่งทั่วไป `~/.agents/skills` ดังนั้นตัวควบคุมและเครื่องมือส่วนใหญ่จึงหยิบมันไปใช้โดยอัตโนมัติ

แต่คุณควรปฏิบัติต่อสกิลนี้เป็นการทดลอง โมเดลต่าง ๆ จะใช้มันด้วยผลที่แตกต่างกัน มีประโยชน์ที่สุดที่จะรันในโหมดวางแผนก่อน เพื่อให้คุณมีความคิดว่าเอเจนต์ต้องการเปลี่ยนอะไร และจากนั้นเตรียมย้อนกลับการเปลี่ยนแปลงหรือแม้แต่เรียก `omarchy reinstall configs` หากเอเจนต์ทำให้ทุกอย่างยุ่งเหยิง
