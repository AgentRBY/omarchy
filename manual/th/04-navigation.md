# การนำทาง

ทุกสิ่งใน Omarchy เกิดขึ้นผ่านคีย์บอร์ด — _ทุกสิ่งจริง ๆ!_ เมื่อระบบเริ่มครั้งแรก คุณแทบทำอะไรด้วยเมาส์เพียงอย่างเดียวไม่ได้เลย แต่คุณกด `Super + Space` เพื่อเปิดเมนู Omarchy ได้ และจากตรงนั้นคุณทำได้แทบทุกอย่าง

แต่เมนู Omarchy ไม่ได้ตั้งใจให้เป็นวิธีหลักในการใช้งานระบบโดยส่วนใหญ่ เราเร็วกว่านั้นได้! แอปพลิเคชันสำคัญที่สุดทั้งหมดผูกตรงกับปุ่มลัดแต่ละปุ่ม คุณเปิดเทอร์มินัลด้วย `Super + Return` และเบราว์เซอร์ด้วย `Super + Shift + Return` ลองทำต่อกันดู แล้วคุณจะเห็นความมหัศจรรย์ของการเรียงหน้าต่างของ Hyprland ทำงาน:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

จากนั้นคุณกด `Super + J` เพื่อวางพวกมันซ้อนกันแทนที่จะอยู่เคียงข้างกัน:

 ![navigation-stacked](images/navigation-stacked.webp)

กด `Super + J` อีกครั้งเพื่อคืนพวกมันกลับสู่ตำแหน่งเคียงข้างกัน จากนั้นลอง `Super + Shift + Arrow Right` ขณะอยู่บนเบราว์เซอร์ เพื่อสลับหน้าต่าง

ตอนนี้ลอง `Super + Ctrl + T` เพื่อเปิดตัวตรวจสอบกิจกรรม มันจะปรากฏเป็นหน้าต่างลอย คุณสามารถเรียงมันโดยใช้ `Super + T` (และกดอีกครั้งเพื่อทำให้มันลอยอีกครั้ง) ตอนนี้กด `Super + Shift + F` เพื่อเปิดตัวจัดการไฟล์ คุณจะได้การจัดวางสี่ช่องที่เรียบร้อย:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

คุณนำทางระหว่างหน้าต่างที่คุณต้องการให้ทำงานด้วย `Super + Arrow` นี่จะเปลี่ยนโฟกัสและย้ายเคอร์เซอร์ไปยังกึ่งกลางของแอปพลิเคชันใหม่

ถ้าคุณกด `Super + Shift + 2` คุณจะย้ายแอปพลิเคชันที่โฟกัสอยู่ไปยังพื้นที่งานที่สอง `Super + Shift + 1` ย้ายมันกลับ (และ `Super + Shift + Alt + 2` จะย้ายแอปพลิเคชันที่โฟกัสอยู่ไปยังพื้นที่งานที่สองโดยไม่เปลี่ยนไปหามัน)

ถ้าคุณกด `Super` ค้างไว้และใช้เมาส์คลิกบนหน้าต่าง คุณจะจัดตำแหน่งของมันใหม่ได้ ถ้าคุณกด `Super` ค้างไว้และใช้ปุ่มขวาบนเมาส์ คุณสามารถปรับขนาดหน้าต่างได้อย่างอิสระ

คุณปิดหน้าต่างด้วย `Super + W` หรือ `Super + Q` (และปิดทุกหน้าต่างด้วย `Ctrl + Alt + Delete`)

คุณยังทำให้เต็มหน้าจอด้วย `Super + F` หรือแม้แต่เต็มความกว้างเพียงอย่างเดียว (โดยรักษาแถบบนไว้) ด้วย `Super + Alt + F` หรือเต็มหน้าจอภายในหน้าต่างด้วย `Super + Ctrl + F` (เหมาะสำหรับ YouTube!)

### เค้าโครง Dwindle เทียบกับแบบเลื่อน

เค้าโครงเริ่มต้นของ Omarchy เรียกว่า dwindle มันรักษาหน้าต่างทั้งหมดที่คุณเปิดบนพื้นที่งานเดียวให้มองเห็นตลอดเวลา แม้ว่าจะต้องย่อพวกมันลงก็ตาม

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

แต่คุณยังเลือกเปลี่ยนพื้นที่งานเป็นเค้าโครงแบบเลื่อนได้ ซึ่งหน้าต่างจะเรียงกันเคียงข้าง เลยขอบที่มองเห็นของจอแสดงผล คุณเปลี่ยนพื้นที่งานเดียวเป็นเค้าโครงนี้ผ่าน `Super + L`

การกด `Super + L` อีกครั้งจะเปลี่ยนพื้นที่งานเป็นแบบลอย ซึ่งหน้าต่างซ้อนกันอย่างอิสระและคุณวางพวกมันเอง และการกดครั้งที่สามจะคืนมันกลับสู่ dwindle `Super + Alt + L` จะหมุนพวกมันไปในทิศทางตรงกันข้าม หน้าต่างที่ลอยอยู่แล้ว — หน้าต่างที่คุณดึงออกด้วย `Super + T` หรือแอปที่เปิดแบบลอยเสมอ — จะยังคงลอยอยู่เมื่อพื้นที่งานกลับไปสู่การเรียง แถบบนจะทำเครื่องหมายพื้นที่งานที่คุณอยู่ด้วยเค้าโครงของมัน: สี่เหลี่ยมสำหรับ dwindle วงกลมสำหรับแบบเลื่อน และสามเหลี่ยมสำหรับแบบลอย การคลิกเครื่องหมายนั้นจะหมุนเค้าโครงเช่นกัน

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

ตัวเลือกนั้นแยกต่อพื้นที่งาน และมันจะคงอยู่อย่างนั้น ดังนั้นคุณรักษาพื้นที่งาน 1 เป็น dwindle สำหรับการท่องเว็บ และพื้นที่งาน 2 เป็นแบบเลื่อนสำหรับโค้ดได้ และพวกมันจะกลับมาเป็นแบบนั้นหลังรีสตาร์ต

ถ้าคุณต้องการใช้เค้าโครงแบบเลื่อนเป็นค่าเริ่มต้น คุณสามารถตั้งค่านั้นใน `~/.config/hypr/looknfeel.lua`:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### พื้นที่งานแบบลอย

พื้นที่งานแบบลอยทำงานเหมือนเดสก์ท็อปแบบดั้งเดิม: หน้าต่างซ้อนกัน และคุณย้ายและกำหนดขนาดพวกมันเอง แต่ละหน้าต่างจะมีแถบชื่อในสีของธีมของคุณ พร้อมปุ่มย่อ ขยายใหญ่สุด และปิด `Super + M` ก็ย่อหน้าต่างที่โฟกัสเช่นกัน หน้าต่างที่ย่อแล้วจะรอใน dock คลิกแอปของมันเพื่อเอามันกลับมา คลิกหน้าต่างเพื่อนำมันมาข้างหน้า ปรับขนาดมันจากขอบหรือมุมใด ๆ ดับเบิลคลิกแถบชื่อเพื่อขยายหน้าต่างใหญ่สุดโดยขณะที่รักษาแถบบนไว้ให้เห็น และดับเบิลคลิกอีกครั้งเพื่อเอาขนาดเดิมของมันกลับมา

พื้นที่งานแบบลอยยังแสดง dock พร้อมแอปที่ปักหมุดไว้ของคุณ ทุกสิ่งที่กำลังทำงาน และตารางของทุกแอปที่อยู่หลังปุ่มแอป ซึ่ง `Super + Alt + Space` และ _แอป_ ในเมนู Omarchy ก็เปิดเช่นกัน คลิกขวาแอปบนตาราง หรือกด `Delete` เพื่อถอนการติดตั้งมัน คลิกแอปเพื่อเปิดมัน หรือเพื่อนำหน้าต่างของมันมาข้างหน้า คลิกอีกครั้งเพื่อหมุนผ่านหน้าต่างของมัน คลิกกลางเปิดหน้าต่างใหม่ ลากไอคอนไปตาม dock เพื่อย้ายมัน การลากแอปที่กำลังทำงานเข้ามาในหมู่แอปอื่น ๆ จะรักษามันไว้ที่นั่น คลิกขวาเพื่อรักษาแอปใน dock เอามันออก หรือปิดมัน dock จะหลีกทางจากหน้าต่างแบบเต็มหน้าจอ คลิกขวาปุ่มแอปเพื่อย้าย dock ไปยังขอบอื่น หรือให้มันซ่อนไปจนกว่าตัวชี้จะแตะขอบของมัน ตำแหน่งนั้นยังอยู่ภายใต้ _สั่งการ > ลักษณะ > Dock > ตำแหน่ง Dock_ และ `omarchy dock position left` กับ `omarchy dock autohide on` ตั้งทั้งสองอย่างจากเทอร์มินัล แอปที่คุณเก็บใน dock จะจางลงขณะที่พวกมันไม่ได้ทำงาน

พื้นที่งานใหม่ และพื้นที่งานใด ๆ ที่คุณไม่ได้กำหนดเค้าโครงของตัวเองด้วย `Super + L` จะใช้เค้าโครงเริ่มต้น การเปลี่ยนค่าเริ่มต้นจะรีเซ็ตทุกพื้นที่งานที่ไม่มีหน้าต่างไปสู่ค่าเริ่มต้นนั้น ขณะที่พื้นที่งานที่มีหน้าต่างอยู่จะรักษาเค้าโครงที่มันมีไว้ เลือกมันภายใต้ _สั่งการ > ลักษณะ > เค้าโครงพื้นที่งาน_: เรียง เลื่อน หรือลอย `omarchy-hyprland-workspace-layout-default scrolling` ตั้งค่ามันจากเทอร์มินัล

### การจัดกลุ่มหน้าต่าง

หน้าต่างสามารถจัดกลุ่มโดยใช้ `Super + G` เมื่อคุณอยู่ในกลุ่มหนึ่งแล้ว ทุกหน้าต่างที่คุณเปิดขณะที่กลุ่มนั้นใช้งานอยู่จะอยู่ในกลุ่มนั้น คุณสามารถย้ายระหว่างหน้าต่างที่จัดกลุ่มเหล่านี้โดยใช้ `Super + Ctrl + Arrow Left/Right` หรือ `Super + Alt + 1/2/3/4` เพื่อไปยังหน้าต่างในกลุ่มโดยตรงตามลำดับ

คุณสามารถย้ายหน้าต่างออกจากการจัดกลุ่มด้วย `Super + Alt + G` หรือสลายทั้งกลุ่มโดยกด `Super + G` อีกครั้ง สุดท้าย คุณสามารถย้ายหน้าต่างนอกกลุ่มเข้ามาในกลุ่มด้วย `Super + Alt + Arrows`

### การดึงหน้าต่างออก

คุณสามารถดึงหน้าต่างออกจากการจัดสรรพื้นที่งานของมันด้วย `Super + O` นั่นจะปักหมุดมันเป็นหน้าต่างลอยที่ตามคุณไปบนพื้นที่งานใด ๆ ก็ตามที่คุณไป เหมาะมากสำหรับเครื่องเล่นวิดีโอและของราว ๆ นั้น

 ![navigation-popped-window](images/navigation-popped-window.webp)

### พื้นที่งานกระดาษทด

สุดท้าย มีพื้นที่งานกระดาษทดแบบพิเศษที่หล่นลงมาเหนือพื้นที่งานที่คุณกำลังอยู่ คล้ายกับคอนโซล Quake สลับมันด้วย `Super + Grave` หรือ `Super + S` และวางหน้าต่างไว้ที่นั่นโดยใช้ `Super + Shift + Grave` หรือ `Super + Alt + S`

มันใช้ได้ดีเป็นพิเศษสำหรับเทอร์มินัลที่รันเอเจนต์อยู่ หรือสำหรับปุ่มควบคุมที่คุณต้องการโต้ตอบอย่างรวดเร็วโดยไม่ต้องออกจากพื้นที่งานปัจจุบัน หากต้องการย้ายหน้าต่างออกจากกระดาษทด ส่งมันตรงไปยังพื้นที่งานอื่นด้วยอะไรอย่าง `Super + Shift + 1`

ขณะที่กระดาษทดมีหน้าต่างเดียว มันจะหล่นลงมาเป็นแผงที่อยู่ตรงกลางแทนที่จะแผ่เต็มหน้าจอ วางแอปที่สองลงบนมัน แล้วมันจะกลับไปเป็นความกว้างเต็ม เพื่อให้ทั้งสองมีที่วางเคียงข้างกัน

### ต้องใช้เวลาปรับตัวสักหน่อย!

ต้องใช้เวลาสักครู่กว่าจะคุ้นเคยกับการนำทางเดสก์ท็อปของคุณแบบนี้ แต่เมื่อคุณคุ้นเคยแล้ว มันจะยากที่จะกลับไปสู่ประสบการณ์เดสก์ท็อปที่ขับเคลื่อนด้วยเมาส์แบบดั้งเดิม!
