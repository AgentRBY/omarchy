# 탐색

Omarchy의 모든 것은 키보드로 이루어집니다 — _전부요!_ 시스템이 처음 시작될 때는 문자 그대로 마우스만으로는 아무것도 할 수 없습니다. 하지만 `Super + Space`를 눌러 Omarchy 메뉴를 표시하면 거기서 거의 모든 것을 할 수 있습니다.

하지만 Omarchy 메뉴조차 대부분의 시간 동안 시스템을 조작하는 주요 수단으로 의도된 것은 아닙니다. 더 빨라질 수 있습니다! 가장 중요한 애플리케이션들은 모두 개별 단축키에 직접 바인딩되어 있습니다. `Super + Return`으로 터미널을, `Super + Shift + Return`으로 브라우저를 시작합니다. 하나 뒤에 다른 하나를 실행해 보세요. 그러면 Hyprland 타일링의 마법을 직접 보게 됩니다:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

그런 다음 `Super + J`를 눌러 나란히 두는 대신 위아래로 쌓을 수 있습니다:

 ![navigation-stacked](images/navigation-stacked.webp)

`Super + J`를 다시 누르면 나란한 위치로 돌아갑니다. 그런 다음 브라우저에서 `Super + Shift + Arrow Right`를 눌러 창을 맞바꿔 보세요.

이제 `Super + Ctrl + T`를 눌러 Activity 모니터를 시작해 보세요. 플로팅 창으로 나타납니다. `Super + T`를 사용해 타일링할 수 있고(다시 누르면 다시 플로팅이 됩니다). 이제 `Super + Shift + F`를 눌러 파일 관리자를 여세요. 깔끔한 4분할 배치가 됩니다:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

활성화하려는 창 사이는 `Super + Arrow`로 이동합니다. 포커스가 전환되고 커서가 새 애플리케이션의 가운데로 이동합니다.

`Super + Shift + 2`를 누르면 현재 포커스된 애플리케이션이 두 번째 워크스페이스로 이동합니다. `Super + Shift + 1`을 누르면 다시 돌아옵니다. (그리고 `Super + Shift + Alt + 2`는 현재 포커스된 애플리케이션을 그 워크스페이스로 전환하지 않고 두 번째 워크스페이스로 이동시킵니다).

`Super`를 누른 채 마우스로 창을 클릭하면 위치를 재배열할 수 있습니다. `Super`를 누른 채 마우스 오른쪽 버튼을 사용하면 창 크기를 자유롭게 조정할 수 있습니다.

창은 `Super + W`나 `Super + Q`로 닫습니다(모든 창은 `Ctrl + Alt + Delete`로 닫습니다).

`Super + F`로 전체 화면으로 가거나, `Super + Alt + F`로 상단 바를 유지한 채 전체 너비로만 가거나, `Super + Ctrl + F`로 창 안에서 전체 화면으로 갈 수도 있습니다(YouTube에 좋습니다!).

### Dwindle 대 스크롤링 레이아웃

Omarchy의 기본 레이아웃은 dwindle이라고 합니다. 하나의 워크스페이스에서 여는 모든 창을, 크기를 줄여야 하더라도 항상 보이게 유지합니다.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

하지만 창들이 디스플레이의 보이는 가장자리를 넘어 나란히 줄지어 있는 스크롤링 레이아웃으로 워크스페이스를 전환할 수도 있습니다. `Super + L`로 단일 워크스페이스를 이 레이아웃으로 전환합니다.

`Super + L`를 다시 누르면 워크스페이스가 플로팅이 되어 창이 자유롭게 겹치고 직접 배치하게 되며, 세 번째로 누르면 dwindle로 돌아갑니다. `Super + Alt + L`은 반대로 순환합니다. 어차피 플로팅인 창 — `Super + T`로 빼냈거나, 항상 플로팅으로 열리는 앱 — 은 워크스페이스가 타일링으로 돌아가도 계속 플로팅으로 남습니다. 상단 바는 현재 워크스페이스를 그 레이아웃으로 표시합니다. dwindle은 정사각형, 스크롤링은 원, 플로팅은 삼각형입니다. 그 표시를 클릭해도 레이아웃이 순환합니다.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

선택은 워크스페이스별로 이루어지며 유지됩니다. 따라서 워크스페이스 1은 탐색용 dwindle로, 워크스페이스 2는 코드용 스크롤링으로 유지할 수 있으며, 재시작 후에도 그대로 돌아옵니다.

스크롤링 레이아웃을 기본값으로 쓰고 싶다면 `~/.config/hypr/looknfeel.lua`에서 설정할 수 있습니다:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### 플로팅 워크스페이스

플로팅 워크스페이스는 전통적인 데스크톱처럼 작동합니다. 창이 겹치고, 직접 이동하고 크기를 조정합니다. 각 창에는 테마 색상의 제목 표시줄이 있으며, 최소화, 최대화, 닫기 버튼이 있습니다. `Super + M`도 포커스된 창을 최소화합니다. 최소화된 창은 독에서 기다리며, 앱을 클릭하면 다시 돌아옵니다. 창을 클릭하면 앞으로 옵니다. 어느 가장자리나 모서리에서든 크기를 조정할 수 있습니다. 제목 표시줄을 두 번 클릭하면 상단 바를 보이게 유지한 채 창을 최대화하고, 다시 두 번 클릭하면 원래 크기로 돌아옵니다.

플로팅 워크스페이스는 독도 표시합니다. 고정된 앱, 실행 중인 모든 앱, 그리고 앱 버튼 뒤에 있는 모든 앱의 그리드가 있습니다. `Super + Alt + Space`와 Omarchy 메뉴의 _앱_도 이를 엽니다. 그리드에서 앱을 오른쪽 클릭하거나 `Delete`를 누르면 제거합니다. 앱을 클릭하면 열리거나 그 창이 앞으로 오며, 다시 클릭하면 창 사이를 순환합니다. 가운데 클릭은 새 창을 엽니다. 아이콘을 독을 따라 드래그해 이동하세요. 실행 중인 앱을 다른 앱들 사이로 드래그하면 거기에 유지됩니다. 오른쪽 클릭으로 앱을 독에 고정하거나, 빼내거나, 종료할 수 있습니다. 독은 전체 화면 창 앞에서는 물러납니다. 앱 버튼을 오른쪽 클릭하면 독을 다른 가장자리로 이동하거나 포인터가 그 가장자리에 닿을 때까지 숨길 수 있습니다. 위치는 _실행 > 모양 > 독 > 독 위치_에서도 설정할 수 있으며, `omarchy dock position left`와 `omarchy dock autohide on`은 터미널에서 둘 다 설정합니다. 독에 고정해 둔 앱은 실행 중이 아닐 때 흐리게 표시됩니다.

새 워크스페이스와, `Super + L`로 자체 레이아웃을 지정하지 않은 워크스페이스는 기본 레이아웃을 사용합니다. 기본값을 바꾸면 창이 없는 모든 워크스페이스가 그 기본값으로 초기화되며, 창이 있는 워크스페이스는 현재 레이아웃을 유지합니다. _실행 > 모양 > 워크스페이스 레이아웃_에서 타일링, 스크롤링, 플로팅 중에서 고르세요. `omarchy-hyprland-workspace-layout-default scrolling`은 터미널에서 설정합니다.

### 창 그룹화

창은 `Super + G`를 사용해 그룹화할 수 있습니다. 그룹 안에 들어온 뒤에는, 그 상태가 활성화되어 있는 동안 시작하는 모든 창이 그룹에 속하게 됩니다. 그룹화된 창 사이에서는 `Super + Ctrl + Arrow Left/Right`로 이동하거나, `Super + Alt + 1/2/3/4`로 순서대로 해당 그룹 창으로 직접 이동할 수 있습니다.

`Super + Alt + G`로 창을 그룹에서 빼내거나, `Super + G`를 다시 눌러 그룹 전체를 해체할 수 있습니다. 마지막으로 `Super + Alt + Arrows`로 그룹 외부의 창을 그룹 안으로 이동시킬 수 있습니다.

### 창 팝업

`Super + O`로 창을 그 워크스페이스 할당에서 빼낼 수 있습니다. 그러면 어떤 워크스페이스로 가든 따라다니는 플로팅 창으로 고정됩니다. 동영상 플레이어 같은 것에 좋습니다.

 ![navigation-popped-window](images/navigation-popped-window.webp)

### 스크래치패드 워크스페이스

마지막으로, Quake 콘솔처럼 현재 있는 워크스페이스 위로 내려오는 특별한 스크래치패드 워크스페이스가 있습니다. `Super + Grave`나 `Super + S`로 토글하고, `Super + Shift + Grave`나 `Super + Alt + S`로 창을 거기에 배치하세요.

에이전트가 실행 중인 터미널이나, 현재 워크스페이스를 떠나지 않고 빠르게 상호작용하려는 컨트롤에 특히 잘 작동합니다. 창을 스크래치패드에서 꺼내려면 `Super + Shift + 1` 같은 것으로 다른 워크스페이스로 직접 보내세요.

스크래치패드에 단일 창만 있으면 화면 전체를 가로지르지 않고 가운데 패널로 내려옵니다. 두 번째 앱을 거기에 두면 전체 너비로 돌아가 둘 다 나란히 있을 공간이 생깁니다.
