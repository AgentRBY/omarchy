# AI

Omarchy meðhöndlar gervigreindarkóðunar-agents sem fyrsta flokks borgara, en það velur ekki uppáhald fyrir þig. Í staðinn kemur hvert stórt kóðunar-agent CLI fortengt sem letihlaðinn ræsir. Ræsararnir eru agnarsmáir [mise](https://mise.jdx.dev/)-stjórnaðir stubbar í `~/.local/bin/`, svo ekkert er sótt þar til þú keyrir einn í fyrsta skipti í alvöru. Hermes er undantekningin: ekkert er stubbað fyrir hann, og að velja hann setur upp Hermes Desktop, eins og _Skráborðsforrit_ hér að neðan útskýrir. Kallaðu á hvaða sem er af þessum og auðkenndu þig þegar beðið er um það:

| Skipun    | Agent                                                            |
|------------|------------------------------------------------------------------|
| `claude`   | [Claude Code](https://code.claude.com/docs/en/overview)          |
| `codex`    | [OpenAI Codex](https://github.com/openai/codex)                  |
| `opencode` | [OpenCode](https://opencode.ai/)                                 |
| `agy`      | [Google Antigravity CLI](https://github.com/google-antigravity/antigravity-cli) |
| `copilot`  | [GitHub Copilot CLI](https://github.com/github/copilot-cli)      |
| `crush`    | [Crush](https://github.com/charmbracelet/crush)                  |
| `grok`     | [Grok Build](https://x.ai/build) frá xAI                        |
| `pi`       | [Mario Zechner's Pi](https://github.com/badlogic/pi-mono)        |
| `omp`      | [Oh My Pi](https://github.com/can1357/oh-my-pi)                  |
| `ori`      | [Ori](https://openrouter.ai/docs/guides/ori/harness), umhverfi OpenRouter |
| `hermes`   | [Hermes](https://hermes-agent.nousresearch.com/), agent Nous Research  |
| `muse`     | [Muse Code](https://dev.meta.ai), kóðunar-agent Meta           |
| `cursor-agent` | [Cursor CLI](https://cursor.com/cli)                         |

`ori` er sérvitringurinn: hann keyrir hin umhverfin á móti öllum líkanalista OpenRouter, svo `ori claude`, `ori codex` eða `ori opencode` ræsa þá agents á hvaða líkani sem þú bendir þeim á, og `ori code` er eigin agent Ori.

Til að vefja viðbótar-CLI á sama hátt skaltu keyra `omarchy-mise-install <package> [command-name]`. Stubbunum er haldið uppfærðum ásamt öllu öðru sem mise stjórnar þegar þú keyrir `omarchy update` (eða samnefnið `mup`).

`grok` er sett upp í gegnum fyrsta flokks `grok`-pakka mise, á sama hátt og `claude` og `codex`. Keyrðu `grok`, eða veldu hann undir _Uppsetning > Sjálfgildi > Agent_. Slepptu `curl | bash`-uppsetningarforritinu á x.ai. Sú leið setur annað eintak í `~/.grok/bin`, setur það fremst á `PATH` og yfirskrifar umbúðir Omarchy.

### Sjálfgefinn agent

Veldu sjálfgefna agentinn þinn með `omarchy default agent <name>` eða undir _Uppsetning > Sjálfgildi > Agent_ í Omarchy-valmyndinni (`Super + Space`). Ef agentinn er ekki uppsettur enn setur valið hann upp fyrst. Nýtt Omarchy býður þér að taka þetta val með einnota tilkynningu.

Að velja Claude reynir líka að setja upp vafraviðbótina hans fyrir Chromium, Chrome, Brave, Brave Origin og Edge. Uppsetning viðbótarinnar á við um alla notendur og gæti beðið um kerfislykilorðið þitt; að aflýsa eða misheppnuð uppsetning viðbótar velur og ræsir samt Claude. Endurræstu vafrann þinn, virkjaðu viðbótina ef beðið er um það og skráðu þig inn í Claude til að ljúka tengingunni. Keyrðu `/chrome` í Claude til að athuga tenginguna. Firefox og Zen styðja ekki þessa viðbót. Ef Claude var þegar sjálfgefinn hjá þér áður en þessari uppsetningu var bætt við skaltu velja hann aftur til að setja upp viðbótina.

[Muse Code](https://dev.meta.ai) — `muse` frá Meta — notar foruppsettan mise-stubb eins og hinir agents. Að velja hann sem sjálfgefinn setur upp opinbera ræsir Meta í gegnum HTTP-bakenda mise. Ræsirinn sannreynir og uppfærir innfæddu tvíundarskrána fyrir vélina þína.

Þegar þú hefur valið ræsir `Super + Shift + Ctrl + A` sjálfgefna agentinn í sérstökum terminal-glugga (eða birtir veljarann ef þú hefur ekki valið enn). Þú getur líka ræst hann beint í verkefni með `omarchy agent prompt "Review this project"`. Agents sem eru ræstir svona keyra eftirlitslaust í sínum eigin ekki-stöðva-til-að-spyrja ham, svo vertu tilbúinn fyrir að þeir geri hluti í alvöru! Og þar sem agents neita að muna traust fyrir heimilismöppuna þína byrja ræsingar frá `$HOME` í `~/Work` í staðinn.

Það eru til terminal-flýtivísanir líka: `a` keyrir sjálfgefna agentinn innfellt í núverandi terminal, á meðan `c`, `cx` og `cy` ræsa OpenCode, Claude Code og Codex beint (aftur í sjálfsamþykkisham þeirra). Þemabreytingar samstillast við agents líka: Claude Code, Pi, OpenCode og Hermes (þegar Omarchy hefur sett hann upp) fylgja öll með þegar þú skiptir um Omarchy-þema.

### Agents-spjaldið

Valmyndastikan er með agents-tákn. Áður en þú hefur sett upp agent leiðir spjald hans þig í gegnum innskráningu í Claude, Codex eða Grok, og sá fyrsti verður sjálfgefinn agentinn þinn. Eftir það setur spjaldið hverja áskrift á eina síðu: hvern agent og reikning með áætlun hans, mæli fyrir 5 klukkustunda lotu- og vikuleg mörk hans með tímanum þar til hann endurstillist (sveimðu fyrir nákvæmt hlutfall), eða afgang af fyrirframgreiddri stöðu, undir línu sem rúllar í gegnum það sem þú hefur notað í þeim öllum, eins og tákn þessa vikuna og mest notaða líkanið þitt. Undir _Make something_ býður það upp á byrjunarfyrirmæli fyrir nýtt þema, viðbót eða forrit sem afhenda verkefnið til sjálfgefna agentsins þíns. Forrit eru byggð eins og Hype, Monologue og Omacut frá Omarchy sjálfu, í C++ og Qt Quick, samkvæmt omarchy-app agent-færninni, og þýðandinn og Qt-hlutarnir sem þau þurfa fylgja með uppsettir. Claude Code, Codex, Grok og Fireworks eru studd úr kassanum.

Vinstrismelltu á táknið í stikunni fyrir spjaldið, hægrismelltu til að ræsa sjálfgefna agentinn þinn. Notkunarskrárnar þar á bak við eru endurskapaðar á 15 mínútna fresti af `omarchy agent usage-update`, og spjaldið getur jafnvel sameinað notkun frá öðrum vélunum þínum í gegnum samstillta möppu. Sjá README undir `$OMARCHY_PATH/shell/plugins/agents/` fyrir allar stillingar.

### Nokkrar áskriftir

Ef þú borgar fyrir fleiri en eina Claude-, Codex- eða Grok-áætlun — persónulega Max og eina í vinnunni, segjum — getur Omarchy haldið þeim öllum innskráðum og fært sig á milli þeirra. Bættu við áskrift með + í agents-spjaldinu, sem leiðir þig í gegnum það þar og þá, eða með `omarchy agent account add claude Work` (eða `codex`, eða `grok`). Það setur upp CLI-ið ef það vantar. Fyrsti reikningurinn hjá veitu skráir sig inn í gegnum venjulega vafrann þinn, nákvæmlega þar sem CLI-ið leitar alltaf. Sérhver reikningur eftir það skráir sig inn í gegnum einkaglugga, svo reikningurinn sem vafrinn þinn er þegar innskráður á sé ekki tekinn upp fyrir mistök; skráðu þig inn þar sem reikningurinn sem þú ert að bæta við og lokaðu öllum einkagluggum sem þú hafðir þegar opna fyrst. Skráðu þig aldrei út úr CLI-inu til að gera þetta: útskráning afturkallar vistaða innskráningu og þann reikning þyrfti að bæta við aftur.

Einn reikningur á hverja veitu er virkur, og hver ný lota byrjar sem hann: `cx`, `cy`, venjulegt `claude`, `codex` eða `grok`, allt sem er ræst í gegnum `omarchy agent`, og forskriftir eða ritlar sem finna CLI-ið á `PATH`. Skiptu með `omarchy agent account use work` (og til baka með `omarchy agent account use main`), eða í spjaldinu með því að ýta á númer reiknings og síðan `Enter` (eða smella á Notkun-hnappinn hans). Lotur sem eru þegar í gangi haldast á reikningnum sem þær byrjuðu á. Samtalasögu, stillingum, færni og viðbótum er deilt á milli reikninga, svo `claude --continue` í sömu möppu heldur áfram þar sem frá var horfið á nýja reikningnum.

Með fleiri en einum reikningi sýnir spjaldið mörk hvers reiknings hlið við hlið, með virka reikninginn merktan. Sjálfgefið lætur Omarchy þig vita þegar virki reikningurinn fer yfir 95% af marki, og að smella á tilkynninguna skiptir yfir á reikninginn með mest laust pláss. Sveimðu yfir línu reiknings í spjaldinu og smelltu á Sjálfskipting sem birtist við hlið Notkun (eða ýttu á `m`), eða keyrðu `omarchy agent account mode auto`, til að láta hann skipta sjálfur í staðinn; á meðan það er á tekur Sjálfskipting sæti Notkunar, og að smella á hana aftur fer aftur í að tilkynna. Bættu við tölu til að breyta þröskuldinum, eins og í `omarchy agent account mode auto 90`. Ef hver reikningur er yfir þröskuldinum heyrirðu af því einu sinni, ásamt því hvaða reikningur losnar fyrst. Á meðan virkur reikningur er innan 15 stiga frá þröskuldinum sínum (80% sjálfgefið) eru mörk hans athuguð á þriggja mínútna fresti frekar en 15.

`omarchy agent account list` sýnir hvern reikning og nýjustu mörk hans, `omarchy agent account remove work` gleymir einum og `omarchy agent account rename primary Hey` endurnefnir einn (eða smelltu á nafn reiknings í spjaldinu). Þessar skipanir virka á reikninga sjálfgefna agentsins þíns; til að ná til hinnar veitunnar skaltu nefna hana fyrst, eins og í `omarchy agent account use codex side`. Innskráningin sem þú hafðir þegar í `~/.claude` eða `~/.codex` er _Aðal_-reikningurinn og helst þar sem hann er. Reikningur sem er ónotaður í meira en um átta klukkustundir getur sýnt _Innskráning þörf_; smelltu á hann til að skrá þann reikning inn aftur beint í spjaldinu, eða byrjaðu lotu í honum, sem endurnýjar innskráninguna sjálf. MCP-netþjónar sem þú hafðir þegar reikningi var bætt við fylgja honum, en þeir sem þú bætir við síðar með `claude mcp add` ná aðeins til reikningsins sem þú bættir þeim við í. Claude Desktop og verkfæri stillt með algerri slóð að CLI-tvínunni fylgja ekki skiptingunni. Skýrt `CLAUDE_CONFIG_DIR`, `CODEX_HOME` eða `GROK_HOME` hefur forgang fram yfir valinn reikning.

### Hrungreining

Omarchy fylgist með systemd-coredump eftir ferlahrunum. Þegar eitthvað hrynur (segfault) færðu „Process crashed“-tilkynningu — smelltu á hana og hrunið er afhent sjálfgefna agentinum þínum ásamt diagnose-crash-færni Omarchy, sem leiðir agentinn í gegnum það að staðfesta staðreyndirnar út frá kjarnadumpinum og ákveða hvort hrunið sé þess virði að tilkynna uppstreymis. Þú getur líka keyrt það handvirkt á móti hvaða PID sem er úr `coredumpctl list` með `omarchy agent crash <pid>`.

Eftirlitið er á sjálfgefið. Slökktu á því undir _Kveikja > Víxla > Hrungrip_ (eða með `omarchy toggle crash-capture`) og tilkynningarnar hætta; `omarchy agent crash <pid>` virkar samt handvirkt.

Einnig er hægt að þagga hrun eitt forrit í senn, sem er það sem greiningin býður þér í lokin. `omarchy crash mute hyprland` stöðvar tilkynningarnar fyrir það forrit eitt, `omarchy crash mute hyprland off` færir þær til baka, og `omarchy crash mute` eitt og sér listar það sem þú hefur þaggað. Það tekur slóð tvíundarinnar jafnglaðlega og nafn hennar, svo `omarchy crash mute /usr/bin/hyprland` gerir það sama. Setja nafn með bili í gæsalappir, eins og í `omarchy crash mute 'Some App'`. Allt annað tilkynnir enn, og þaggaða forritið hrynur enn — þetta felur áminninguna, það lagar ekkert.

### Skjáborðsforrit

Valmyndin _Setja upp > AI_ ber líka nokkur myndræn gervigreindarforrit: ChatGPT-skjáborðsforritið, Claude-skjáborðsforritið (Linux-beta Anthropic, með Chat-, Cowork- og Claude Code-flipum), Grok Bot til að spjalla við líkön xAI, Hermes Desktop, OpenClaw og Perplexity-skjáborðsforritið. Grok Bot er skjáborðsspjallforritið. Kóðunar-agentinn er `grok`-skipunin.

Hermes Desktop er sá sem vert er að þekkja, þar sem vél hefur einn Hermes, og hann er forritsins: Hermes er aðeins nokkurn tímann settur upp í gegnum forritið, og `hermes`-skipunin sem sjálfgefinn agent keyrir er forritsins. Að velja Hermes sem sjálfgefinn agent setur upp sama hlutinn og færslan _Setja upp > AI_ gerir: pakkann og Hermes-keyrsluumhverfi undir `~/.hermes` sem eigið uppsetningarforrit Hermes setur upp, sem tekur nokkrar mínútur í fyrsta skipti. Það keyrsluumhverfi er sá eini Hermes sem terminal-`hermes`-skipunin, sjálfgefinn agentinn og forritið nota öll, og það uppfærir sig sjálft með `hermes update` frekar en að bíða eftir Omarchy-útgáfu. Að setja það upp afhendir Hermes einnig Omarchy-þemað sem útlit (skin) sem heitir `omarchy`, sem sérhver Hermes-flötur fylgir þegar þú skiptir um þemu; veldu annað undir Appearance-stillingum Hermes eða með `/skin` ef þú vilt frekar að það geri það ekki, og Omarchy lætur það val í friði. Að fjarlægja forritið undir _Fjarlægja > AI_ lokar Hermes fyrst, gáttinni innifalinni, tekur það keyrsluumhverfi með sér og heldur spjöllunum þínum, minningunum og færninni sem Hermes skrifaði fyrir sjálfan sig nema þú segir annað: það spyr, sjálfgefið nei, hvort þau gögn og tengistillingar þínar eigi að fara með.

Skrjáborðsupplifun OpenClaw er Control UI hennar, sem opnast sem vefforrit með eigin staðbundinni gátt á bak við sig. OpenClaw býr í `~/.openclaw` og uppfærir sig sjálft: notaðu „Update Gateway“-hnapp Control UI eða keyrðu `openclaw update`, og gáttin endurræsist á nýju útgáfunni. Omarchy velur aðeins þá útgáfu sem ný uppsetning byrjar á. Að fjarlægja OpenClaw undir _Fjarlægja > AI_ tekur gáttarþjónustuna og forritið með sér og spyr síðan hvort `~/.openclaw` eigi að fara með líka, þar sem það geymir spjöllin þín og skilríki ásamt OpenClaw sjálfu og viðbótarkeyrsluumhverfunum sem það sækir; sjálfgefið heldur því, og að setja OpenClaw upp aftur tekur það upp aftur.

### Staðbundin LLM

Omarchy mælir með tveimur leiðum til að keyra staðbundin LLM-líkön: LM Studio og Ollama. LM Studio veitir GUI-viðmót til að finna opin líkön, setja þau upp og keyra þau. Það er frábær leið til að komast auðveldlega af stað. Ollama býður upp á CLI til að gera slíkt á svipaðan hátt. En ef þú ert nýr í staðbundnum líkönum myndi ég byrja á LM Studio. Þú getur sett hvort sem er upp undir _Setja upp > AI_ í Omarchy-valmyndinni.

### Omarchy-færnin

Agent-færni hjálpar gervigreind að nota ákveðin verkfæri á ákveðinn hátt, og Omarchy kemur með sjálfgefna færni til að sníða kerfið. Eins og að stilla Hyprland-stillinguna þína, aðlaga stikuna eða jafnvel búa til nýtt þema frá grunni. Henni er tengt táknrænt (symlink) inn í færnimöppurnar fyrir Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` og hverja `~/.hermes/profiles/*/skills`) og almennu `~/.agents/skills`-staðsetninguna, svo flest umhverfi taka hana upp sjálfkrafa.

En þú ættir að meðhöndla þessa færni sem tilraunakennda. Mismunandi líkön nota hana með mismunandi árangri. Best er að keyra í áætlunarham fyrst, svo þú hafir hugmynd um hvað agentinn vill breyta. Og vertu síðan tilbúinn að afturkalla breytingar eða jafnvel kalla fram `omarchy reinstall configs` ef agentinn gerir allt í rugli.
