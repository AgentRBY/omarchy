# வழிசெலுத்தல்

Omarchy-இல் எல்லாம் விசைப்பலகை வழியாக நடக்கிறது — _எல்லாம்!_ அமைப்பு முதலில் தொடங்கும் போது, ​​உண்மையில் சுட்டி மட்டுமே கொண்டு எதுவும் செய்ய முடியாது. ஆனால் Omarchy மெனுவை வெளிப்படுத்த `Super + Space` ஐ அழுத்தலாம் மற்றும் இங்கிருந்து கிட்டத்தட்ட எல்லாவற்றையும் செய்யலாம்.

ஆனால் Omarchy மெனு பெரும்பாலான நேரங்களில் அமைப்பை இயக்குவதற்கான முக்கிய வழியாகக் கூட இருக்க வேண்டியதில்லை. அதை விட வேகமாகச் செல்லலாம்! அனைத்து முக்கியமான பயன்பாடுகளும் நேரடியாக தனிப்பட்ட ஹாட்கீகளுடன் பிணைக்கப்பட்டுள்ளன. நீங்கள் `Super + Return` மூலம் டெர்மினலைத் தொடங்குகிறீர்கள் மற்றும் `Super + Shift + Return` மூலம் ஒரு உலாவியைத் தொடங்குகிறீர்கள். ஒன்றன் பிறகு மற்றொன்றைச் செய்து பாருங்கள், Hyprland-இன் அடுக்கின் மந்திரத்தைச் செயலில் பார்ப்பீர்கள்:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

பிறகு அவற்றை பக்கத்திலிருந்து பக்கத்திற்கு பதிலாக ஒன்றன் மேல் ஒன்றாக அடுக்க `Super + J` ஐ அழுத்தலாம்:

 ![navigation-stacked](images/navigation-stacked.webp)

அவற்றை அவற்றின் பக்கத்திலிருந்து பக்க நிலைகளுக்குத் திருப்ப `Super + J` ஐ மீண்டும் அழுத்தவும். பிறகு உலாவியில் இருக்கும் போது சாளரங்களை மாற்ற `Super + Shift + Arrow Right` ஐ முயற்சிக்கவும்.

இப்போது செயல்பாட்டு மானிட்டரைத் தொடங்க `Super + Ctrl + T` ஐ முயற்சிக்கவும். அது ஒரு மிதக்கும் சாளரமாகத் தோன்றும். `Super + T` ஐப் பயன்படுத்தி அதை அடுக்கலாம் (மற்றும் அதை மீண்டும் மிதக்க வைக்க அதை மீண்டும் அழுத்தவும்). இப்போது கோப்புகள் மேலாளரைத் திறக்க `Super + Shift + F` ஐ அழுத்தவும். உங்களிடம் ஒரு நேர்த்தியான நான்கு-வழி அமைப்பு இருக்கும்:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

`Super + Arrow` மூலம் நீங்கள் செயலில் இருக்க விரும்பும் சாளரங்களுக்கு இடையே வழிசெலுத்துகிறீர்கள். இது கவனத்தை மாற்றி கர்சரை புதிய பயன்பாட்டின் மையத்திற்கு நகர்த்தும்.

`Super + Shift + 2` ஐ அழுத்தினால், தற்போது கவனம் செலுத்தப்பட்ட பயன்பாட்டை இரண்டாவது பணியிடத்திற்கு நகர்த்துவீர்கள். `Super + Shift + 1` அதைத் திரும்ப நகர்த்துகிறது. (மேலும் `Super + Shift + Alt + 2` தற்போது கவனம் செலுத்தப்பட்ட பயன்பாட்டை அதற்கு மாறாமல் இரண்டாவது பணியிடத்திற்கு நகர்த்தும்).

நீங்கள் `Super` ஐப் பிடித்து, ஒரு சாளரத்தில் கிளிக் செய்ய சுட்டியைப் பயன்படுத்தினால், அது எங்கே அமர்ந்திருக்கிறது என்பதை மறுஒழுங்கமைக்க முடியும். `Super` ஐப் பிடித்து சுட்டியில் வலது பொத்தானைப் பயன்படுத்தினால், சாளரத்தை சுதந்திரமாக மறுஅளவிடலாம்.

`Super + W` அல்லது `Super + Q` இல் ஒரு சாளரத்தை மூடுகிறீர்கள் (மற்றும் `Ctrl + Alt + Delete` இல் அனைத்து சாளரங்களையும் மூடுகிறீர்கள்).

`Super + F` மூலம் முழுத் திரைக்கும் செல்லலாம் அல்லது `Super + Alt + F` மூலம் முழு-அகலத்திற்கு (மேல் பட்டையை வைத்திருத்தல்) செல்லலாம் அல்லது `Super + Ctrl + F` மூலம் ஒரு சாளரத்திற்குள் முழுத் திரைக்கும் செல்லலாம் (YouTube-க்கு நல்லது!).

### Dwindle vs உருட்டல் தளவமைப்பு

Omarchy-இன் இயல்புநிலை தளவமைப்பு dwindle என்று அழைக்கப்படுகிறது. நீங்கள் ஒரு ஒற்றை பணியிடத்தில் திறக்கும் அனைத்து சாளரங்களையும் எல்லா நேரமும் காணக்கூடியதாக இது வைத்திருக்கிறது, அவற்றைச் சுருக்க வேண்டியிருந்தாலும் கூட.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

ஆனால் நீங்கள் ஒரு பணியிடத்தை உருட்டல் தளவமைப்பாக மாற்றவும் தேர்வு செய்யலாம், அங்கு சாளரங்கள் பக்கத்திலிருந்து பக்கமாக வரிசையாக அமைக்கப்பட்டுள்ளன, காட்சியின் காணக்கூடிய விளிம்புக்கு அப்பால். `Super + L` வழியாக ஒரு ஒற்றை பணியிடத்தை இந்த தளவமைப்பாக மாற்றுகிறீர்கள்.

`Super + L` ஐ மீண்டும் அழுத்துவது பணியிடத்தை மிதக்க வைக்கிறது, அங்கு சாளரங்கள் சுதந்திரமாக ஒன்றுடன் ஒன்று மேற்பொருந்துகின்றன மற்றும் நீங்களே அவற்றை வைக்கிறீர்கள், மேலும் மூன்றாவது அழுத்தம் அதை dwindle-க்குத் திருப்புகிறது. `Super + Alt + L` அவற்றின் வழியாக மற்ற திசையில் செல்கிறது. எப்படியிருந்தாலும் மிதக்கும் ஒரு சாளரம் — `Super + T` மூலம் நீங்கள் வெளியே எடுத்த ஒன்று, அல்லது எப்போதும் மிதந்து திறக்கும் ஒரு செயலி — பணியிடம் அடுக்கிற்குத் திரும்பும் போது மிதந்து கொண்டே இருக்கும். மேல் பட்டை நீங்கள் இருக்கும் பணியிடத்தை அதன் தளவமைப்புடன் குறிக்கிறது: dwindle-க்கு ஒரு சதுரம், உருட்டலுக்கு ஒரு வட்டம், மற்றும் மிதப்பதற்கு ஒரு முக்கோணம். அந்தக் குறியைக் கிளிக் செய்வதும் தளவமைப்பைச் சுழற்றுகிறது.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

தேர்வு பணியிடத்திற்கு ஒன்று, மேலும் அது நிலைத்திருக்கும். எனவே நீங்கள் பணியிடம் 1 ஐ உலாவுவதற்கு dwindle-இலும் பணியிடம் 2 ஐ குறியீட்டிற்கு உருட்டலிலும் வைத்திருக்கலாம், மேலும் அவை மறுதொடக்கத்திற்குப் பிறகு அப்படியே திரும்பி வரும்.

உருட்டல் தளவமைப்பை இயல்புநிலையாகப் பயன்படுத்த விரும்பினால், அதை `~/.config/hypr/looknfeel.lua` இல் அமைக்கலாம்:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### மிதக்கும் பணியிடங்கள்

ஒரு மிதக்கும் பணியிடம் ஒரு பாரம்பரிய டெஸ்க்டாப் போல வேலை செய்கிறது: சாளரங்கள் ஒன்றுடன் ஒன்று மேற்பொருந்துகின்றன, மேலும் நீங்களே அவற்றை நகர்த்தி அளவிடுகிறீர்கள். ஒவ்வொரு சாளரமும் உங்கள் தீமின் வண்ணங்களில் ஒரு தலைப்புப் பட்டையைப் பெறுகிறது, சிறிதாக்க, பெரிதாக்க, மற்றும் மூடுவதற்கான பொத்தான்களுடன். `Super + M` கவனம் செலுத்தப்பட்ட சாளரத்தையும் சிறிதாக்குகிறது. ஒரு சிறிதாக்கப்பட்ட சாளரம் dock-இல் காத்திருக்கிறது; அதைத் திரும்பக் கொண்டுவர அதன் செயலியைக் கிளிக் செய்யவும். ஒரு சாளரத்தை முன்னால் கொண்டுவர அதைக் கிளிக் செய்யவும். எந்த விளிம்பு அல்லது மூலையிலிருந்தும் அதை மறுஅளவிடவும். மேல் பட்டையைப் பார்வையில் வைத்துக் கொண்டு சாளரத்தைப் பெரிதாக்க ஒரு தலைப்புப் பட்டையை இரட்டை-கிளிக் செய்யவும், மேலும் அதன் பழைய அளவைத் திரும்பப் பெற மீண்டும் செய்யவும்.

ஒரு மிதக்கும் பணியிடம் ஒரு dock-ஐயும் காட்டுகிறது, உங்கள் பொருத்தப்பட்ட செயலிகள், இயங்கும் அனைத்தும், மற்றும் செயலிகள் பொத்தானுக்குப் பின்னால் உள்ள ஒவ்வொரு செயலியின் கட்டத்துடன், இதை `Super + Alt + Space` மற்றும் Omarchy மெனுவில் _செயலிகள்_ கூட திறக்கின்றன. கட்டத்தில் ஒரு செயலியை வலது-கிளிக் செய்யவும், அல்லது `Delete` ஐ அழுத்தவும், அதை நிறுவல் நீக்க. ஒரு செயலியைத் திறக்க, அல்லது அதன் சாளரத்தை முன்னால் கொண்டுவர அதைக் கிளிக் செய்யவும்; அதன் சாளரங்கள் வழியாகச் சுழற்ற மீண்டும் கிளிக் செய்யவும். நடு-கிளிக் ஒரு புதிய சாளரத்தைத் திறக்கிறது. dock வழியாக ஒரு ஐகானை நகர்த்த அதை இழுக்கவும்; இயங்கும் ஒரு செயலியை மற்றவற்றுக்கு இடையே இழுப்பது அதை அங்கே வைத்திருக்கிறது. dock-இல் ஒரு செயலியை வைத்திருக்க, அதை வெளியே எடுக்க, அல்லது அதை விட்டு வெளியேற வலது-கிளிக் செய்யவும். dock ஒரு முழுத்திரை சாளரத்தின் வழியிலிருந்து விலகுகிறது. dock-ஐ வேறொரு விளிம்பிற்கு நகர்த்த அல்லது சுட்டி அதன் விளிம்பை அடையும் வரை அதை மறைக்க செயலிகள் பொத்தானை வலது-கிளிக் செய்யவும். நிலை _தூண்டு > தோற்றம் > Dock > Dock நிலை_ இன் கீழும் உள்ளது, மேலும் `omarchy dock position left` மற்றும் `omarchy dock autohide on` ஒரு டெர்மினலிலிருந்து இரண்டையும் அமைக்கின்றன. நீங்கள் dock-இல் வைத்திருக்கும் செயலிகள் அவை இயங்காத போது மங்கலாக இருக்கும்.

புதிய பணியிடங்கள், மற்றும் `Super + L` மூலம் நீங்கள் சொந்தமாக ஒரு தளவமைப்பைக் கொடுக்காத எந்தவொன்றும், இயல்புநிலை தளவமைப்பைப் பயன்படுத்துகின்றன. இயல்புநிலையை மாற்றுவது சாளரங்கள் இல்லாத ஒவ்வொரு பணியிடத்தையும் அதற்கு மீட்டமைக்கிறது, அதே நேரத்தில் சாளரங்கள் உள்ள ஒன்று அதற்கு உள்ள தளவமைப்பை வைத்திருக்கிறது. _தூண்டு > தோற்றம் > பணியிட அமைப்பு_ இன் கீழ் அதைத் தேர்ந்தெடுக்கவும்: அடுக்குதல், உருட்டுதல், அல்லது மிதக்கும். `omarchy-hyprland-workspace-layout-default scrolling` ஒரு டெர்மினலிலிருந்து அதை அமைக்கிறது.

### சாளரங்களைக் குழுவாக்குதல்

`Super + G` ஐப் பயன்படுத்தி சாளரங்களைக் குழுவாக்கலாம். நீங்கள் ஒரு குழுவில் இருந்ததும், அது செயலில் இருக்கும் போது நீங்கள் தொடங்கும் ஒவ்வொரு சாளரமும் குழுவைச் சேர்ந்ததாக இருக்கும். `Super + Ctrl + Arrow Left/Right` அல்லது `Super + Alt + 1/2/3/4` ஐப் பயன்படுத்தி இந்தக் குழுப்படுத்தப்பட்ட சாளரங்களுக்கு இடையே வரிசையில் நேரடியாகக் குழுப்படுத்தப்பட்ட சாளரத்திற்குச் செல்லலாம்.

`Super + Alt + G` மூலம் ஒரு சாளரத்தைக் குழுவிலிருந்து வெளியே நகர்த்தலாம் அல்லது `Super + G` ஐ மீண்டும் அழுத்துவதன் மூலம் முழு குழுவையும் பிரிக்கலாம். இறுதியாக, `Super + Alt + Arrows` மூலம் குழுவிற்கு வெளியே உள்ள சாளரங்களை அதற்குள் நகர்த்தலாம்.

### சாளரங்களை வெளியேற்றுதல்

`Super + O` மூலம் ஒரு சாளரத்தை அதன் பணியிட ஒதுக்கீட்டிலிருந்து வெளியேற்றலாம். அது அதை நீங்கள் செல்லும் எந்த பணியிடத்திலும் உங்களைப் பின்தொடரும் ஒரு மிதக்கும் சாளரமாகப் பொருத்தும். வீடியோ பிளேயர்கள் போன்றவற்றிற்கு சிறந்தது.

### ஸ்கிராட்ச்பேட் பணியிடம்

இறுதியாக, நீங்கள் தற்போது இருக்கும் எந்த பணியிடத்தின் மீதும் கீழே விழும் ஒரு சிறப்பு ஸ்கிராட்ச்பேட் பணியிடம் உள்ளது, ஒரு Quake கன்சோல் போலவே. `Super + Grave` அல்லது `Super + S` மூலம் அதை மாற்றவும், மற்றும் `Super + Shift + Grave` அல்லது `Super + Alt + S` ஐப் பயன்படுத்தி அங்கே ஒரு சாளரத்தை வைக்கவும்.

ஒரு Agent-ஐ இயக்கும் டெர்மினலுக்கு, அல்லது தற்போதைய பணியிடத்தை விட்டு வெளியேறாமல் விரைவாகத் தொடர்பு கொள்ள விரும்பும் கட்டுப்பாடுகளுக்கு இது குறிப்பாக நன்றாக வேலை செய்கிறது. ஒரு சாளரத்தை ஸ்கிராட்ச்பேடிலிருந்து நகர்த்த, `Super + Shift + 1` போன்ற ஒன்றைக் கொண்டு அதை நேரடியாக வேறொரு பணியிடத்திற்கு அனுப்பவும்.

ஸ்கிராட்ச்பேட் ஒரு ஒற்றை சாளரத்தை வைத்திருக்கும் போது, ​​அது திரையை விரிப்பதற்கு பதிலாக ஒரு மைய பேனலாகக் கீழே விழுகிறது. அதில் ஒரு இரண்டாவது செயலியை வைக்கவும், அது முழு அகலத்திற்குத் திரும்புகிறது, எனவே இரண்டிற்கும் பக்கத்திலிருந்து பக்கமாக அமர இடம் உள்ளது.

### பழக சிறிது நேரம் எடுக்கும்!

உங்கள் டெஸ்க்டாப்பை இப்படி வழிசெலுத்தப் பழக சிறிது நேரம் எடுக்கும், ஆனால் நீங்கள் பழகியதும், பாரம்பரிய சுட்டி-இயக்கப்படும் டெஸ்க்டாப் அனுபவத்திற்குத் திரும்புவது கடினமாக இருக்கும்!
