# AI

Omarchy AI குறியீட்டு Agent-களை முதல்-வகுப்பு குடிமக்களாகக் கருதுகிறது, ஆனால் அது உங்களுக்காக ஒரு பிடித்ததைத் தேர்ந்தெடுக்காது. அதற்கு பதிலாக, ஒவ்வொரு முக்கிய குறியீட்டு-Agent CLI-யும் சோம்பேறித்தனமாக ஏற்றப்பட்ட தொடக்கியாக முன்கூட்டியே இணைக்கப்பட்டு வருகிறது. தொடக்கிகள் `~/.local/bin/` இல் உள்ள சிறிய [mise](https://mise.jdx.dev/)-நிர்வகிக்கப்படும் ஸ்டப்கள், எனவே நீங்கள் உண்மையில் ஒன்றை முதல் முறையாக இயக்கும் வரை எதுவும் பதிவிறக்கப்படாது. Hermes விதிவிலக்கு: அதற்காக எதுவும் ஸ்டப் செய்யப்படவில்லை, மேலும் அதைத் தேர்ந்தெடுப்பது Hermes Desktop-ஐ நிறுவுகிறது, கீழே உள்ள _டெஸ்க்டாப் செயலிகள்_ விளக்குவது போல. இவற்றில் எதையும் அழைத்து, கேட்கப்படும் போது அங்கீகரிக்கவும்:

| கட்டளை    | Agent                                                            |
|------------|------------------------------------------------------------------|
| `claude`   | [Claude Code](https://code.claude.com/docs/en/overview)          |
| `codex`    | [OpenAI Codex](https://github.com/openai/codex)                  |

| `agy`      | [Google Antigravity CLI](https://github.com/google-antigravity/antigravity-cli) |

| `crush`    | [Crush](https://github.com/charmbracelet/crush)                  |
| `grok`     | xAI-இலிருந்து [Grok Build](https://x.ai/build)                        |
| `pi`       | [Mario Zechner-இன் Pi](https://github.com/badlogic/pi-mono)        |
| `omp`      | [Oh My Pi](https://github.com/can1357/oh-my-pi)                  |
| `ori`      | [Ori](https://openrouter.ai/docs/guides/ori/harness), OpenRouter-இன் ஹார்னஸ் |

`ori` வித்தியாசமானது: இது OpenRouter-இன் முழு மாதிரி பட்டியலுக்கு எதிராக மற்ற ஹார்னஸ்களை இயக்குகிறது, எனவே `ori claude`, `ori codex`, அல்லது `ori opencode` நீங்கள் சுட்டிக்காட்டும் எந்த மாதிரியிலும் அந்த Agent-களைத் தொடங்குகின்றன, மேலும் `ori code` என்பது Ori-இன் சொந்த Agent.

அதே வழியில் ஒரு கூடுதல் CLI-ஐச் சுற்ற, `omarchy-mise-install <package> [command-name]` ஐ இயக்கவும். நீங்கள் `omarchy update` (அல்லது `mup` மாற்றுப்பெயர்) ஐ இயக்கும் போது mise நிர்வகிக்கும் மற்ற அனைத்துடனும் ஸ்டப்கள் புதுப்பித்த நிலையில் வைக்கப்படுகின்றன.

`grok` என்பது mise-இன் முதல்-தரப்பு `grok` தொகுப்பு மூலம் நிறுவப்படுகிறது, `claude` மற்றும் `codex` போலவே. `grok` ஐ இயக்கவும், அல்லது _அமைப்பு > இயல்புநிலைகள் > Agent_ இன் கீழ் அதைத் தேர்ந்தெடுக்கவும். x.ai-இல் `curl | bash` நிறுவியைத் தவிர்க்கவும். அந்தப் பாதை `~/.grok/bin` இல் இரண்டாவது நகலை வைக்கிறது, அதை `PATH` இல் முன்னிறுத்துகிறது, மேலும் Omarchy-இன் ராப்பரை மேலெழுதுகிறது.

### இயல்புநிலை Agent

`omarchy default agent <name>` மூலம் அல்லது Omarchy மெனுவில் (`Super + Space`) _அமைப்பு > இயல்புநிலைகள் > Agent_ இன் கீழ் உங்கள் இயல்புநிலை Agent-ஐத் தேர்ந்தெடுக்கவும். Agent இன்னும் நிறுவப்படவில்லை என்றால், அதைத் தேர்ந்தெடுப்பது முதலில் அதை நிறுவுகிறது. ஒரு புதிய Omarchy ஒரு முறை அறிவிப்புடன் இந்தத் தேர்வைச் செய்ய உங்களை அழைக்கும்.

Claude-ஐத் தேர்ந்தெடுப்பது Chromium, Chrome, Brave, Brave Origin, மற்றும் Edge க்காக அதன் உலாவி நீட்டிப்பை அமைக்கவும் முயற்சிக்கிறது. நீட்டிப்பு அமைப்பு அனைத்து பயனர்களுக்கும் பொருந்தும் மற்றும் உங்கள் கணினி கடவுச்சொல்லைக் கேட்கலாம்; ரத்து செய்வது அல்லது தோல்வியடைந்த நீட்டிப்பு நிறுவல் இன்னும் Claude-ஐத் தேர்ந்தெடுத்துத் தொடங்குகிறது. உங்கள் உலாவியை மறுதொடக்கம் செய்யவும், கேட்கப்பட்டால் நீட்டிப்பை இயக்கவும், மேலும் அதை இணைப்பதை முடிக்க Claude-இல் உள்நுழையவும். இணைப்பைச் சரிபார்க்க Claude-இல் `/chrome` ஐ இயக்கவும். Firefox மற்றும் Zen இந்த நீட்டிப்பை ஆதரிக்காது. இந்த அமைப்பு சேர்க்கப்படுவதற்கு முன்பே Claude உங்கள் இயல்புநிலையாக இருந்திருந்தால், நீட்டிப்பை நிறுவ அதை மீண்டும் தேர்ந்தெடுக்கவும்.

[Muse Code](https://dev.meta.ai) — Meta-இன் `muse` — மற்ற Agent-களைப் போல முன்கூட்டியே நிறுவப்பட்ட mise ஸ்டப்பைப் பயன்படுத்துகிறது. அதை இயல்புநிலையாகத் தேர்ந்தெடுப்பது mise-இன் HTTP பின்நிலை மூலம் Meta-இன் அதிகாரப்பூர்வ தொடக்கியை நிறுவுகிறது. தொடக்கி உங்கள் இயந்திரத்திற்கான சொந்த பைனரியைச் சரிபார்த்துப் புதுப்பிக்கிறது.

நீங்கள் தேர்ந்தெடுத்ததும், `Super + Shift + Ctrl + A` இயல்புநிலை Agent-ஐ ஒரு பிரத்யேக டெர்மினல் சாளரத்தில் தொடங்குகிறது (அல்லது நீங்கள் இன்னும் தேர்ந்தெடுக்கவில்லை என்றால் தேர்வாளரைக் கொண்டுவருகிறது). `omarchy agent prompt "Review this project"` மூலம் அதை நேரடியாக ஒரு பணியிலும் தொடங்கலாம். இப்படித் தொடங்கப்படும் Agent-கள் அவற்றின் அந்தந்த கேட்க-நிறுத்தாத பயன்முறைகளில் கவனிக்கப்படாமல் இயங்குகின்றன, எனவே அவை உண்மையில் விஷயங்களைச் செய்யத் தயாராக இருங்கள்! மேலும் Agent-கள் உங்கள் முகப்பு கோப்பகத்திற்கான நம்பிக்கையை நினைவில் வைக்க மறுக்கின்றன என்பதால், `$HOME` இலிருந்து தொடங்குதல்கள் அதற்கு பதிலாக `~/Work` இல் தொடங்குகின்றன.

டெர்மினல் குறுக்குவழிகளும் உள்ளன: `a` தற்போதைய டெர்மினலில் இயல்புநிலை Agent-ஐ இன்லைனில் இயக்குகிறது, அதே நேரத்தில் `c`, `cx`, மற்றும் `cy` OpenCode, Claude Code, மற்றும் Codex-ஐ நேரடியாகத் தொடங்குகின்றன (மீண்டும் அவற்றின் தானியங்கு-ஒப்புதல் பயன்முறைகளில்). தீம் மாற்றங்கள் Agent-களுக்கும் ஒத்திசைகின்றன: Claude Code, Pi, OpenCode, மற்றும் Hermes (Omarchy அதை நிறுவியவுடன்) அனைத்தும் நீங்கள் Omarchy தீமை மாற்றும் போது பின்தொடர்கின்றன.

### Agent-கள் பேனல்

மேல் பட்டையில் ஒரு Agent-கள் ஐகான் உள்ளது. நீங்கள் ஒரு Agent-ஐ அமைப்பதற்கு முன், அதன் பேனல் Claude, Codex, அல்லது Grok-இல் உள்நுழைவதன் வழியாக உங்களை அழைத்துச் செல்கிறது, மேலும் முதலாவது உங்கள் இயல்புநிலை Agent ஆக மாறுகிறது. அதற்குப் பிறகு, பேனல் ஒவ்வொரு சந்தாவையும் ஒரு பக்கத்தில் வைக்கிறது: ஒவ்வொரு Agent மற்றும் கணக்கு அதன் திட்டத்துடன், அதன் 5-மணி நேர அமர்வு மற்றும் வாராந்திர வரம்புகள் ஒவ்வொன்றிற்கும் அது மீட்டமைக்கும் வரையிலான நேரத்துடன் ஒரு மீட்டர் (சரியான சதவீதத்திற்கு மிதக்கவும்), அல்லது மீதமுள்ள முன்பண இருப்பு, இந்த வார டோக்கன்கள் மற்றும் உங்கள் அதிகம் பயன்படுத்தப்பட்ட மாதிரி போல அவை அனைத்திலும் நீங்கள் பயன்படுத்தியதைச் சுழற்றும் ஒரு வரியின் கீழ். _Make something_ இன் கீழ் இது ஒரு புதிய தீம், செருகுநிரல், அல்லது செயலிக்கான தொடக்க தூண்டல்களை வழங்குகிறது, அவை பணியை உங்கள் இயல்புநிலை Agent-இடம் ஒப்படைக்கின்றன. செயலிகள் Omarchy-இன் சொந்த Hype, Monologue, மற்றும் Omacut போல, C++ மற்றும் Qt Quick இல், omarchy-app Agent திறனைப் பின்பற்றி கட்டமைக்கப்படுகின்றன, மேலும் அவற்றுக்குத் தேவையான கம்பைலர் மற்றும் Qt பகுதிகள் நிறுவப்பட்டு வருகின்றன. Claude Code, Codex, Grok, மற்றும் Fireworks ஆகியவை பெட்டியிலிருந்து வெளியே உள்ளடக்கப்பட்டுள்ளன.

பேனலுக்கு பட்டை ஐகானை இடது-கிளிக் செய்யவும், உங்கள் இயல்புநிலை Agent-ஐத் தொடங்க வலது-கிளிக் செய்யவும். அதன் பின்னால் உள்ள பயன்பாட்டு பதிவுகள் ஒவ்வொரு 15 நிமிடங்களுக்கும் `omarchy agent usage-update` ஆல் மீண்டும் உருவாக்கப்படுகின்றன, மேலும் பேனல் ஒத்திசைக்கப்பட்ட கோப்புறை வழியாக உங்கள் மற்ற இயந்திரங்களிலிருந்து பயன்பாட்டைக் கூட ஒன்றிணைக்க முடியும். முழு அமைப்புகளுக்கும் `$OMARCHY_PATH/shell/plugins/agents/` இன் கீழ் உள்ள README-ஐப் பார்க்கவும்.

### பல சந்தாக்கள்

நீங்கள் ஒன்றுக்கு மேற்பட்ட Claude, Codex, அல்லது Grok திட்டத்திற்கு பணம் செலுத்தினால் — ஒரு தனிப்பட்ட Max மற்றும் ஒரு வேலை ஒன்று, சொல்லுங்கள் — Omarchy அவை அனைத்தையும் உள்நுழைந்து வைத்திருந்து அவற்றுக்கு இடையே நகர முடியும். Agent-கள் பேனலில் உள்ள + மூலம் ஒரு சந்தாவைச் சேர்க்கவும், இது அங்கேயே அதன் வழியாக உங்களை அழைத்துச் செல்கிறது, அல்லது `omarchy agent account add claude Work` (அல்லது `codex`, அல்லது `grok`) மூலம் சேர்க்கவும். அது காணாமல் போனால் CLI-ஐ நிறுவுகிறது. ஒரு வழங்குநருக்கான முதல் கணக்கு உங்கள் சாதாரண உலாவி மூலம், CLI எப்போதும் பார்க்கும் இடத்தில் உள்நுழைகிறது. அதற்குப் பிறகு ஒவ்வொன்றும் ஒரு தனிப்பட்ட சாளரம் மூலம் உள்நுழைகிறது, எனவே உங்கள் உலாவி ஏற்கனவே உள்நுழைந்துள்ள கணக்கு தவறுதலாக எடுக்கப்படாது; நீங்கள் சேர்க்கும் கணக்காக அங்கே உள்நுழையவும், மேலும் நீங்கள் ஏற்கனவே திறந்திருந்த எந்த தனிப்பட்ட சாளரத்தையும் முதலில் மூடவும். இதைச் செய்ய CLI-இலிருந்து ஒருபோதும் வெளியேறாதீர்கள்: வெளியேறுவது சேமிக்கப்பட்ட உள்நுழைவை ரத்து செய்கிறது, மேலும் அந்தக் கணக்கு மீண்டும் சேர்க்கப்பட வேண்டும்.

ஒரு வழங்குநருக்கு ஒரு கணக்கு செயலில் உள்ளது, மேலும் ஒவ்வொரு புதிய அமர்வும் அதுவாகத் தொடங்குகிறது: `cx`, `cy`, ஒரு எளிய `claude`, `codex`, அல்லது `grok`, `omarchy agent` மூலம் தொடங்கப்படும் எதுவும், மற்றும் `PATH` இல் CLI-ஐக் கண்டுபிடிக்கும் ஸ்கிரிப்டுகள் அல்லது எடிட்டர்கள். `omarchy agent account use work` மூலம் மாறவும் (மற்றும் `omarchy agent account use main` மூலம் திரும்பவும்), அல்லது பேனலில் ஒரு கணக்கின் எண்ணை அழுத்தி பிறகு `Enter` (அல்லது அதன் பயன்படுத்து பொத்தானைக் கிளிக் செய்வதன்) மூலம் மாறவும். ஏற்கனவே இயங்கும் அமர்வுகள் அவை தொடங்கிய கணக்கில் இருக்கும். உரையாடல் வரலாறு, அமைப்புகள், திறன்கள், மற்றும் செருகுநிரல்கள் கணக்குகள் முழுவதும் பகிரப்படுகின்றன, எனவே அதே கோப்புறையில் `claude --continue` புதிய கணக்கில் நீங்கள் விட்ட இடத்தில் தொடர்கிறது.

ஒன்றுக்கு மேற்பட்ட கணக்குகளுடன், பேனல் ஒவ்வொரு கணக்கின் வரம்புகளையும் பக்கத்திலிருந்து பக்கமாகக் காட்டுகிறது, செயலில் உள்ளது குறிக்கப்பட்டுள்ளது. இயல்பாக செயலில் உள்ள கணக்கு ஒரு வரம்பின் 95% ஐக் கடக்கும் போது Omarchy உங்களுக்கு அறிவிக்கிறது, மேலும் அறிவிப்பைக் கிளிக் செய்வது அதிக இடவசதி உள்ள கணக்கிற்கு மாறுகிறது. பேனலில் ஒரு கணக்கின் வரியில் மிதந்து, பயன்படுத்து க்கு அருகில் தோன்றும் Autoswitch ஐக் கிளிக் செய்யவும் (அல்லது `m` ஐ அழுத்தவும்), அல்லது அதற்கு பதிலாக அது தானாகவே மாற `omarchy agent account mode auto` ஐ இயக்கவும்; அது இயக்கத்தில் இருக்கும் போது, ​​Autoswitch பயன்படுத்து இன் இடத்தை எடுக்கிறது, மேலும் அதை மீண்டும் கிளிக் செய்வது அறிவிப்பிற்குத் திரும்புகிறது. வரம்பை மாற்ற ஒரு எண்ணைச் சேர்க்கவும், `omarchy agent account mode auto 90` இல் உள்ளது போல. ஒவ்வொரு கணக்கும் வரம்பிற்கு மேல் இருந்தால், எந்த கணக்கு முதலில் விடுவிக்கப்படுகிறது என்பதுடன், அதைப் பற்றி ஒரு முறை கேட்பீர்கள். செயலில் உள்ள கணக்கு அதன் வரம்பிலிருந்து 15 புள்ளிகளுக்குள் இருக்கும் போது (இயல்புநிலையில் 80%), அதன் வரம்புகள் ஒவ்வொரு 15 க்கும் பதிலாக ஒவ்வொரு மூன்று நிமிடங்களுக்கும் சரிபார்க்கப்படுகின்றன.

`omarchy agent account list` ஒவ்வொரு கணக்கையும் அதன் சமீபத்திய வரம்புகளையும் காட்டுகிறது, `omarchy agent account remove work` ஒன்றை மறக்கிறது, மற்றும் `omarchy agent account rename primary Hey` ஒன்றை மறுபெயரிடுகிறது (அல்லது பேனலில் ஒரு கணக்கின் பெயரைக் கிளிக் செய்யவும்). இந்த கட்டளைகள் உங்கள் இயல்புநிலை Agent-இன் கணக்குகளில் வேலை செய்கின்றன; மற்ற வழங்குநரை அடைய, `omarchy agent account use codex side` இல் உள்ளது போல முதலில் அதைப் பெயரிடவும். `~/.claude` அல்லது `~/.codex` இல் நீங்கள் ஏற்கனவே வைத்திருந்த உள்நுழைவு _Main_ கணக்கு மற்றும் அது இருக்கும் இடத்தில் இருக்கும். சுமார் எட்டு மணி நேரத்திற்கும் மேலாகப் பயன்படுத்தப்படாமல் விடப்பட்ட ஒரு கணக்கு _Sign-in required_ ஐக் காட்டலாம்; பேனலில் அந்தக் கணக்கில் மீண்டும் உள்நுழைய அதைக் கிளிக் செய்யவும், அல்லது அதில் ஒரு அமர்வைத் தொடங்கவும், இது உள்நுழைவைத் தானாகவே புதுப்பிக்கிறது. ஒரு கணக்கு சேர்க்கப்பட்ட போது உங்களிடம் இருந்த MCP சேவையகங்கள் அதற்கு வருகின்றன, ஆனால் பின்னர் `claude mcp add` மூலம் நீங்கள் சேர்ப்பவை நீங்கள் சேர்த்த கணக்கை மட்டுமே அடைகின்றன. ஒரு CLI பைனரிக்கு ஒரு முழுமையான பாதையுடன் கட்டமைக்கப்பட்ட Claude Desktop மற்றும் கருவிகள் சுவிட்சைப் பின்தொடராது. ஒரு வெளிப்படையான `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, அல்லது `GROK_HOME` தேர்ந்தெடுக்கப்பட்ட கணக்கை விட முன்னுரிமை பெறுகிறது.

### செயலிழப்பு கண்டறிதல்

Omarchy செயல்முறை செயலிழப்புகளுக்காக systemd-coredump-ஐப் பார்க்கிறது. ஏதாவது segfault ஆகும் போது, ​​உங்களுக்கு ஒரு "செயல்முறை செயலிழந்தது" அறிவிப்பு கிடைக்கும் — அதைக் கிளிக் செய்யவும், மேலும் செயலிழப்பு Omarchy-இன் diagnose-crash திறனுடன் உங்கள் இயல்புநிலை Agent-இடம் ஒப்படைக்கப்படுகிறது, இது கோர் டம்பிலிருந்து உண்மைகளை நிறுவுவதன் மூலமும் செயலிழப்பு மேல்நிலையில் புகாரளிக்கத் தகுந்ததா என்பதைத் தீர்மானிப்பதன் மூலமும் Agent-ஐ அழைத்துச் செல்கிறது. `omarchy agent crash <pid>` மூலம் `coredumpctl list` இலிருந்து எந்த PID-க்கு எதிராகவும் அதை கையால் இயக்கலாம்.

பார்ப்பது இயல்பாகவே இயக்கத்தில் உள்ளது. _தூண்டு > மாற்று > செயலிழப்பு பதிவு_ இன் கீழ் (அல்லது `omarchy toggle crash-capture` மூலம்) அதை அணைக்கவும், அறிவிப்புகள் நிற்கும்; `omarchy agent crash <pid>` இன்னும் கையால் வேலை செய்கிறது.

செயலிழப்புகளை ஒரு நேரத்தில் ஒரு நிரல் என அமைதிப்படுத்தலாம், இதைத்தான் கண்டறிதல் இறுதியில் உங்களுக்கு வழங்குகிறது. `omarchy crash mute hyprland` அந்த நிரலுக்கு மட்டுமே அறிவிப்புகளை நிறுத்துகிறது, `omarchy crash mute hyprland off` அவற்றைத் திரும்பக் கொண்டுவருகிறது, மேலும் `omarchy crash mute` தனியாக நீங்கள் மியூட் செய்ததைப் பட்டியலிடுகிறது. இது பைனரியின் பாதையை அதன் பெயரைப் போலவே மகிழ்ச்சியுடன் எடுக்கிறது, எனவே `omarchy crash mute /usr/bin/hyprland` அதே விஷயத்தைச் செய்கிறது. `omarchy crash mute 'Some App'` இல் உள்ளது போல இடைவெளி உள்ள பெயரை மேற்கோள் காட்டவும். மற்ற அனைத்தும் இன்னும் அறிவிக்கின்றன, மேலும் மியூட் செய்யப்பட்ட நிரல் இன்னும் செயலிழக்கிறது — இது நினைவூட்டலை மறைக்கிறது, அது எதையும் சரிசெய்யாது.

### டெஸ்க்டாப் செயலிகள்

_நிறுவு > AI_ மெனு சில வரைகலை AI செயலிகளையும் கொண்டுள்ளது: ChatGPT டெஸ்க்டாப் செயலி, Claude டெஸ்க்டாப் செயலி (Anthropic-இன் Linux பீட்டா, Chat, Cowork, மற்றும் Claude Code தாவல்களுடன்), xAI-இன் மாதிரிகளுடன் அரட்டையடிக்க Grok Bot, Hermes Desktop, OpenClaw, மற்றும் Perplexity டெஸ்க்டாப் செயலி. Grok Bot டெஸ்க்டாப் அரட்டை செயலி. குறியீட்டு Agent என்பது `grok` கட்டளை.

Hermes Desktop தான் அறிந்து கொள்ள வேண்டியது, ஏனெனில் ஒரு இயந்திரத்தில் ஒரு Hermes உள்ளது, மேலும் அது செயலியினுடையது: Hermes செயலி மூலம் மட்டுமே நிறுவப்படுகிறது, மேலும் இயல்புநிலை Agent இயக்கும் `hermes` கட்டளை செயலியினுடையது. Hermes-ஐ இயல்புநிலை Agent ஆகத் தேர்ந்தெடுப்பது _நிறுவு > AI_ பதிவு செய்யும் அதே விஷயத்தை நிறுவுகிறது: தொகுப்பு, மற்றும் Hermes-இன் சொந்த நிறுவியால் அமைக்கப்பட்ட `~/.hermes` இன் கீழ் ஒரு Hermes ரன்டைம், இது முதல் முறை சில நிமிடங்கள் எடுக்கும். அந்த ரன்டைம் தான் டெர்மினல் `hermes` கட்டளை, இயல்புநிலை Agent மற்றும் செயலி அனைத்தும் பயன்படுத்தும் ஒரே Hermes, மேலும் அது ஒரு Omarchy வெளியீட்டிற்காகக் காத்திருப்பதற்கு பதிலாக `hermes update` மூலம் தன்னைப் புதுப்பிக்கிறது. அதை நிறுவுவது Hermes-க்கு Omarchy தீமை `omarchy` எனப் பெயரிடப்பட்ட ஒரு தோலாகவும் ஒப்படைக்கிறது, இதை நீங்கள் தீம்களை மாற்றும் போது ஒவ்வொரு Hermes மேற்பரப்பும் பின்தொடர்கிறது; நீங்கள் அது வேண்டாம் என்றால் Hermes-இன் தோற்றம் அமைப்புகளின் கீழ் அல்லது `/skin` மூலம் வேறொன்றைத் தேர்ந்தெடுக்கவும், மேலும் Omarchy அந்தத் தேர்வைத் தனியாக விட்டுவிடுகிறது. _நீக்கு > AI_ இன் கீழ் செயலியை நீக்குவது முதலில் Hermes-ஐ மூடுகிறது, கேட்வே உட்பட, அந்த ரன்டைமை அதனுடன் எடுக்கிறது, மேலும் நீங்கள் வேறுவிதமாகச் சொல்லாவிட்டால் உங்கள் அரட்டைகள், நினைவுகள், மற்றும் Hermes தனக்காக எழுதிய திறன்களை வைத்திருக்கிறது: அந்தத் தரவும் உங்கள் இணைப்பு அமைப்புகளும் கூட போக வேண்டுமா என்று அது கேட்கிறது, இயல்புநிலையாக இல்லை.

OpenClaw-இன் டெஸ்க்டாப் அனுபவம் அதன் Control UI, இது அதன் சொந்த உள்ளூர் கேட்வேயால் ஆதரிக்கப்படும் ஒரு வலை செயலியாகத் திறக்கிறது. OpenClaw `~/.openclaw` இல் உள்ளது மற்றும் தன்னைப் புதுப்பிக்கிறது: Control UI-இன் "Update Gateway" பொத்தானைப் பயன்படுத்தவும் அல்லது `openclaw update` ஐ இயக்கவும், மேலும் கேட்வே புதிய பதிப்பில் மறுதொடக்கம் செய்கிறது. Omarchy ஒரு புதிய நிறுவல் தொடங்கும் வெளியீட்டை மட்டுமே தேர்ந்தெடுக்கிறது. _நீக்கு > AI_ இன் கீழ் OpenClaw-ஐ நீக்குவது கேட்வே சேவையையும் செயலியையும் அதனுடன் எடுக்கிறது, பிறகு `~/.openclaw` கூட போக வேண்டுமா என்று கேட்கிறது, ஏனெனில் அது OpenClaw-ஐயே மற்றும் அது பதிவிறக்கும் செருகுநிரல் ரன்டைம்களுடன் உங்கள் அரட்டைகள் மற்றும் சான்றுகளை வைத்திருக்கிறது; இயல்புநிலை அதை வைத்திருக்கிறது, மேலும் OpenClaw-ஐ மீண்டும் நிறுவுவது அதைத் திரும்ப எடுக்கிறது.

### உள்ளூர் LLMகள்

Omarchy உள்ளூர் LLM மாதிரிகளை இயக்குவதற்கான இரண்டு வழிகளைப் பரிந்துரைக்கிறது: LM Studio மற்றும் Ollama. LM Studio திறந்த-எடை மாதிரிகளைக் கண்டுபிடித்து, அவற்றை நிறுவி, அவற்றை இயக்குவதற்கு ஒரு GUI இடைமுகத்தை வழங்குகிறது. எளிதாகத் தொடங்க இது ஒரு சிறந்த வழி. Ollama அதேபோல் செய்வதற்கு ஒரு CLI ஐ வழங்குகிறது. ஆனால் நீங்கள் உள்ளூர் மாதிரிகளுக்குப் புதியவர் என்றால், நான் LM Studio-வுடன் தொடங்குவேன். Omarchy மெனுவில் _நிறுவு > AI_ இன் கீழ் எதையும் நிறுவலாம்.

### Omarchy திறன்

Agent திறன்கள் AI குறிப்பிட்ட கருவிகளை ஒரு குறிப்பிட்ட வழியில் பயன்படுத்த உதவுகின்றன, மேலும் Omarchy அமைப்பைத் தனிப்பயனாக்குவதற்கான இயல்புநிலை திறனுடன் வருகிறது. உங்கள் Hyprland கட்டமைப்பை மாற்றுவது, பட்டையைச் சரிசெய்வது, அல்லது புதிதாக ஒரு புதிய தீமை உருவாக்குவது போல. இது Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` மற்றும் ஒவ்வொரு `~/.hermes/profiles/*/skills`), மற்றும் பொதுவான `~/.agents/skills` இருப்பிடத்திற்கான திறன் கோப்பகங்களில் சிம்லிங்க் செய்யப்பட்டுள்ளது, எனவே பெரும்பாலான ஹார்னஸ்கள் அதைத் தானாகவே எடுக்கின்றன.

ஆனால் இந்தத் திறனை நீங்கள் சோதனை ரீதியாகக் கருத வேண்டும். வெவ்வேறு மாதிரிகள் அதை வெவ்வேறு விளைவுகளுக்குப் பயன்படுத்தும். Agent என்ன மாற்ற விரும்புகிறது என்பது பற்றி உங்களுக்கு ஒரு யோசனை இருக்கும் பொருட்டு, முதலில் திட்ட பயன்முறையில் இயக்குவது சிறந்தது. பிறகு, Agent எல்லாவற்றையும் குழப்பினால், மாற்றங்களைத் திரும்பப் பெற அல்லது `omarchy reinstall configs` ஐ அழைக்கக் கூட தயாராக இருங்கள்.
