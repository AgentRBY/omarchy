# AI

Omarchy AI කේතීකරණ නියෝජිතයන් ප්‍රථම පන්තියේ පුරවැසියන් ලෙස සලකයි, නමුත් එය ඔබට ප්‍රියතම එකක් තෝරා දෙන්නේ නැත. ඒ වෙනුවට, සෑම ප්‍රධාන කේතීකරණ-නියෝජිත CLI එකක්ම කම්මැලි-පූරණය කරන ලද දියත්කරුවෙකු ලෙස පෙර-සම්බන්ධ වී එයි. දියත්කරුවන් `~/.local/bin/` හි කුඩා [mise](https://mise.jdx.dev/)-කළමනාකරණය කරන ලද කොටස් වන බැවින්, ඔබ ඇත්තටම එකක් ධාවනය කරන පළමු වර තෙක් කිසිවක් බාගනු නොලැබේ. Hermes යනු ව්‍යතිරේකයයි: ඒ සඳහා කිසිවක් කොටස් කර නැති අතර, එය තෝරා ගැනීම Hermes Desktop ස්ථාපනය කරයි, පහත _ඩෙස්ක්ටොප් යෙදුම්_ පැහැදිලි කරන ආකාරයට. මේවායින් ඕනෑම එකක් කැඳවා විමසූ විට සත්‍යාපනය කරන්න:

`ori` යනු අමුත්තායි: එය OpenRouter හි සම්පූර්ණ ආකෘති නාමාවලියට එරෙහිව අනෙකුත් පද්ධති ධාවනය කරයි, එබැවින් `ori claude`, `ori codex`, හෝ `ori opencode` එම නියෝජිතයන් ඔබ ඒවා යොමු කරන ඕනෑම ආකෘතියක් මත ආරම්භ කරන අතර, `ori code` යනු Ori හිම නියෝජිතයායි.

අමතර CLI එකක් එලෙසම එතීමට, `omarchy-mise-install <package> [command-name]` ධාවනය කරන්න. ඔබ `omarchy update` (හෝ `mup` අනුනාමය) ධාවනය කරන විට mise කළමනාකරණය කරන අනෙක් සියල්ල සමඟ කොටස් යාවත්කාලීනව තබා ගනු ලැබේ.

`grok`, `claude` සහ `codex` ආකාරයෙන්ම mise ප්‍රථම පාර්ශ්වීය `grok` පැකේජය හරහා ස්ථාපනය කරනු ලැබේ. `grok` ධාවනය කරන්න, නැතහොත් _සැකසුම > පෙරනිමි > නියෝජිතයා_ යටතේ එය තෝරන්න. x.ai හි `curl | bash` ස්ථාපකය මඟ හරින්න. එම මාර්ගය `~/.grok/bin` හි දෙවන පිටපතක් තබයි, එය `PATH` මත ඉදිරියට තබයි, සහ Omarchy හි එතුම මකා දමයි.

### පෙරනිමි නියෝජිතයා

ඔබේ පෙරනිමි නියෝජිතයා `omarchy default agent <name>` සමඟ හෝ Omarchy මෙනුවේ (`Super + Space`) _සැකසුම > පෙරනිමි > නියෝජිතයා_ යටතේ තෝරන්න. නියෝජිතයා තවම ස්ථාපනය කර නොමැති නම්, එය තෝරා ගැනීම පළමුව එය ස්ථාපනය කරයි. නැවුම් Omarchy එකක් එක් වරක් දැනුම්දීමකින් මෙම තේරීම කිරීමට ඔබට ආරාධනා කරනු ඇත.

Claude තෝරා ගැනීම Chromium, Chrome, Brave, Brave Origin, සහ Edge සඳහා එහි බ්‍රවුසර දිගුව සැකසීමට ද උත්සාහ කරයි. දිගු සැකසුම සියලුම පරිශීලකයින්ට අදාළ වන අතර ඔබේ පද්ධති මුරපදය ඉල්ලා සිටිය හැකිය; අවලංගු කිරීමක් හෝ අසාර්ථක දිගු ස්ථාපනයක් තවමත් Claude තෝරා දියත් කරයි. ඔබේ බ්‍රවුසරය නැවත අරඹන්න, විමසුවහොත් දිගුව සබල කරන්න, සහ එය සම්බන්ධ කිරීම අවසන් කිරීමට Claude වෙත පිවිසෙන්න. සම්බන්ධතාවය පරීක්ෂා කිරීමට Claude හි `/chrome` ධාවනය කරන්න. Firefox සහ Zen මෙම දිගුව සඳහා සහාය නොදක්වයි. මෙම සැකසුම එක් කිරීමට පෙර Claude දැනටමත් ඔබේ පෙරනිමිය වී තිබුණේ නම්, දිගුව ස්ථාපනය කිරීමට එය නැවත තෝරන්න.

[Muse Code](https://dev.meta.ai) — Meta හි `muse` — අනෙකුත් නියෝජිතයන් මෙන් පෙර-ස්ථාපිත mise කොටසක් භාවිත කරයි. එය පෙරනිමිය ලෙස තෝරා ගැනීම mise HTTP පසුබිම හරහා Meta නිල දියත්කය ස්ථාපනය කරයි. දියත්කය ඔබේ යන්ත්‍රය සඳහා ස්වාභාවික ද්විමය තහවුරු කර යාවත්කාලීන කරයි.

ඔබ තෝරාගත් පසුව, `Super + Shift + Ctrl + A` කැපවූ ටර්මිනල් කවුළුවක පෙරනිමි නියෝජිතයා දියත් කරයි (හෝ ඔබ තවම තෝරාගෙන නොමැති නම් තේරීම ගෙන එයි). ඔබට `omarchy agent prompt "Review this project"` සමඟ එය කෙලින්ම කාර්යයකට ද දියත් කළ හැකිය. මෙලෙස දියත් කරන ලද නියෝජිතයන් ඔවුන්ගේ අදාළ අසන්න-නවත්වන්න-එපා මාදිලිවල නොසැලකිලිමත්ව ධාවනය වන බැවින්, ඔවුන් ඇත්තටම දේවල් කිරීමට සූදානම්ව සිටින්න! නියෝජිතයන් ඔබේ නිවසේ නාමාවලිය සඳහා විශ්වාසය මතක තබා ගැනීමට ප්‍රතික්ෂේප කරන බැවින්, `$HOME` වෙතින් දියත් කිරීම් ඒ වෙනුවට `~/Work` හි ආරම්භ වේ.

ටර්මිනල් කෙටිමං ද ඇත: `a` වත්මන් ටර්මිනලයේ පේළිගතව පෙරනිමි නියෝජිතයා ධාවනය කරයි, එසේම `c`, `cx`, සහ `cy` OpenCode, Claude Code, සහ Codex කෙලින්ම ආරම්භ කරයි (ඔවුන්ගේ ස්වයංක්‍රීයව අනුමත කරන මාදිලිවල නැවතත්). තේමා වෙනස් කිරීම් නියෝජිතයන්ට ද සමමුහුර්ත වේ: ඔබ Omarchy තේමාව මාරු කරන විට Claude Code, Pi, OpenCode, සහ Hermes (Omarchy එය ස්ථාපනය කළ පසු) සියල්ලම අනුගමනය කරයි.

### නියෝජිතයන්ගේ පැනලය

ඉහළ තීරුවට නියෝජිතයන්ගේ අයිකනයක් ඇත. ඔබ නියෝජිතයෙකු සැකසීමට පෙර, එහි පැනලය Claude, Codex, හෝ Grok වෙත පිවිසීම හරහා ඔබව රැගෙන යන අතර, පළමුවැන්නා ඔබේ පෙරනිමි නියෝජිතයා බවට පත් වේ. ඉන්පසු, පැනලය සෑම දායකත්වයක්ම එක් පිටුවක් මත තබයි: සෑම නියෝජිතයෙකුම සහ ගිණුමක් එහි සැලැස්ම සමඟ, එය යළි පිහිටුවන තෙක් කාලය සමඟ එහි පැය 5 සැසි සහ සතිපතා සීමාවන් සඳහා මීටරයක් (නිවැරදි ප්‍රතිශතය සඳහා මූසිකය තබන්න), නැතහොත් ඉතිරි පෙරගෙවුම් ශේෂය, මෙම සතියේ ටෝකන සහ ඔබේ වැඩිපුරම භාවිතා කළ ආකෘතිය වැනි ඒවා සියල්ල හරහා ඔබ භාවිතා කළ දේ හරහා භ්‍රමණය වන පේළියක් යටතේ. _යමක් සාදන්න_ යටතේ එය කාර්යය ඔබේ පෙරනිමි නියෝජිතයාට භාර දෙන නව තේමාවක්, අතිරේක වැඩසටහනක්, හෝ යෙදුමක් සඳහා ආරම්භක ප්‍රේරණ ඉදිරිපත් කරයි. යෙදුම් ගොඩනඟා ඇත්තේ Omarchy හිම Hype, Monologue, සහ Omacut ආකාරයටම, C++ සහ Qt Quick හි, omarchy-app නියෝජිත කුසලතාව අනුගමනය කරමින් වන අතර, ඔවුන්ට අවශ්‍ය සම්පාදකය සහ Qt කොටස් ස්ථාපනය කර ඇත. Claude Code, Codex, Grok, සහ Fireworks පෙට්ටියෙන් පිටතම ආවරණය කර ඇත.

පැනලය සඳහා තීරු අයිකනය වම්-ක්ලික් කරන්න, ඔබේ පෙරනිමි නියෝජිතයා දියත් කිරීමට දකුණු-ක්ලික් කරන්න. එහි පිටුපස ඇති භාවිත වාර්තා සෑම මිනිත්තු 15කට වරක් `omarchy agent usage-update` මගින් නැවත ජනනය කරනු ලබන අතර, පැනලයට සමමුහුර්ත කළ ෆෝල්ඩරයක් හරහා ඔබේ අනෙකුත් යන්ත්‍රවලින් භාවිතය ඒකාබද්ධ කිරීමට පවා හැකිය. සම්පූර්ණ සැකසුම් සඳහා `$OMARCHY_PATH/shell/plugins/agents/` යටතේ README බලන්න.

### දායකත්ව කිහිපයක්

ඔබ එක් Claude, Codex, හෝ Grok සැලැස්මකට වඩා ගෙවන්නේ නම් — පුද්ගලික Max එකක් සහ වැඩ එකක්, කියන්න — Omarchy වලට ඒවා සියල්ලම පුරවා තබා ඒවා අතර ගමන් කළ හැකිය. නියෝජිතයන්ගේ පැනලයේ + සමඟ දායකත්වයක් එක් කරන්න, එය එහිම එය හරහා ඔබව රැගෙන යයි, නැතහොත් `omarchy agent account add claude Work` (හෝ `codex`, හෝ `grok`) සමඟ. එය අතුරුදහන් නම් CLI එක ස්ථාපනය කරයි. සපයන්නෙකු සඳහා වන පළමු ගිණුම CLI එක සැමවිටම සොයන තැනම, ඔබේ සාමාන්‍ය බ්‍රවුසරය හරහා පුරනය වේ. ඊට පසු සෑම එකක්ම පුද්ගලික කවුළුවක් හරහා පුරනය වන බැවින්, ඔබේ බ්‍රවුසරය දැනටමත් පුරවා ඇති ගිණුම අත්වැරදීමකින් තෝරා ගන්නේ නැත; ඔබ එක් කරන ගිණුම ලෙස එහි පුරනය වන්න, සහ ඔබ දැනටමත් විවෘත කර ඇති ඕනෑම පුද්ගලික කවුළුවක් පළමුව වසන්න. මෙය කිරීමට කිසිවිටෙක CLI එකෙන් ඉවත් නොවන්න: ඉවත් වීම සුරකින ලද පුරනය වීම අවලංගු කරන අතර, එම ගිණුම නැවත එක් කිරීමට සිදු වනු ඇත.

සපයන්නෙකුට එක් ගිණුමක් ක්‍රියාකාරී වන අතර, සෑම නව සැසියක්ම එය ලෙස ආරම්භ වේ: `cx`, `cy`, සරල `claude`, `codex`, හෝ `grok`, `omarchy agent` හරහා දියත් කරන ලද ඕනෑම දෙයක්, සහ `PATH` මත CLI එක සොයාගන්නා ස්ක්‍රිප්ට් හෝ සංස්කාරකවරුන්. `omarchy agent account use work` සමඟ මාරු වන්න (`omarchy agent account use main` සමඟ ආපසු), නැතහොත් ගිණුමක අංකය ඔබා ඉන්පසු `Enter` (හෝ එහි Use බොත්තම ක්ලික් කිරීමෙන්) පැනලයේ. දැනටමත් ධාවනය වන සැසි ඒවා ආරම්භ කළ ගිණුමේම රැඳී සිටියි. සංවාද ඉතිහාසය, සැකසුම්, කුසලතා, සහ අතිරේක වැඩසටහන් ගිණුම් හරහා බෙදා ගනු ලබන බැවින්, එකම ෆෝල්ඩරයේ `claude --continue` ඔබ නව ගිණුමෙන් නතර කළ තැනින්ම දිගටම ගෙන යයි.

### බිඳවැටීම් රෝග විනිශ්චය

Omarchy ක්‍රියාවලි බිඳවැටීම් සඳහා systemd-coredump නිරීක්ෂණය කරයි. යමක් segfault වන විට, ඔබට "Process crashed" දැනුම්දීමක් ලැබෙනු ඇත — එය ක්ලික් කරන්න, සහ බිඳවැටීම Omarchy හි diagnose-crash කුසලතාව සමඟ ඔබේ පෙරනිමි නියෝජිතයාට භාර දෙනු ලැබේ, එය නියෝජිතයාව මූලික ඩම්පයෙන් කරුණු තහවුරු කිරීම සහ බිඳවැටීම ඉහළට වාර්තා කිරීමට වටින්නේදැයි තීරණය කිරීම හරහා රැගෙන යයි. ඔබට එය `omarchy agent crash <pid>` සමඟ `coredumpctl list` වෙතින් ඕනෑම PID එකකට එරෙහිව අතින් ද ධාවනය කළ හැකිය.

නිරීක්ෂණය පෙරනිමියෙන් සක්‍රියයි. එය _ක්‍රියාත්මක > සක්‍රිය/අක්‍රිය > බිඳවැටීම් ග්‍රහණය_ යටතේ අක්‍රිය කරන්න (හෝ `omarchy toggle crash-capture` සමඟ) දැනුම්දීම් නතර වේ; `omarchy agent crash <pid>` තවමත් අතින් වැඩ කරයි.

බිඳවැටීම් එක් වැඩසටහනක් වරකට නිහඬ කළ හැකි අතර, රෝග විනිශ්චය අවසානයේදී ඔබට ඉදිරිපත් කරන්නේ එයයි. `omarchy crash mute hyprland` එම වැඩසටහන සඳහා පමණක් දැනුම්දීම් නවත්වයි, `omarchy crash mute hyprland off` ඒවා ආපසු ගෙන එයි, සහ `omarchy crash mute` තනිවම ඔබ නිහඬ කළ දේ ලැයිස්තුගත කරයි. එය ද්විමයේ මාර්ගය එහි නම තරම්ම සතුටින් ගන්නා බැවින්, `omarchy crash mute /usr/bin/hyprland` ද එම දෙයම කරයි. `omarchy crash mute 'Some App'` හි මෙන් ඉඩක් ඇති නමක් උද්ධෘත කරන්න. අන් සියල්ල තවමත් දැනුම් දෙන අතර, නිහඬ කළ වැඩසටහන තවමත් බිඳ වැටේ — මෙය මතක්කිරීම සඟවයි, එය කිසිවක් නිවැරදි නොකරයි.

### ඩෙස්ක්ටොප් යෙදුම්

_ස්ථාපනය > AI_ මෙනුව චිත්‍රක AI යෙදුම් කිහිපයක් ද දරයි: ChatGPT ඩෙස්ක්ටොප් යෙදුම, Claude ඩෙස්ක්ටොප් යෙදුම (Chat, Cowork, සහ Claude Code ටැබ් සමඟ Anthropic හි Linux බීටා), xAI ආකෘති සමඟ කතාබස් කිරීම සඳහා Grok Bot, Hermes Desktop, OpenClaw, සහ Perplexity ඩෙස්ක්ටොප් යෙදුම. Grok Bot යනු ඩෙස්ක්ටොප් කතාබස් යෙදුමයි. කේතීකරණ නියෝජිතයා යනු `grok` විධානයයි.

Hermes Desktop දැනගැනීමට ඇති එකකි, මන්ද යන්ත්‍රයකට එක් Hermes එකක් ඇති අතර, එය යෙදුමේ එකයි: Hermes කොහොමත් ස්ථාපනය වන්නේ යෙදුම හරහා පමණක් වන අතර, පෙරනිමි නියෝජිතයා ධාවනය කරන `hermes` විධානය යෙදුමේ එකයි. Hermes පෙරනිමි නියෝජිතයා ලෙස තෝරා ගැනීම _ස්ථාපනය > AI_ ප්‍රවේශය කරන දෙයම ස්ථාපනය කරයි: පැකේජය, සහ Hermes හිම ස්ථාපකය විසින් සැකසූ `~/.hermes` යටතේ Hermes ධාවන කාලයක්, එය පළමු වරට මිනිත්තු කිහිපයක් ගතවේ. එම ධාවන කාලය ටර්මිනල් `hermes` විධානය, පෙරනිමි නියෝජිතයා සහ යෙදුම යන සියල්ලම භාවිත කරන එක් Hermes වන අතර, එය Omarchy නිකුතුවක් බලා සිටීමට වෙනුවට `hermes update` සමඟ තනිවම යාවත්කාලීන වේ. එය ස්ථාපනය කිරීම `omarchy` ලෙස නම් කළ සමක් ලෙස Omarchy තේමාව ද Hermes වෙත භාර දෙන අතර, ඔබ තේමා මාරු කරන විට සෑම Hermes මතුපිටක්ම එය අනුගමනය කරයි; ඔබ එයට එසේ නොවීමට කැමති නම් Hermes හි පෙනුම සැකසුම් යටතේ හෝ `/skin` සමඟ වෙනත් එකක් තෝරන්න, Omarchy එම තේරීම තනිවම තබයි. _ඉවත් කරන්න > AI_ යටතේ යෙදුම ඉවත් කිරීම gateway එක ඇතුළුව Hermes පළමුව වසයි, එම ධාවන කාලය එය සමඟ ගෙන යන අතර, ඔබ වෙනත් ආකාරයකින් නොකියන්නේ නම් ඔබේ කතාබස්, මතකයන්, සහ Hermes තමන් වෙනුවෙන් ලියූ කුසලතා තබා ගනී: එම දත්ත සහ ඔබේ සම්බන්ධතා සැකසුම් ද යා යුතුදැයි එය අසයි, පෙරනිමියෙන් නැත.

OpenClaw හි ඩෙස්ක්ටොප් අත්දැකීම එහි Control UI එක වන අතර, එය තමන්ගේම දේශීය gateway එකක් මගින් සහාය දක්වන වෙබ් යෙදුමක් ලෙස විවෘත වේ. OpenClaw `~/.openclaw` හි ජීවත් වන අතර තනිවම යාවත්කාලීන වේ: Control UI හි "Update Gateway" බොත්තම භාවිත කරන්න නැතහොත් `openclaw update` ධාවනය කරන්න, gateway එක නව අනුවාදය මත නැවත ආරම්භ වේ. Omarchy නැවුම් ස්ථාපනයක් ආරම්භ කරන නිකුතුව පමණක් තෝරයි. _ඉවත් කරන්න > AI_ යටතේ OpenClaw ඉවත් කිරීම gateway සේවාව සහ යෙදුම එය සමඟ ගෙන යන අතර ඉන්පසු `~/.openclaw` ද යා යුතුදැයි අසයි, මන්ද එය OpenClaw ම සහ එය බාගන්නා අතිරේක ධාවන කාලයන් සමඟ ඔබේ කතාබස් සහ අක්තපත්‍ර රඳවාගෙන සිටින අතර; පෙරනිමිය එය තබා ගන්නා අතර, OpenClaw නැවත ස්ථාපනය කිරීම එය නැවත ලබා ගනී.

### දේශීය LLM

Omarchy දේශීය LLM ආකෘති ධාවනය කිරීමේ ක්‍රම දෙකක් නිර්දේශ කරයි: LM Studio සහ Ollama. LM Studio විවෘත-බර ආකෘති සොයා ගැනීමට, ඒවා ස්ථාපනය කිරීමට, සහ ඒවා ධාවනය කිරීමට GUI අතුරුමුහුණතක් සපයයි. එය පහසුවෙන් ආරම්භ කිරීමට විශිෂ්ට ක්‍රමයකි. Ollama ඒ හා සමානව කිරීමට CLI එකක් ඉදිරිපත් කරයි. නමුත් ඔබ දේශීය ආකෘතිවලට නවකයෙකු නම්, මම LM Studio සමඟ ආරම්භ කරමි. ඔබට Omarchy මෙනුවේ _ස්ථාපනය > AI_ යටතේ ඕනෑම එකක් ස්ථාපනය කළ හැකිය.

### Omarchy කුසලතාව

නියෝජිත කුසලතා AI හට විශේෂිත ආකාරයකින් විශේෂිත මෙවලම් භාවිත කිරීමට උපකාර කරන අතර, පද්ධතිය අනුකූල කිරීමට Omarchy පෙරනිමි කුසලතාවක් සමඟ නැව්ගත වේ. ඔබේ Hyprland වින්‍යාසය සකස් කිරීම, තීරුව සකස් කිරීම, හෝ මුල සිට නව තේමාවක් නිර්මාණය කිරීම වැනි. එය Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` සහ සෑම `~/.hermes/profiles/*/skills`), සහ සාමාන්‍ය `~/.agents/skills` ස්ථානය සඳහා කුසලතා නාමාවලි වලට symlink කර ඇති බැවින්, බොහෝ පද්ධති එය ස්වයංක්‍රීයව ලබා ගනී.

නමුත් ඔබ මෙම කුසලතාව අත්හදා බැලීමක් ලෙස සැලකිය යුතුය. විවිධ ආකෘති එය විවිධ ප්‍රයෝග සඳහා භාවිත කරනු ඇත. නියෝජිතයා වෙනස් කිරීමට කැමති දේ පිළිබඳ අදහසක් ඔබට ඇති වන පරිදි පළමුව සැලසුම් මාදිලියේ ධාවනය කිරීම වඩාත් සුදුසුය. ඉන්පසු නියෝජිතයා සියල්ල අවුල් කළහොත් වෙනස්කම් ආපසු හැරවීමට හෝ `omarchy reinstall configs` කැඳවීමට පවා සූදානම්ව සිටින්න.
