# ආරම්භ කිරීම

Omarchy ISO එකක් භාවිතයෙන් ස්ථාපනය කෙරේ. ඔබට සම්පූර්ණ ධාවකයම අත්පත් කරගන්නා පූර්ණ-තැටි ස්ථාපනයක් හෝ, ධාවකයක වෙන් නොකළ ඉඩ තුළ Omarchy තබන නිදහස්-ඉඩ ස්ථාපනයක් අතර තෝරාගත හැකිය — Windows හෝ වෙනත් මෙහෙයුම් පද්ධතියක් සමඟ dual boot කරන්නේ එලෙසය (බලන්න [dual-boot ස්ථාපනය](50-dual-boot-install.md) — පළමුව Windows හි BitLocker අක්‍රිය කළ යුතු බව සලකන්න). කෙසේ වෙතත්, ස්ථාපනය පෙරනිමියෙන් පූර්ණ සංකේතනයට යොමු වන අතර, පූර්ණ-තැටි විකල්පය තෝරාගත් ධාවකය මකා දමනු ඇත, එබැවින් පවතින එකක් භාවිත කිරීමට පෙර උපස්ථයක් ගැනීමට වග බලා ගන්න!

පළමුව [Omarchy ISO එක බාගන්න](https://omarchy.org/), එය USB කූරකට දමන්න (Mac/Windows හි [balenaEtcher](https://etcher.balena.io/) හෝ Linux හි [caligula](https://github.com/ifd3f/caligula) භාවිත කරන්න), සහ කූරෙන් boot කරන්න.

### වෙනත් හිමිකරුවෙකු සඳහා ස්ථාපනය කිරීම

(ඔබ දැනටමත් භාවිත කරමින් සිටි යන්ත්‍රයක් නැවත ස්ථාපනයකින් තොරව ද භාර දිය හැකිය — බලන්න [පරිගණකය යළි පිහිටුවීම](48-security.md).)

### සංකේතනය රහිත ස්ථාපන

Omarchy පෙරනිමියෙන් සංකේතනය සමඟ ස්ථාපනය කෙරේ. නැති වීමට හෝ සොරකම් කිරීමට හැකි ඕනෑම පරිගණකයක් සඳහා එය ආරක්ෂිත, වගකිවයුතු තේරීමයි. ඔබේ දෘඪාංගයට ප්‍රවේශය ඇති කිසිවෙකුට ඔබේ දත්ත ලබා ගැනීමට හැකි වීමට ඔබ කැමති නැත!

නමුත් විශේෂ අවස්ථාවලදී, ආරක්ෂිත පරිගණකවල දුරස්ථ Omarchy ස්ථාපන හෝ සංවේදී දත්ත නොමැති ඉවත දැමිය හැකි ස්ථාපන සඳහා වැනි, ඔබට සංකේතනය නොමැතිව ස්ථාපනය කිරීමට අවශ්‍ය විය හැකිය. සංකේතනය රහිත ස්ථාපනයකට මාරු වීමට තැටි ආකෘතිකරණ තහවුරු කිරීමේදී ඔබට `Ctrl + C` එබිය හැකිය.
