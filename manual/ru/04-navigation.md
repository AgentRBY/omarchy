# Навигация

Всё в Omarchy происходит через клавиатуру — _ВСЁ!_ При первом запуске системы вы буквально ничего не сможете сделать одной только мышью. Но вы можете нажать `Super + Space`, чтобы открыть меню Omarchy, и отсюда сделать практически всё.

Но меню Omarchy даже не предполагается основным способом управления системой большую часть времени. Мы можем быстрее! Все самые важные приложения привязаны напрямую к отдельным сочетаниям клавиш. Терминал запускается через `Super + Return`, а браузер — через `Super + Shift + Return`. Попробуйте сделать одно за другим, и вы увидите магию тайлинга Hyprland в действии:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

Затем можно нажать `Super + J`, чтобы сложить их друг над другом вместо расположения бок о бок:

 ![navigation-stacked](images/navigation-stacked.webp)

Нажмите `Super + J` ещё раз, чтобы вернуть их в положение бок о бок. Затем попробуйте `Super + Shift + Arrow Right` в браузере, чтобы поменять окна местами.

Теперь попробуйте `Super + Ctrl + T`, чтобы запустить монитор активности. Он появится как плавающее окно. Его можно сделать тайловым с помощью `Super + T` (и нажать ещё раз, чтобы снова сделать плавающим). Теперь нажмите `Super + Shift + F`, чтобы открыть файловый менеджер. Получится аккуратная четырёхсторонняя конфигурация:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

Между окнами вы переключаетесь с помощью `Super + Arrow`. Это переключает фокус и перемещает курсор в центр нового приложения.

Если нажать `Super + Shift + 2`, текущее сфокусированное приложение переместится на второе рабочее пространство. `Super + Shift + 1` перемещает его обратно. (А `Super + Shift + Alt + 2` переместит текущее сфокусированное приложение на второе рабочее пространство, не переключаясь на него.)

Если удерживать `Super` и щёлкать мышью по окну, можно менять его расположение. Если удерживать `Super` и использовать правую кнопку мыши, можно свободно изменять размер окна.

Окно закрывается через `Super + W` или `Super + Q` (а все окна закрываются через `Ctrl + Alt + Delete`).

Также можно перейти в полноэкранный режим через `Super + F`, просто на всю ширину (сохраняя верхнюю панель) через `Super + Alt + F` или в полноэкранный режим внутри окна через `Super + Ctrl + F` (хорошо для YouTube!).

### Раскладка dwindle и прокрутка

Раскладка Omarchy по умолчанию называется dwindle. Она удерживает все окна, открытые на одном рабочем пространстве, видимыми всё время, даже если приходится их уменьшать.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

Но можно также превратить рабочее пространство в раскладку прокрутки, где окна выстроены бок о бок за видимой границей дисплея. Одно рабочее пространство переводится в эту раскладку через `Super + L`.

Повторное нажатие `Super + L` делает рабочее пространство плавающим, где окна свободно перекрываются и вы размещаете их сами, а третье нажатие возвращает его к dwindle. `Super + Alt + L` проходит через них в обратном порядке. Окно, которое плавает само по себе — то, которое вы вынули через `Super + T`, или приложение, которое всегда открывается плавающим, — продолжает плавать, когда рабочее пространство возвращается к тайлингу. Верхняя панель отмечает рабочее пространство, на котором вы находитесь, его раскладкой: квадрат для dwindle, круг для прокрутки и треугольник для плавающего. Щелчок по этой отметке тоже циклически меняет раскладку.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

Выбор делается для каждого рабочего пространства и сохраняется. Так что рабочее пространство 1 можно оставить на dwindle для веб-сёрфинга, а рабочее пространство 2 — на прокрутке для кода, и они вернутся в таком виде после перезапуска.

Если хотите использовать раскладку прокрутки по умолчанию, это можно задать в `~/.config/hypr/looknfeel.lua`:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### Плавающие рабочие пространства

Плавающее рабочее пространство работает как традиционный рабочий стол: окна перекрываются, а вы сами перемещаете их и меняете размер. Каждое окно получает заголовок в цветах вашей темы с кнопками сворачивания, разворачивания и закрытия. `Super + M` также сворачивает сфокусированное окно. Свёрнутое окно ждёт в доке; щёлкните по его приложению, чтобы вернуть его. Щёлкните по окну, чтобы выдвинуть его вперёд. Изменяйте размер с любого края или угла. Дважды щёлкните по заголовку, чтобы развернуть окно, сохраняя верхнюю панель видимой, и ещё раз, чтобы вернуть его прежний размер.

Плавающее рабочее пространство также показывает док с закреплёнными приложениями, всем, что запущено, и сеткой всех приложений за кнопкой приложений, которую также открывают `Super + Alt + Space` и _Приложения_ в меню Omarchy. Щёлкните правой кнопкой мыши по приложению в сетке или нажмите `Delete`, чтобы удалить его. Щёлкните по приложению, чтобы открыть его или выдвинуть его окно вперёд; щёлкните ещё раз, чтобы перебрать его окна. Средний щелчок открывает новое окно. Перетащите значок вдоль дока, чтобы переместить его; перетаскивание запущенного приложения среди остальных сохраняет его там. Щёлкните правой кнопкой мыши, чтобы оставить приложение в доке, убрать его или завершить. Док убирается с пути полноэкранного окна. Щёлкните правой кнопкой мыши по кнопке приложений, чтобы переместить док к другому краю или заставить его скрываться, пока указатель не достигнет его края. Положение также находится в _Действия > Внешний вид > Док > Положение дока_, а `omarchy dock position left` и `omarchy dock autohide on` устанавливают оба параметра из терминала. Приложения, которые вы держите в доке, бледнеют, пока не запущены.

Новые рабочие пространства и все те, которым вы не дали собственную раскладку через `Super + L`, используют раскладку по умолчанию. Изменение значения по умолчанию сбрасывает каждое рабочее пространство без окон к нему, а пространство с окнами сохраняет имеющуюся раскладку. Выберите её в _Действия > Внешний вид > Раскладка рабочих пространств_: Мозаичная, Прокрутка или Плавающий. `omarchy-hyprland-workspace-layout-default scrolling` устанавливает её из терминала.

### Группировка окон

Окна можно группировать с помощью `Super + G`. Как только вы оказались в группе, каждое окно, запущенное при активной группе, будет ей принадлежать. Между этими сгруппированными окнами можно перемещаться с помощью `Super + Ctrl + Arrow Left/Right` или `Super + Alt + 1/2/3/4`, чтобы перейти напрямую к сгруппированному окну по порядку.

Окно можно вывести из группы с помощью `Super + Alt + G` или разобрать всю группу повторным нажатием `Super + G`. Наконец, окна вне группы можно переместить в неё с помощью `Super + Alt + Arrows`.

### Вынесение окон

Окно можно вынести из его выделения рабочего пространства с помощью `Super + O`. Это закрепит его как плавающее окно, которое следует за вами на любое рабочее пространство. Отлично подходит для видеоплееров и тому подобного.

 ![navigation-popped-window](images/navigation-popped-window.webp)

### Рабочее пространство-блокнот

Наконец, есть специальное рабочее пространство-блокнот, которое опускается поверх любого рабочего пространства, на котором вы сейчас находитесь, во многом как консоль Quake. Переключайте его через `Super + Grave` или `Super + S` и помещайте туда окно с помощью `Super + Shift + Grave` или `Super + Alt + S`.

Особенно хорошо оно подходит для терминала с работающим агентом или для элементов управления, с которыми вы хотите быстро взаимодействовать, не покидая текущее рабочее пространство. Чтобы переместить окно с блокнота, отправьте его напрямую на другое рабочее пространство чем-то вроде `Super + Shift + 1`.

Пока блокнот содержит одно окно, он опускается как центрированная панель, а не охватывает весь экран. Поместите на него второе приложение, и он вернётся к полной ширине, чтобы у двух приложений было место расположиться бок о бок.

### К этому нужно привыкнуть!

Требуется некоторое время, чтобы привыкнуть к такой навигации по рабочему столу, но как только привыкнете, будет трудно вернуться к традиционному рабочему столу, управляемому мышью!
