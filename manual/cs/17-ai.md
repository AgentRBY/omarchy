# AI

Omarchy zachází s AI agenty pro kódování jako s prvotřídními občany, ale nevybírá za vás favorita. Místo toho je každé hlavní CLI agenta pro kódování předem zapojeno jako líně načítaný spouštěč. Spouštěče jsou drobné záložky spravované nástrojem [mise](https://mise.jdx.dev/) v `~/.local/bin/`, takže se nic nestahuje, dokud některý skutečně nespustíte. Hermes je výjimkou: pro něj není záložka žádná a jeho výběr nainstaluje Hermes Desktop, jak vysvětluje _Desktopové aplikace_ níže. Spusťte kterýkoli z nich a při výzvě se ověřte:

| Příkaz    | Agent                                                            |
|------------|------------------------------------------------------------------|
| `claude`   | [Claude Code](https://code.claude.com/docs/en/overview)          |
| `codex`    | [OpenAI Codex](https://github.com/openai/codex)                  |
| `opencode` | [OpenCode](https://opencode.ai/)                                 |
| `agy`      | [Google Antigravity CLI](https://github.com/google-antigravity/antigravity-cli) |
| `copilot`  | [GitHub Copilot CLI](https://github.com/github/copilot-cli)      |
| `crush`    | [Crush](https://github.com/charmbracelet/crush)                  |
| `grok`     | [Grok Build](https://x.ai/build) od xAI                        |
| `pi`       | [Pi Maria Zechnera](https://github.com/badlogic/pi-mono)        |
| `omp`      | [Oh My Pi](https://github.com/can1357/oh-my-pi)                  |
| `ori`      | [Ori](https://openrouter.ai/docs/guides/ori/harness), harness OpenRouteru |
| `hermes`   | [Hermes](https://hermes-agent.nousresearch.com/), agent Nous Research  |
| `muse`     | [Muse Code](https://dev.meta.ai), agent pro kódování Mety           |
| `cursor-agent` | [Cursor CLI](https://cursor.com/cli)                         |

`ori` je ten zvláštní: spouští ostatní harnesse proti celému katalogu modelů OpenRouteru, takže `ori claude`, `ori codex` nebo `ori opencode` spustí tyto agenty na jakémkoli modelu, na který je namíříte, a `ori code` je vlastní agent Ori.

Chcete-li stejným způsobem zabalit další CLI, spusťte `omarchy-mise-install <package> [command-name]`. Záložky jsou udržovány aktuální spolu se vším ostatním, co mise spravuje, když spustíte `omarchy update` (nebo alias `mup`).

`grok` se instaluje prostřednictvím balíčku `grok` od mise z první ruky, stejně jako `claude` a `codex`. Spusťte `grok`, nebo ho vyberte v _Nastavení > Výchozí > Agent_. Instalátor `curl | bash` na x.ai vynechte. Tato cesta umístí druhou kopii do `~/.grok/bin`, předřadí ji na `PATH` a přepíše wrapper Omarchy.

### Výchozí agent

Svého výchozího agenta si vyberte pomocí `omarchy default agent <name>` nebo v _Nastavení > Výchozí > Agent_ v nabídce Omarchy (`Super + Space`). Pokud agent ještě není nainstalován, jeho výběr ho nejprve nainstaluje. Čerstvé Omarchy vás k této volbě vyzve jednorázovým oznámením.

Výběr Claude se také pokusí nastavit jeho rozšíření pro prohlížeče Chromium, Chrome, Brave, Brave Origin a Edge. Nastavení rozšíření platí pro všechny uživatele a může požádat o vaše systémové heslo; zrušení nebo neúspěšná instalace rozšíření Claude stále vybere a spustí. Restartujte prohlížeč, na výzvu rozšíření povolte a přihlaste se ke Claude a připojení dokončete. Spusťte `/chrome` v Claude a připojení zkontrolujte. Firefox a Zen toto rozšíření nepodporují. Pokud byl Claude vaším výchozím už před přidáním tohoto nastavení, vyberte ho znovu a rozšíření nainstalujte.

[Muse Code](https://dev.meta.ai) — `muse` od Mety — používá předinstalovanou záložku mise jako ostatní agenti. Jeho výběr jako výchozího nainstaluje oficiální spouštěč Mety prostřednictvím HTTP backendu mise. Spouštěč ověří a aktualizuje nativní binární soubor pro váš počítač.

Jakmile si vyberete, `Super + Shift + Ctrl + A` spustí výchozího agenta ve vyhrazeném okně terminálu (nebo vyvolá výběr, pokud jste si ještě nevybrali). Můžete ho také spustit přímo do úlohy pomocí `omarchy agent prompt "Review this project"`. Agenti spuštění tímto způsobem běží bez obsluhy v jejich příslušných režimech nezastavování se s dotazy, takže buďte připraveni, že skutečně budou dělat věci! A protože agenti odmítají pamatovat si důvěru pro váš domovský adresář, spuštění z `$HOME` začínají místo toho v `~/Work`.

Existují i terminálové zkratky: `a` spustí výchozího agenta přímo v aktuálním terminálu, zatímco `c`, `cx` a `cy` spouštějí OpenCode, Claude Code a Codex přímo (opět v jejich automaticky schvalujících režimech). Změny motivu se synchronizují i s agenty: Claude Code, Pi, OpenCode a Hermes (jakmile ho Omarchy nainstalovalo) následují, když přepnete motiv Omarchy.

### Panel agentů

Horní panel má ikonu agentů. Než si agenta nastavíte, jeho panel vás provede přihlášením ke Claude, Codex nebo Grok a první z nich se stane vaším výchozím agentem. Poté panel umístí každé předplatné na jednu stránku: každého agenta a účet s jeho plánem, měřič pro každý z jeho 5hodinových limitů relace a týdenních limitů s časem do resetování (najeďte pro přesné procento), nebo zbývající předplacený zůstatek, pod řádkem, který rotuje tím, co jste použili u všech z nich, jako jsou tokeny za tento týden a váš nejpoužívanější model. V části _Make something_ nabízí úvodní prompty pro nový motiv, plugin nebo aplikaci, které úlohu předají vašemu výchozímu agentovi. Aplikace se vytvářejí tak, jak se vytvářejí vlastní Hype, Monologue a Omacut od Omarchy, v C++ a Qt Quick, podle dovednosti agenta omarchy-app, a kompilátor a části Qt, které potřebují, jsou nainstalovány. Claude Code, Codex, Grok a Fireworks jsou pokryty hned po vybalení.

Klikněte levým tlačítkem na ikonu panelu pro panel, pravým tlačítkem pro spuštění výchozího agenta. Záznamy o využití za ním se každých 15 minut regenerují pomocí `omarchy agent usage-update` a panel může dokonce slučovat využití z vašich ostatních počítačů prostřednictvím synchronizované složky. Úplné nastavení viz README v `$OMARCHY_PATH/shell/plugins/agents/`.

### Několik předplatných

Pokud platíte za více plánů Claude, Codex nebo Grok — například osobní Max a pracovní — Omarchy je může udržet všechny přihlášené a pohybovat se mezi nimi. Přidejte předplatné pomocí + v panelu agentů, který vás tím provede přímo tam, nebo pomocí `omarchy agent account add claude Work` (nebo `codex`, nebo `grok`). Pokud CLI chybí, nainstaluje ho. První účet pro poskytovatele se přihlásí přes váš normální prohlížeč, přesně tam, kam se CLI vždy dívá. Každý další se poté přihlásí přes soukromé okno, aby se účet, ke kterému je váš prohlížeč již přihlášen, nezachytil omylem; přihlaste se tam jako účet, který přidáváte, a nejprve zavřete všechna soukromá okna, která už máte otevřená. Za tímto účelem se nikdy neodhlašujte z CLI: odhlášení zruší uložené přihlášení a tento účet by musel být přidán znovu.

Pro každého poskytovatele je aktivní jeden účet a každá nová relace začíná jako on: `cx`, `cy`, prosté `claude`, `codex` nebo `grok`, cokoli spuštěného přes `omarchy agent` a skripty nebo editory, které najdou CLI na `PATH`. Přepínejte pomocí `omarchy agent account use work` (a zpět pomocí `omarchy agent account use main`), nebo v panelu stisknutím čísla účtu a poté `Enter` (nebo kliknutím na jeho tlačítko Use). Relace, které už běží, zůstanou na účtu, se kterým začaly. Historie konverzací, nastavení, dovednosti a pluginy jsou sdíleny napříč účty, takže `claude --continue` ve stejné složce pokračuje tam, kde jste na novém účtu přestali.

Při více účtech panel zobrazuje limity každého účtu vedle sebe, přičemž aktivní je označen. Ve výchozím nastavení vás Omarchy upozorní, když aktivní účet překročí 95 % limitu, a kliknutím na oznámení se přepne na účet s největší rezervou. Najeďte na řádek účtu v panelu a klikněte na Autoswitch, který se objeví vedle Use (nebo stiskněte `m`), nebo spusťte `omarchy agent account mode auto`, aby se přepínal sám; zatímco je zapnutý, Autoswitch zaujímá místo Use a opětovným kliknutím se vrátí k oznamování. Přidejte číslo pro změnu prahu, například `omarchy agent account mode auto 90`. Pokud je každý účet nad prahem, uslyšíte o tom jednou spolu s tím, který účet se uvolní jako první. Zatímco je aktivní účet do 15 bodů od svého prahu (80 % ve výchozím nastavení), jeho limity se kontrolují každé tři minuty místo každých 15.

`omarchy agent account list` zobrazí každý účet a jeho nejnovější limity, `omarchy agent account remove work` jeden zapomene a `omarchy agent account rename primary Hey` jeden přejmenuje (nebo klikněte na název účtu v panelu). Tyto příkazy pracují s účty vašeho výchozího agenta; chcete-li dosáhnout na jiného poskytovatele, nejprve ho pojmenujte, například `omarchy agent account use codex side`. Přihlášení, které jste již měli v `~/.claude` nebo `~/.codex`, je účet _Main_ a zůstává tam, kde je. Účet ponechaný bez použití déle než asi osm hodin může zobrazovat _Sign-in required_; klikněte na něj a tento účet znovu přihlaste přímo v panelu, nebo v něm spusťte relaci, která přihlášení sama obnoví. Servery MCP, které jste měli při přidání účtu, s ním přijdou, ale ty, které přidáte později pomocí `claude mcp add`, dosáhnou pouze na účet, ve kterém jste je přidali. Claude Desktop a nástroje nakonfigurované s absolutní cestou k binárnímu souboru CLI přepínání nenásledují. Explicitní `CLAUDE_CONFIG_DIR`, `CODEX_HOME` nebo `GROK_HOME` má přednost před vybraným účtem.

### Diagnostika pádů

Omarchy sleduje pády procesů v systemd-coredump. Když něco spadne na segfault, dostanete oznámení „Process crashed“ — klikněte na něj a pád se předá vašemu výchozímu agentovi spolu s dovedností diagnose-crash od Omarchy, která agenta provede stanovením faktů z core dumpu a rozhodnutím, zda pád stojí za nahlášení upstreamu. Můžete ho také spustit ručně pro jakékoli PID z `coredumpctl list` pomocí `omarchy agent crash <pid>`.

Sledování je ve výchozím nastavení zapnuté. Vypněte ho v _Akce > Přepnout > Záznam pádů_ (nebo pomocí `omarchy toggle crash-capture`) a oznámení přestanou; `omarchy agent crash <pid>` ručně stále funguje.

Pády lze ztišit i po jednotlivých programech, což vám diagnostika na konci nabídne. `omarchy crash mute hyprland` zastaví oznámení pouze pro tento program, `omarchy crash mute hyprland off` je přivede zpět a samotné `omarchy crash mute` vypíše, co jste ztišili. Stejně ochotně přijímá cestu k binárnímu souboru jako jeho název, takže `omarchy crash mute /usr/bin/hyprland` dělá totéž. Název s mezerou uvozujte, například `omarchy crash mute 'Some App'`. Všechno ostatní stále oznamuje a ztišený program stále padá — toto skrývá připomenutí, nic neopravuje.

### Desktopové aplikace

Nabídka _Instalovat > AI_ obsahuje také několik grafických AI aplikací: desktopovou aplikaci ChatGPT, desktopovou aplikaci Claude (linuxová beta od Anthropiku se záložkami Chat, Cowork a Claude Code), Grok Bot pro chatování s modely xAI, Hermes Desktop, OpenClaw a desktopovou aplikaci Perplexity. Grok Bot je desktopová chatovací aplikace. Agent pro kódování je příkaz `grok`.

Hermes Desktop je ten, o kterém je třeba vědět, protože počítač má jeden Hermes a je to Hermes aplikace: Hermes se instaluje pouze prostřednictvím aplikace a příkaz `hermes`, který výchozí agent spouští, patří aplikaci. Výběr Hermese jako výchozího agenta nainstaluje totéž co položka _Instalovat > AI_: balíček a runtime Hermese v `~/.hermes` nastavený vlastním instalátorem Hermese, což poprvé trvá několik minut. Tento runtime je jediný Hermes, který používají příkaz `hermes` v terminálu, výchozí agent i aplikace, a aktualizuje se sám pomocí `hermes update`, místo aby čekal na vydání Omarchy. Jeho instalace také předá Hermesovi motiv Omarchy jako skin s názvem `omarchy`, který následuje každá plocha Hermese, když přepínáte motivy; vyberte si jiný v nastavení vzhledu Hermese nebo pomocí `/skin`, pokud byste raději, aby to nedělal, a Omarchy tuto volbu nechá na pokoji. Odebrání aplikace v _Odebrat > AI_ nejprve zavře Hermese včetně brány, vezme tento runtime s sebou a ponechá vaše chaty, vzpomínky a dovednosti, které Hermes napsal sám pro sebe, pokud neřeknete jinak: zeptá se, s výchozím ne, zda mají odejít i tato data a vaše nastavení připojení.

Zážitek z plochy u OpenClaw je jeho Control UI, které se otevírá jako webová aplikace podložená vlastní místní bránou. OpenClaw žije v `~/.openclaw` a aktualizuje se sám: použijte tlačítko „Update Gateway“ v Control UI nebo spusťte `openclaw update` a brána se restartuje na nové verzi. Omarchy vybírá pouze vydání, od kterého čerstvá instalace začíná. Odebrání OpenClaw v _Odebrat > AI_ vezme službu brány i aplikaci s sebou a poté se zeptá, zda má odejít i `~/.openclaw`, protože tam jsou vaše chaty a přihlašovací údaje vedle samotného OpenClaw a runtime pluginů, které stahuje; výchozí nastavení ho zachovává a opětovná instalace OpenClaw ho znovu převezme.

### Místní LLM

Omarchy doporučuje dva způsoby spouštění místních modelů LLM: LM Studio a Ollama. LM Studio poskytuje rozhraní GUI pro hledání modelů s otevřenými vahami, jejich instalaci a spouštění. Je to skvělý způsob, jak snadno začít. Ollama nabízí CLI, které dělá totéž podobně. Ale pokud jste v místních modelech noví, začal bych s LM Studiem. Oba můžete nainstalovat v _Instalovat > AI_ v nabídce Omarchy.

### Dovednost Omarchy

Dovednosti agentů pomáhají AI používat konkrétní nástroje konkrétním způsobem a Omarchy se dodává s výchozí dovedností pro vyladění systému. Například ladění vaší konfigurace Hyprlandu, úpravy panelu, nebo dokonce vytvoření nového motivu od nuly. Je symlinkována do adresářů dovedností pro Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), Pi (`~/.pi/agent/skills`), Antigravity (`~/.gemini/config/skills`), Hermes (`~/.hermes/skills` a každý `~/.hermes/profiles/*/skills`) a obecné umístění `~/.agents/skills`, takže ji většina harnessů zachytí automaticky.

Měli byste ale tuto dovednost považovat za experimentální. Různé modely ji používají s různým efektem. Nejlepší je nejprve běžet v plánovacím režimu, abyste měli představu, co by agent rád změnil. A pak buďte připraveni vrátit změny zpět, nebo dokonce vyvolat `omarchy reinstall configs`, pokud agent všechno rozbije.
