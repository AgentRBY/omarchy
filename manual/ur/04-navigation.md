# نیویگیشن

Omarchy میں سب کچھ کی بورڈ کے ذریعے ہوتا ہے — _ہر چیز!_ جب سسٹم پہلی بار شروع ہوتا ہے تو، آپ لفظی طور پر ماؤس سے کچھ نہیں کر سکتے۔ لیکن آپ Omarchy Menu ظاہر کرنے کے لیے `Super + Space` دبا سکتے ہیں اور یہاں سے تقریباً سب کچھ کر سکتے ہیں۔

لیکن Omarchy مینیو کا مقصد اکثر اوقات سسٹم چلانے کا مرکزی طریقہ بننا بھی نہیں ہے۔ ہم اس سے زیادہ تیز ہو سکتے ہیں! تمام اہم ترین ایپلیکیشنز براہ راست انفرادی ہاٹ کیز سے منسلک ہیں۔ آپ ٹرمینل `Super + Return` سے اور براؤزر `Super + Shift + Return` سے شروع کرتے ہیں۔ ایک کے بعد دوسرا کر کے آزمائیں، اور آپ Hyprland کی ٹائلنگ کا جادو عملی شکل میں دیکھیں گے:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

اس کے بعد آپ انہیں ساتھ ساتھ رکھنے کے بجائے ایک دوسرے کے اوپر اسٹیک کرنے کے لیے `Super + J` دبا سکتے ہیں:

 ![navigation-stacked](images/navigation-stacked.webp)

انہیں ان کی ساتھ ساتھ والی جگہوں پر واپس لانے کے لیے دوبارہ `Super + J` دبائیں۔ پھر براؤزر پر ہوتے ہوئے ونڈوز کو تبدیل کرنے کے لیے `Super + Shift + Arrow Right` آزمائیں۔

اب Activity مانیٹر شروع کرنے کے لیے `Super + Ctrl + T` آزمائیں۔ وہ تیرتی ہوئی ونڈو کے طور پر ظاہر ہو گا۔ آپ اسے `Super + T` استعمال کر کے ٹائل کر سکتے ہیں (اور اسے دوبارہ تیرتا ہوا بنانے کے لیے دوبارہ یہی دبائیں)۔ اب فائلز مینیجر کھولنے کے لیے `Super + Shift + F` دبائیں۔ آپ کے پاس ایک صاف ستھرا چار طرفہ سیٹ اپ ہو گا:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

آپ `Super + Arrow` سے اس ونڈو کے درمیان نیویگیٹ کرتے ہیں جسے آپ فعال چاہتے ہیں۔ یہ فوکس تبدیل کرے گا اور کرسر کو نئی ایپلیکیشن کے مرکز میں لے جائے گا۔

اگر آپ `Super + Shift + 2` دبائیں تو، آپ موجودہ فوکس شدہ ایپلیکیشن کو دوسرے ورک اسپیس پر منتقل کر دیں گے۔ `Super + Shift + 1` اسے واپس لے جاتا ہے۔ (اور `Super + Shift + Alt + 2` موجودہ فوکس شدہ ایپلیکیشن کو دوسرے ورک اسپیس پر اس پر جائے بغیر منتقل کر دے گا)۔

اگر آپ `Super` دبائے رکھیں اور ماؤس سے ونڈو پر کلک کریں تو، آپ اس کی جگہ دوبارہ ترتیب دے سکیں گے۔ اگر آپ `Super` دبائے رکھیں اور ماؤس کا دایاں بٹن استعمال کریں تو، آپ آزادی سے ونڈو کا سائز تبدیل کر سکتے ہیں۔

آپ `Super + W` یا `Super + Q` پر ونڈو بند کرتے ہیں (اور `Ctrl + Alt + Delete` پر تمام ونڈوز بند کرتے ہیں)۔

آپ `Super + F` سے فل اسکرین بھی جا سکتے ہیں یا یہاں تک کہ صرف فل وِڈتھ (اوپری بار کو برقرار رکھتے ہوئے) `Super + Alt + F` سے یا ونڈو کے اندر فل اسکرین `Super + Ctrl + F` سے (YouTube کے لیے اچھا ہے!)۔

### Dwindle بمقابلہ اسکرولنگ لے آؤٹ

Omarchy کا ڈیفالٹ لے آؤٹ dwindle کہلاتا ہے۔ یہ ایک واحد ورک اسپیس پر کھولنے والی تمام ونڈوز کو ہر وقت نظر آتا رکھتا ہے، چاہے انہیں چھوٹا ہی کیوں نہ کرنا پڑے۔

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

لیکن آپ ورک اسپیس کو اسکرولنگ لے آؤٹ میں تبدیل کرنے کا انتخاب بھی کر سکتے ہیں جہاں ونڈوز ڈسپلے کے نظر آنے والے کنارے سے پرے، ساتھ ساتھ قطار میں کھڑی ہوتی ہیں۔ آپ `Super + L` کے ذریعے ایک واحد ورک اسپیس کو اس لے آؤٹ میں تبدیل کرتے ہیں۔

`Super + L` دوبارہ دبانے سے ورک اسپیس تیرتا ہوا ہو جاتا ہے، جہاں ونڈوز آزادانہ طور پر ایک دوسرے پر چڑھتی ہیں اور آپ انہیں خود رکھتے ہیں، اور تیسری بار دبانے سے یہ dwindle پر واپس آ جاتا ہے۔ `Super + Alt + L` ان میں دوسرے طریقے سے جاتا ہے۔ ایک ونڈو جو ویسے بھی تیرتی ہے — وہ جسے آپ نے `Super + T` سے باہر نکالا، یا ایسی ایپ جو ہمیشہ تیرتی ہوئی کھلتی ہے — جب ورک اسپیس واپس ٹائلنگ پر جاتا ہے تو تیرتی رہتی ہے۔ اوپری بار جس ورک اسپیس پر آپ ہیں، اسے اس کے لے آؤٹ سے نشان زد کرتا ہے: dwindle کے لیے مربع، اسکرولنگ کے لیے دائرہ، اور تیرنے کے لیے مثلث۔ اس نشان پر کلک کرنے سے بھی لے آؤٹ چکر لگاتا ہے۔

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

یہ انتخاب فی ورک اسپیس ہے، اور یہ برقرار رہتا ہے۔ لہٰذا آپ براؤزنگ کے لیے ورک اسپیس 1 کو dwindle پر اور کوڈ کے لیے ورک اسپیس 2 کو اسکرولنگ پر رکھ سکتے ہیں، اور ری اسٹارٹ کے بعد وہ اسی طرح واپس آئیں گے۔

اگر آپ اسکرولنگ لے آؤٹ کو بطور ڈیفالٹ استعمال کرنا چاہتے ہیں تو، آپ اسے `~/.config/hypr/looknfeel.lua` میں سیٹ کر سکتے ہیں:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### تیرتے ہوئے ورک اسپیسز

ایک تیرتا ہوا ورک اسپیس روایتی ڈیسک ٹاپ کی طرح کام کرتا ہے: ونڈوز ایک دوسرے پر چڑھتی ہیں، اور آپ انہیں خود حرکت دیتے اور سائز دیتے ہیں۔ ہر ونڈو کو آپ کے تھیم کے رنگوں میں ٹائٹل بار ملتا ہے، جس میں کم سے کم کرنے، زیادہ سے زیادہ کرنے اور بند کرنے کے بٹن ہوتے ہیں۔ `Super + M` فوکس شدہ ونڈو کو بھی کم سے کم کر دیتا ہے۔ کم سے کم کی گئی ونڈو ڈاک میں انتظار کرتی ہے؛ اسے واپس لانے کے لیے اس کی ایپ پر کلک کریں۔ کسی ونڈو کو آگے لانے کے لیے اس پر کلک کریں۔ کسی بھی کنارے یا کونے سے اس کا سائز تبدیل کریں۔ اوپری بار کو نظر میں رکھتے ہوئے ونڈو کو زیادہ سے زیادہ کرنے کے لیے ٹائٹل بار پر ڈبل کلک کریں، اور اس کا پرانا سائز واپس حاصل کرنے کے لیے دوبارہ کریں۔

ایک تیرتا ہوا ورک اسپیس ایک ڈاک بھی دکھاتا ہے، جس میں آپ کی پِن کی ہوئی ایپس، چل رہی ہر چیز، اور ایپس بٹن کے پیچھے ہر ایپ کی گرڈ ہوتی ہے، جسے `Super + Alt + Space` اور Omarchy مینیو میں _ایپس_ بھی کھولتے ہیں۔ گرڈ پر کسی ایپ پر دائیں کلک کریں، یا `Delete` دبائیں، اسے ان انسٹال کرنے کے لیے۔ ایپ کھولنے کے لیے، یا اس کی ونڈو کو آگے لانے کے لیے، ایپ پر کلک کریں؛ اس کی ونڈوز میں چکر لگانے کے لیے دوبارہ کلک کریں۔ درمیانی کلک ایک نئی ونڈو کھولتا ہے۔ آئی کون کو منتقل کرنے کے لیے اسے ڈاک کے ساتھ گھسیٹیں؛ چل رہی ایپ کو دوسروں کے درمیان گھسیٹنا اسے وہیں رکھتا ہے۔ ایپ کو ڈاک میں رکھنے، اسے نکالنے، یا اسے بند کرنے کے لیے دائیں کلک کریں۔ ڈاک فل اسکرین ونڈو کی راہ سے ہٹ جاتا ہے۔ ڈاک کو دوسرے کنارے پر منتقل کرنے یا اسے اس وقت تک چھپانے کے لیے جب تک پوائنٹر اس کے کنارے تک نہ پہنچ جائے، ایپس بٹن پر دائیں کلک کریں۔ یہ جگہ _ٹریگر > ظاہری شکل > Dock > Dock Position_ کے نیچے بھی ہے، اور `omarchy dock position left` اور `omarchy dock autohide on` دونوں کو ٹرمینل سے سیٹ کرتے ہیں۔ جن ایپس کو آپ ڈاک میں رکھتے ہیں، جب وہ نہیں چل رہی ہوتیں تو مدھم ہوتی ہیں۔

نئے ورک اسپیسز، اور کوئی بھی جسے آپ نے `Super + L` سے اپنا لے آؤٹ نہیں دیا، ڈیفالٹ لے آؤٹ استعمال کرتے ہیں۔ ڈیفالٹ تبدیل کرنے سے بغیر ونڈوز والا ہر ورک اسپیس اس پر ری سیٹ ہو جاتا ہے، جبکہ جس پر ونڈوز ہوں وہ اسی لے آؤٹ کو برقرار رکھتا ہے جو اس کے پاس ہے۔ اسے _ٹریگر > ظاہری شکل > Workspace Layout_ کے نیچے منتخب کریں: Tiling، Scrolling یا Floating۔ `omarchy-hyprland-workspace-layout-default scrolling` اسے ٹرمینل سے سیٹ کرتا ہے۔

### ونڈوز کو گروپ کرنا

ونڈوز کو `Super + G` استعمال کر کے گروپ کیا جا سکتا ہے۔ ایک بار جب آپ گروپ میں ہوں تو، جب وہ فعال ہے اس دوران آپ جو بھی ونڈو شروع کریں گے وہ گروپ سے تعلق رکھے گی۔ آپ ان گروپ شدہ ونڈوز کے درمیان `Super + Ctrl + Arrow Left/Right` استعمال کر کے منتقل ہو سکتے ہیں یا ترتیب سے براہ راست گروپ شدہ ونڈو پر جانے کے لیے `Super + Alt + 1/2/3/4` استعمال کر سکتے ہیں۔

آپ `Super + Alt + G` سے ونڈو کو گروپنگ سے باہر منتقل کر سکتے ہیں یا دوبارہ `Super + G` دبا کر پورے گروپ کو جدا کر سکتے ہیں۔ آخر میں، آپ `Super + Alt + Arrows` سے گروپ کے باہر کی ونڈوز کو اس میں منتقل کر سکتے ہیں۔

### ونڈوز کو باہر نکالنا

آپ `Super + O` سے ونڈو کو اس کی ورک اسپیس مختص کاری سے باہر نکال سکتے ہیں۔ یہ اسے تیرتی ہوئی ونڈو کے طور پر پِن کر دے گا جو آپ جس بھی ورک اسپیس پر جائیں وہاں آپ کی پیروی کرتی ہے۔ ویڈیو پلیئرز وغیرہ کے لیے بہترین۔

 ![navigation-popped-window](images/navigation-popped-window.webp)

### اسکریچ پیڈ ورک اسپیس

آخر میں، ایک خاص اسکریچ پیڈ ورک اسپیس ہے جو آپ فی الحال جس بھی ورک اسپیس پر ہیں اس کے اوپر گر پڑتا ہے، بالکل Quake کنسول کی طرح۔ اسے `Super + Grave` یا `Super + S` سے ٹوگل کریں، اور `Super + Shift + Grave` یا `Super + Alt + S` استعمال کر کے وہاں ونڈو رکھیں۔

یہ خاص طور پر ایجنٹ چلانے والے ٹرمینل کے لیے، یا ان کنٹرولز کے لیے اچھا کام کرتا ہے جن کے ساتھ آپ موجودہ ورک اسپیس چھوڑے بغیر تیزی سے تعامل کرنا چاہتے ہیں۔ ونڈو کو اسکریچ پیڈ سے ہٹانے کے لیے، اسے براہ راست کسی اور ورک اسپیس پر بھیجیں جیسے `Super + Shift + 1`۔

جب اسکریچ پیڈ ایک واحد ونڈو رکھتا ہے تو، یہ اسکرین پھیلانے کے بجائے مرکز میں واقع پینل کے طور پر نیچے آتا ہے۔ اس پر دوسری ایپ رکھیں اور یہ مکمل چوڑائی پر واپس چلا جاتا ہے، تاکہ دونوں کو ساتھ ساتھ بیٹھنے کی جگہ ملے۔

### اس کی عادت ڈالنے میں کچھ وقت لگتا ہے!

اپنے ڈیسک ٹاپ کو اس طرح نیویگیٹ کرنے کی عادت ڈالنے میں تھوڑا وقت لگتا ہے، لیکن ایک بار جب آپ ڈال لیتے ہیں تو، روایتی ماؤس پر مبنی ڈیسک ٹاپ تجربے کی طرف واپس جانا مشکل ہو جائے گا!
