# ہارڈویئر تصدیق

### فنگر پرنٹ تصدیق

بہت سے لیپ ٹاپس تصدیق کے لیے فنگر پرنٹ سینسر کے ساتھ آتے ہیں۔ آپ Omarchy مینیو (`Super + Space`) میں _سیٹ اپ > Security > Fingerprint_ چلا کر اسے Omarchy کے ساتھ استعمال کر سکتے ہیں۔

یہ فنگر پرنٹ پیکیج انسٹال کرے گا، آپ کا پرنٹ لے گا، اس کی تصدیق کرے گا، اور آپ لاک اسکرین سے کھولنے (جسے آپ `Super + Ctrl + L` سے چلا سکتے ہیں)، sudo موڈ میں داخل ہونے، اور سسٹم پرامپٹس کی منظوری دینے کے لیے اپنا فنگر پرنٹ استعمال کرنے کے لیے تیار ہوں گے۔

جب آپ کے لیپ ٹاپ کا ڈھکن بند ہو تو فنگر پرنٹ پرامپٹ خود بخود چھوڑ دیا جاتا ہے، تاکہ آپ ایسے سینسر کے انتظار میں نہ رہیں جہاں آپ پہنچ نہیں سکتے اور سیدھا پاس ورڈ پرامپٹ پر چلے جائیں۔ اگر آپ کو کسی خارجی کی بورڈ پر کام کرنا پڑے جس میں سینسر نہ ہو تو، جب `sudo` کے دوران آپ سے فنگر پرنٹ مانگا جائے تو بس `CTRL + C` دبا دیں۔

آپ Omarchy مینیو میں _ہٹائیں > Security > Fingerprint_ کے تحت فنگر پرنٹ تصدیق ہٹا سکتے ہیں۔

### Fido2 تصدیق

اگر آپ Fido2 ڈیوائس استعمال کر رہے ہیں تو آپ اسے Omarchy مینیو (`Super + Space`) میں _سیٹ اپ > Security > Fido2_ کے ذریعے `sudo` تصدیق کے لیے سیٹ اپ کر سکتے ہیں۔ تاہم یہ `sudo` اور سسٹم منظوری پرامپٹس کا احاطہ کرتا ہے، آپ کے کمپیوٹر کو کھولنے کا نہیں۔

آپ Omarchy مینیو میں _ہٹائیں > Security > Fido2_ کے تحت fido2 تصدیق ہٹا سکتے ہیں۔
