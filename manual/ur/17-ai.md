# AI

Omarchy AI کوڈنگ ایجنٹس کو فرسٹ کلاس شہری مانتا ہے، لیکن یہ آپ کے لیے پسندیدہ نہیں چنتا۔ اس کے بجائے، ہر بڑا کوڈنگ ایجنٹ CLI پہلے سے لیزی لوڈڈ لانچر کے طور پر وائرڈ آتا ہے۔ لانچرز `~/.local/bin/` میں چھوٹے [mise](https://mise.jdx.dev/) کے زیر انتظام اسٹب ہیں، لہٰذا جب تک آپ واقعی ان میں سے ایک پہلی بار نہ چلائیں، کچھ ڈاؤن لوڈ نہیں ہوتا۔ Hermes اس کی استثنا ہے: اس کے لیے کچھ بھی اسٹب نہیں ہے، اور اسے منتخب کرنے سے Hermes Desktop انسٹال ہو جاتا ہے، جیسا کہ _ڈیسک ٹاپ ایپس_ نیچے وضاحت کرتی ہیں۔ ان میں سے کسی کو بھی طلب کریں اور جب اشارہ کیا جائے تو تصدیق کریں:

`ori` الگ تھلگ ہے: یہ دوسرے ہارنسز کو OpenRouter کے پورے ماڈل کیٹلاگ کے خلاف چلاتا ہے، لہٰذا `ori claude`، `ori codex` یا `ori opencode` ان ایجنٹس کو اس ماڈل پر شروع کرتے ہیں جس کی طرف آپ اشارہ کریں، اور `ori code` Ori کا اپنا ایجنٹ ہے۔

کسی اضافی CLI کو بھی اسی طرح لپیٹنے کے لیے، `omarchy-mise-install <package> [command-name]` چلائیں۔ اسٹب اس ہر چیز کے ساتھ تازہ رکھے جاتے ہیں جس کا انتظام mise کرتا ہے جب آپ `omarchy update` (یا `mup` عرف) چلاتے ہیں۔

`grok` mise کے فرسٹ پارٹی `grok` پیکیج کے ذریعے انسٹال ہوتا ہے، `claude` اور `codex` کی طرح۔ `grok` چلائیں، یا اسے _سیٹ اپ > Defaults > Agent_ کے تحت منتخب کریں۔ x.ai پر `curl | bash` انسٹالر کو چھوڑ دیں۔ وہ راستہ `~/.grok/bin` میں دوسری کاپی رکھتا ہے، اسے `PATH` پر آگے بڑھاتا ہے، اور Omarchy کے ریپر کو اوور رائٹ کر دیتا ہے۔

### ڈیفالٹ ایجنٹ

`omarchy default agent <name>` سے یا Omarchy Menu (`Super + Space`) میں _سیٹ اپ > Defaults > Agent_ کے تحت اپنا ڈیفالٹ ایجنٹ منتخب کریں۔ اگر ایجنٹ ابھی انسٹال نہیں ہوا تو، اسے منتخب کرنے سے یہ پہلے انسٹال ہو جاتا ہے۔ نیا Omarchy آپ کو ایک بار کی نوٹیفکیشن کے ساتھ یہ انتخاب کرنے کی دعوت دے گا۔

Claude منتخب کرنے سے Chromium، Chrome، Brave، Brave Origin اور Edge کے لیے اس کی براؤزر ایکسٹینشن سیٹ اپ کرنے کی کوشش بھی ہوتی ہے۔ ایکسٹینشن سیٹ اپ تمام صارفین پر لاگو ہوتا ہے اور آپ کا سسٹم پاس ورڈ مانگ سکتی ہے؛ منسوخ یا ناکام ایکسٹینشن انسٹال پھر بھی Claude کو منتخب اور لانچ کر دیتا ہے۔ اپنا براؤزر دوبارہ شروع کریں، اگر اشارہ کیا جائے تو ایکسٹینشن فعال کریں، اور اسے جوڑنا مکمل کرنے کے لیے Claude میں سائن ان کریں۔ کنکشن چیک کرنے کے لیے Claude میں `/chrome` چلائیں۔ Firefox اور Zen اس ایکسٹینشن کی حمایت نہیں کرتے۔ اگر یہ سیٹ اپ شامل کیے جانے سے پہلے Claude آپ کا ڈیفالٹ تھا تو، ایکسٹینشن انسٹال کرنے کے لیے اسے دوبارہ منتخب کریں۔

[Muse Code](https://dev.meta.ai) — Meta کا `muse` — دوسرے ایجنٹس کی طرح پہلے سے انسٹال شدہ mise اسٹب استعمال کرتا ہے۔ اسے بطور ڈیفالٹ منتخب کرنے سے mise کے HTTP بیک اینڈ کے ذریعے Meta کا سرکاری لانچر انسٹال ہوتا ہے۔ لانچر آپ کی مشین کے لیے نیٹو بائنری کی توثیق اور اسے اپ ڈیٹ کرتا ہے۔

آپ کے منتخب کر لینے کے بعد، `Super + Shift + Ctrl + A` ڈیفالٹ ایجنٹ کو خصوصی ٹرمینل ونڈو میں لانچ کرتا ہے (یا اگر آپ نے ابھی منتخب نہیں کیا تو پِکر لے آتا ہے)۔ آپ اسے براہ راست کسی کام میں بھی `omarchy agent prompt "Review this project"` سے لانچ کر سکتے ہیں۔ اس طرح لانچ کیے گئے ایجنٹ اپنے اپنے 'مت روکو پوچھنے کے لیے' موڈز میں بلا نگرانی چلتے ہیں، لہٰذا ان کے واقعی کچھ کرنے کے لیے تیار رہیں! اور چونکہ ایجنٹ آپ کی ہوم ڈائریکٹری کے لیے اعتماد یاد رکھنے سے انکار کرتے ہیں، `$HOME` سے لانچز اس کے بجائے `~/Work` میں شروع ہوتی ہیں۔

ٹرمینل شارٹ کٹ بھی ہیں: `a` موجودہ ٹرمینل میں ڈیفالٹ ایجنٹ کو ان لائن چلاتا ہے، جبکہ `c`، `cx` اور `cy` OpenCode، Claude Code اور Codex کو براہ راست شروع کرتے ہیں (دوبارہ ان کے خود منظور موڈز میں)۔ تھیم کی تبدیلیاں ایجنٹس کے ساتھ بھی سنک ہو جاتی ہیں: جب آپ Omarchy تھیم تبدیل کرتے ہیں تو Claude Code، Pi، OpenCode اور Hermes (جیسے ہی Omarchy نے اسے انسٹال کیا) سب ساتھ چلتے ہیں۔

### ایجنٹس پینل

اوپری بار میں ایجنٹس کا آئیکن ہے۔ آپ کے ایجنٹ سیٹ اپ کرنے سے پہلے، اس کا پینل آپ کو Claude، Codex یا Grok میں سائن ان کرانے میں مدد کرتا ہے، اور پہلا آپ کا ڈیفالٹ ایجنٹ بن جاتا ہے۔ اس کے بعد، پینل ہر سبسکرپشن کو ایک صفحے پر رکھتا ہے: ہر ایجنٹ اور اکاؤنٹ اس کے پلان کے ساتھ، اس کے 5 گھنٹے کے سیشن اور ہفتہ وار حدود میں سے ہر ایک کے لیے میٹر جس میں ری سیٹ تک کا وقت ہو (عین فیصد کے لیے ہوور کریں)، یا بقیہ پری پیڈ بیلنس، ایک لائن کے تحت جو ان تمام میں آپ نے کیا استعمال کیا ہے اس میں گردش کرتی ہے، جیسے اس ہفتے کے ٹوکن اور آپ کا سب سے زیادہ استعمال شدہ ماڈل۔ _Make something_ کے تحت یہ نئی تھیم، پلگ ان، یا ایپ کے لیے اسٹارٹر پرومپٹس پیش کرتا ہے جو کام کو آپ کے ڈیفالٹ ایجنٹ کے حوالے کر دیتے ہیں۔ ایپس اسی طرح بنائی جاتی ہیں جس طرح Omarchy کی اپنی Hype، Monologue اور Omacut ہیں، C++ اور Qt Quick میں، omarchy-app ایجنٹ اسکل کی پیروی کرتے ہوئے، اور جن کمپائلر اور Qt اجزاء کی انہیں ضرورت ہوتی ہے وہ انسٹال شدہ آتے ہیں۔ Claude Code، Codex، Grok اور Fireworks باکس سے باہر شامل ہیں۔

پینل کے لیے بار آئیکن پر بایاں کلک، اپنا ڈیفالٹ ایجنٹ لانچ کرنے کے لیے دایاں کلک۔ اس کے پیچھے استعمال کے ریکارڈ `omarchy agent usage-update` سے ہر 15 منٹ میں دوبارہ بنائے جاتے ہیں، اور پینل سنک شدہ فولڈر کے ذریعے آپ کی دیگر مشینوں کے استعمال کو بھی ملا سکتا ہے۔ مکمل سیٹنگز کے لیے `$OMARCHY_PATH/shell/plugins/agents/` کے تحت README دیکھیں۔

### چند سبسکرپشنز

اگر آپ ایک سے زیادہ Claude، Codex یا Grok پلان کی ادائیگی کرتے ہیں — مثال کے طور پر ذاتی Max اور ورک والا — Omarchy ان سب کو سائن ان رکھ سکتی ہے اور ان کے درمیان حرکت کر سکتی ہے۔ ایجنٹس پینل میں + سے سبسکرپشن شامل کریں، جو آپ کو بالکل وہیں اس میں لے جاتا ہے، یا `omarchy agent account add claude Work` (یا `codex`، یا `grok`) سے۔ اگر CLI غائب ہو تو یہ اسے انسٹال کرتا ہے۔ پرووائیڈر کے لیے پہلا اکاؤنٹ آپ کے عام براؤزر کے ذریعے سائن ان کرتا ہے، بالکل وہیں جہاں CLI ہمیشہ دیکھتا ہے۔ اس کے بعد ہر ایک پرائیویٹ ونڈو کے ذریعے سائن ان کرتا ہے، تاکہ جس اکاؤنٹ میں آپ کا براؤزر پہلے سے سائن ان ہے وہ غلطی سے نہ اٹھ جائے؛ اس اکاؤنٹ کے طور پر وہیں سائن ان کریں جسے آپ شامل کر رہے ہیں، اور پہلے کوئی پرائیویٹ ونڈو جو آپ نے پہلے سے کھول رکھی ہو اسے بند کر دیں۔ ایسا کرنے کے لیے کبھی CLI سے لاگ آؤٹ نہ ہوں: لاگ آؤٹ کرنے سے محفوظ سائن ان منسوخ ہو جاتا ہے، اور اس اکاؤنٹ کو دوبارہ شامل کرنا ہو گا۔

فی پرووائیڈر ایک اکاؤنٹ فعال ہوتا ہے، اور ہر نیا سیشن بطور یہی شروع ہوتا ہے: `cx`، `cy`، سادہ `claude`، `codex`، یا `grok`، `omarchy agent` کے ذریعے لانچ کی گئی کوئی بھی چیز، اور اسکرپٹس یا ایڈیٹرز جو `PATH` پر CLI تلاش کرتے ہیں۔ `omarchy agent account use work` سے تبدیل کریں (اور `omarchy agent account use main` سے واپس)، یا پینل میں اکاؤنٹ کے نمبر کو دبا کر پھر `Enter` (یا اس کے Use بٹن پر کلک کر کے)۔ پہلے سے چل رہے سیشن اسی اکاؤنٹ پر رہتے ہیں جس سے انہوں نے شروع کیا تھا۔ گفتگو کی تاریخ، سیٹنگز، اسکلز اور پلگ انز تمام اکاؤنٹس میں مشترک ہیں، لہٰذا اسی فولڈر میں `claude --continue` وہیں سے شروع ہوتا ہے جہاں آپ نے نئے اکاؤنٹ پر چھوڑا تھا۔

ایک سے زیادہ اکاؤنٹ کے ساتھ، پینل ہر اکاؤنٹ کی حدود ساتھ ساتھ دکھاتا ہے، فعال والے کو نشان زد کر کے۔ بطور ڈیفالٹ Omarchy آپ کو مطلع کرتا ہے جب فعال اکاؤنٹ کسی حد کا 95% عبور کر لیتا ہے، اور نوٹیفکیشن پر کلک کرنے سے سب سے زیادہ گنجائش والے اکاؤنٹ پر جا گِرتی ہے۔ پینل میں اکاؤنٹ کی لائن پر ہوور کریں اور Use کے ساتھ ظاہر ہونے والے Autoswitch پر کلک کریں (یا `m` دبائیں)، یا `omarchy agent account mode auto` چلائیں، تاکہ یہ اس کے بجائے خود تبدیل ہو؛ جب یہ آن ہو تو، Autoswitch، Use کی جگہ لے لیتا ہے، اور اس پر دوبارہ کلک کرنے سے یہ دوبارہ مطلع کرنے پر آ جاتا ہے۔ حد تبدیل کرنے کے لیے نمبر شامل کریں، جیسے `omarchy agent account mode auto 90` میں۔ اگر ہر اکاؤنٹ حد سے اوپر ہو تو، آپ کو اس کے بارے میں ایک بار سنایا جائے گا، اس کے ساتھ کہ کون سا اکاؤنٹ پہلے خالی ہوتا ہے۔ جب فعال اکاؤنٹ اپنی حد کے 15 پوائنٹس کے اندر ہوتا ہے (ڈیفالٹ پر 80%)، تو اس کی حدود ہر 15 کے بجائے ہر تین منٹ میں چیک کی جاتی ہیں۔

`omarchy agent account list` ہر اکاؤنٹ اور اس کی تازہ ترین حدود دکھاتا ہے، `omarchy agent account remove work` ایک کو بھول جاتا ہے، اور `omarchy agent account rename primary Hey` ایک کا نام تبدیل کر دیتا ہے (یا پینل میں اکاؤنٹ کے نام پر کلک کریں)۔ یہ کمانڈز آپ کے ڈیفالٹ ایجنٹ کے اکاؤنٹس پر کام کرتی ہیں؛ دوسرے پرووائیڈر تک پہنچنے کے لیے، پہلے اس کا نام لیں، جیسے `omarchy agent account use codex side` میں۔ جو لاگ ان آپ کے پاس پہلے سے `~/.claude` یا `~/.codex` میں تھا، وہ _Main_ اکاؤنٹ ہے اور وہیں رہتا ہے جہاں ہے۔ آٹھ گھنٹے سے زیادہ غیر استعمال شدہ رہا اکاؤنٹ _Sign-in required_ دکھا سکتا ہے؛ بالکل پینل میں اس اکاؤنٹ کو دوبارہ سائن ان کرنے کے لیے اس پر کلک کریں، یا اس میں سیشن شروع کریں، جو سائن ان کو خود تازہ کر لیتا ہے۔ جب اکاؤنٹ شامل کیا گیا تھا اس وقت آپ کے پاس موجود MCP سرورز اس کے ساتھ آ جاتے ہیں، لیکن جو آپ بعد میں `claude mcp add` سے شامل کرتے ہیں وہ صرف اسی اکاؤنٹ تک پہنچتے ہیں جس میں آپ نے انہیں شامل کیا تھا۔ Claude Desktop اور CLI بائنری کے مطلق راستے سے کنفیگر شدہ ٹولز اس تبدیلی کی پیروی نہیں کرتے۔ واضح `CLAUDE_CONFIG_DIR`، `CODEX_HOME`، یا `GROK_HOME` منتخب اکاؤنٹ پر ترجیح لیتا ہے۔

### کریش کی تشخیص

Omarchy پروسیس کریشز کے لیے systemd-coredump پر نظر رکھتا ہے۔ جب کچھ سیگ فولٹ ہوتا ہے تو، آپ کو "Process crashed" نوٹیفکیشن ملے گی — اس پر کلک کریں، اور کریش آپ کے ڈیفالٹ ایجنٹ کے حوالے کر دیا جاتا ہے Omarchy کی diagnose-crash اسکل کے ساتھ، جو ایجنٹ کو کور ڈمپ سے حقائق قائم کرنے اور یہ فیصلہ کرنے میں لے جاتی ہے کہ آیا کریش اپ اسٹریم رپورٹ کرنے کے قابل ہے۔ آپ اسے `coredumpctl list` سے کسی بھی PID کے خلاف `omarchy agent crash <pid>` سے ہاتھ سے بھی چلا سکتے ہیں۔

نظر رکھنا ڈیفالٹ طور پر آن ہے۔ اسے _ٹریگر > Toggle > Crash Capture_ کے تحت (یا `omarchy toggle crash-capture` سے) آف کریں اور نوٹیفکیشنز رک جاتی ہیں؛ `omarchy agent crash <pid>` ہاتھ سے اب بھی کام کرتا ہے۔

کریشز کو ایک وقت میں ایک پروگرام خاموش بھی کیا جا سکتا ہے، جو تشخیص آخر میں آپ کو پیش کرتی ہے۔ `omarchy crash mute hyprland` صرف اس پروگرام کے لیے نوٹیفکیشنز روکتا ہے، `omarchy crash mute hyprland off` انہیں واپس لے آتا ہے، اور صرف `omarchy crash mute` اس کی فہرست دیتا ہے جو آپ نے خاموش کیا ہے۔ یہ بائنری کا راستہ بھی اس کے نام کی خوشی کے ساتھ لیتا ہے، لہٰذا `omarchy crash mute /usr/bin/hyprland` یہی کرتا ہے۔ جس نام میں جگہ ہو اسے اقتباس میں رکھیں، جیسے `omarchy crash mute 'Some App'` میں۔ باقی سب اب بھی مطلع کرتے ہیں، اور خاموش پروگرام اب بھی کریش ہوتا ہے — یہ یاد دہانی چھپاتا ہے، یہ کچھ ٹھیک نہیں کرتا۔

### ڈیسک ٹاپ ایپس

_انسٹال کریں > AI_ مینیُو میں کچھ گرافیکل AI ایپس بھی ہیں: ChatGPT ڈیسک ٹاپ ایپ، Claude ڈیسک ٹاپ ایپ (Anthropic کا Linux بیٹا، Chat، Cowork اور Claude Code ٹیبز کے ساتھ)، xAI کے ماڈل کے ساتھ چیٹ کے لیے Grok Bot، Hermes Desktop، OpenClaw اور Perplexity ڈیسک ٹاپ ایپ۔ Grok Bot ڈیسک ٹاپ چیٹ ایپ ہے۔ کوڈنگ ایجنٹ `grok` کمانڈ ہے۔

Hermes Desktop وہ واحد ہے جس کے بارے میں جاننا ہو، کیونکہ ایک مشین میں ایک Hermes ہوتا ہے، اور وہ ایپ کا ہے: Hermes صرف اور صرف ایپ کے ذریعے انسٹال ہوتا ہے، اور ڈیفالٹ ایجنٹ جو `hermes` کمانڈ چلاتا ہے وہ ایپ کا ہے۔ Hermes کو ڈیفالٹ ایجنٹ کے طور پر منتخب کرنے سے وہی چیز انسٹال ہوتی ہے جو _انسٹال کریں > AI_ اندراج کرتا ہے: پیکیج، اور `~/.hermes` کے تحت Hermes رن ٹائم جو Hermes کے اپنے انسٹالر نے سیٹ اپ کیا، جس میں پہلی بار چند منٹ لگتے ہیں۔ وہ رن ٹائم وہی واحد Hermes ہے جسے ٹرمینل `hermes` کمانڈ، ڈیفالٹ ایجنٹ اور ایپ سب استعمال کرتے ہیں، اور یہ Omarchy ریلیز کا انتظار کیے بغیر، `hermes update` سے خود کو اپ ڈیٹ کرتا ہے۔ اسے انسٹال کرنے سے Hermes کو Omarchy تھیم `omarchy` نامی سکن کے طور پر بھی حوالے ہو جاتی ہے، جس کی پیروی ہر Hermes سطح آپ کے تھیمز تبدیل کرنے پر کرتی ہے؛ Hermes کی Appearance سیٹنگز کے تحت یا `/skin` سے کوئی اور منتخب کریں اگر آپ چاہیں کہ یہ نہ کرے، اور Omarchy اس انتخاب کو تنہا چھوڑ دیتی ہے۔ _ہٹائیں > AI_ کے تحت ایپ ہٹانے سے پہلے Hermes بند ہو جاتا ہے، گیٹ وے سمیت، وہ رن ٹائم اپنے ساتھ لے جاتا ہے، اور آپ کی چیٹس، یادیں، اور وہ اسکلز جو Hermes نے اپنے لیے لکھی تھیں برقرار رکھتا ہے جب تک آپ اس سے دوسری صورت نہ کہیں: یہ پوچھتا ہے، ڈیفالٹ طور پر نہیں، آیا وہ ڈیٹا اور آپ کی کنکشن سیٹنگز بھی جانی چاہئیں۔

OpenClaw کا ڈیسک ٹاپ تجربہ اس کا Control UI ہے، جو اپنے مقامی گیٹ وے کی پشت پناہی سے ویب ایپ کے طور پر کھلتا ہے۔ OpenClaw `~/.openclaw` میں رہتا ہے اور خود کو اپ ڈیٹ کرتا ہے: Control UI کا "Update Gateway" بٹن استعمال کریں یا `openclaw update` چلائیں، اور گیٹ وے نئے ورژن پر دوبارہ شروع ہو جاتا ہے۔ Omarchy صرف اس ریلیز کا انتخاب کرتا ہے جس سے تازہ انسٹال شروع ہوتا ہے۔ _ہٹائیں > AI_ کے تحت OpenClaw ہٹانے سے گیٹ وے سروس اور ایپ اس کے ساتھ جاتی ہیں اور پھر پوچھتا ہے کہ آیا `~/.openclaw` بھی جانا چاہیے، کیونکہ اس میں OpenClaw خود اور اس کے ڈاؤن لوڈ کردہ پلگ ان رن ٹائمز کے ساتھ آپ کی چیٹس اور اسناد شامل ہیں؛ ڈیفالٹ اسے برقرار رکھتا ہے، اور OpenClaw دوبارہ انسٹال کر کے اسے واپس اٹھا لیتا ہے۔

### مقامی LLMs

Omarchy مقامی LLM ماڈلز چلانے کے دو طریقے تجویز کرتا ہے: LM Studio اور Ollama۔ LM Studio اوپن ویٹ ماڈلز تلاش کرنے، انہیں انسٹال کرنے اور انہیں چلانے کے لیے GUI انٹرفیس فراہم کرتا ہے۔ یہ آسانی سے چلنا شروع کرنے کا ایک بہترین طریقہ ہے۔ Ollama ایسا ہی کرنے کے لیے CLI پیش کرتا ہے۔ لیکن اگر آپ مقامی ماڈلز کے لیے نئے ہیں تو، میں LM Studio سے شروع کروں گا۔ آپ Omarchy Menu میں _انسٹال کریں > AI_ کے تحت دونوں میں سے کوئی انسٹال کر سکتے ہیں۔

### Omarchy Skill

ایجنٹ اسکلز AI کو مخصوص طریقے سے مخصوص ٹولز استعمال کرنے میں مدد کرتی ہیں، اور Omarchy سسٹم کو ترتیب دینے کے لیے ڈیفالٹ اسکل کے ساتھ آتا ہے۔ جیسے اپنی Hyprland کانفیگ میں تبدیلیاں کرنا، بار کو ایڈجسٹ کرنا، یا حتیٰ کہ شروع سے نئی تھیم بنانا۔ یہ Claude Code (`~/.claude/skills`)، Codex (`~/.codex/skills`)، Pi (`~/.pi/agent/skills`)، Antigravity (`~/.gemini/config/skills`)، Hermes (`~/.hermes/skills` اور ہر `~/.hermes/profiles/*/skills`)، اور عمومی `~/.agents/skills` جگہ کے لیے اسکل ڈائریکٹریز میں سم لنک ہے، لہٰذا زیادہ تر ہارنسز اسے خود بخود اٹھا لیتے ہیں۔

لیکن آپ کو اس اسکل کو تجرباتی ماننا چاہیے۔ مختلف ماڈلز اسے مختلف اثر تک استعمال کریں گے۔ بہتر ہے پہلے پلان موڈ میں چلائیں، تاکہ آپ کو اندازہ ہو کہ ایجنٹ کیا تبدیل کرنا چاہے گا۔ اور پھر تبدیلیاں واپس لینے یا یہاں تک کہ `omarchy reinstall configs` طلب کرنے کے لیے تیار رہیں، اگر ایجنٹ ہر چیز کا گند بنا دے۔
