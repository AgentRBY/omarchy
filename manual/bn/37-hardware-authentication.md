# হার্ডওয়্যার প্রমাণীকরণ

### ফিঙ্গারপ্রিন্ট প্রমাণীকরণ

অনেক ল্যাপটপে প্রমাণীকরণের জন্য ফিঙ্গারপ্রিন্ট সেন্সর থাকে। Omarchy মেনুতে (`Super + Space`) _সেটআপ > Security > Fingerprint_ চালিয়ে Omarchy-র সাথে এটি ব্যবহার করতে পারেন।

তা ফিঙ্গারপ্রিন্ট প্যাকেজ ইনস্টল করবে, আপনার ছাপ সংগ্রহ করবে, যাচাই করবে, আর আপনি লক স্ক্রিন থেকে আনলক করতে (যা `Super + Ctrl + L` দিয়ে ট্রিগার করতে পারেন), sudo মোডে ঢুকতে এবং সিস্টেম প্রম্পট অনুমোদন করতে আপনার ফিঙ্গারপ্রিন্ট ব্যবহারের জন্য প্রস্তুত হবেন।

আপনার ল্যাপটপের ঢাকনা বন্ধ থাকলে, ফিঙ্গারপ্রিন্ট প্রম্পট স্বয়ংক্রিয়ভাবে এড়িয়ে যাওয়া হয়, তাই পৌঁছাতে না পারা সেন্সরের জন্য অপেক্ষা করার বদলে সরাসরি পাসওয়ার্ড প্রম্পটে যান। অন্যথায় সেন্সর নেই এমন বাহ্যিক কীবোর্ডে কাজ করতে হলে, `sudo`-র সময় ফিঙ্গারপ্রিন্ট চাওয়া হলে শুধু `CTRL + C` চাপুন।

Omarchy মেনুতে _সরান > Security > Fingerprint_-এর অধীনে ফিঙ্গারপ্রিন্ট প্রমাণীকরণ সরাতে পারেন।

### Fido2 প্রমাণীকরণ

Fido2 ডিভাইস ব্যবহার করলে, Omarchy মেনুতে (`Super + Space`) _সেটআপ > Security > Fido2_ ব্যবহার করে `sudo` প্রমাণীকরণের জন্য তা সেট আপ করতে পারেন। তবে এটি `sudo` ও সিস্টেম অনুমোদন প্রম্পট কভার করে, আপনার কম্পিউটার আনলক করা নয়।

Omarchy মেনুতে _সরান > Security > Fido2_-এর অধীনে fido2 প্রমাণীকরণ সরাতে পারেন।
