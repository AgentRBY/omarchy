# AI

Omarchy מתייחסת לסוכני קידוד AI כאל אזרחים מן השורה הראשונה, אבל היא לא בוחרת מועדף עבורכם. במקום זאת, כל CLI מרכזי של סוכן קידוד מגיע מחווט מראש כמפעיל שנטען בעצלתיים. המפעילים הם בדלים זעירים המנוהלים על ידי [mise](https://mise.jdx.dev/) ב-`~/.local/bin/`, כך ששום דבר לא יורד עד הפעם הראשונה שבאמת מפעילים אחד מהם. Hermes הוא היוצא מן הכלל: שום דבר לא מוגדר כבדל עבורו, ובחירתו מתקינה את Hermes Desktop, כפי שמסביר הסעיף _אפליקציות שולחן עבודה_ להלן. הפעילו כל אחד מאלה והזדהו כאשר תתבקשו:

| פקודה    | סוכן                                                            |
|------------|------------------------------------------------------------------|
| `claude`   | [Claude Code](https://code.claude.com/docs/en/overview)          |
| `codex`    | [OpenAI Codex](https://github.com/openai/codex)                  |
| `opencode` | [OpenCode](https://opencode.ai/)                                 |
| `agy`      | [Google Antigravity CLI](https://github.com/google-antigravity/antigravity-cli) |
| `copilot`  | [GitHub Copilot CLI](https://github.com/github/copilot-cli)      |
| `crush`    | [Crush](https://github.com/charmbracelet/crush)                  |
| `grok`     | [Grok Build](https://x.ai/build) from xAI                        |
| `pi`       | [Mario Zechner's Pi](https://github.com/badlogic/pi-mono)        |
| `omp`      | [Oh My Pi](https://github.com/can1357/oh-my-pi)                  |
| `ori`      | [Ori](https://openrouter.ai/docs/guides/ori/harness), OpenRouter's harness |
| `hermes`   | [Hermes](https://hermes-agent.nousresearch.com/), Nous Research's agent  |
| `muse`     | [Muse Code](https://dev.meta.ai), Meta's coding agent           |
| `cursor-agent` | [Cursor CLI](https://cursor.com/cli)                         |

הפקודה `ori` היא היוצאת דופן: היא מפעילה את המסגרות האחרות מול כל קטלוג המודלים של OpenRouter, כך ש-`ori claude`, `ori codex` או `ori opencode` מפעילים את הסוכנים האלה על איזה מודל שתכוונו אליו, ו-`ori code` הוא הסוכן של Ori עצמו.

כדי לעטוף CLI נוסף באותה דרך, הריצו את `omarchy-mise-install <package> [command-name]`. הבדלים נשמרים מעודכנים יחד עם כל השאר ש-mise מנהל כאשר מריצים את `omarchy update` (או את הכינוי `mup`).

הפקודה `grok` מותקנת דרך חבילת ה-`grok` של mise ממקור ראשון, באותה דרך כמו `claude` ו-`codex`. הריצו את `grok`, או בחרו אותו תחת _הגדרה > ברירות מחדל > סוכן_. דלגו על מתקין ה-`curl | bash` באתר x.ai. הנתיב הזה שם עותק שני ב-`~/.grok/bin`, מוסיף אותו בתחילת `PATH`, ודורס את העטיפה של Omarchy.

### סוכן ברירת המחדל

בחרו את סוכן ברירת המחדל שלכם עם `omarchy default agent <name>` או תחת _הגדרה > ברירות מחדל > סוכן_ בתפריט Omarchy (`Super + Space`). אם הסוכן עדיין לא מותקן, בחירתו מתקינה אותו תחילה. Omarchy טרייה תזמין אתכם לבחור זאת עם התראה חד-פעמית.

בחירת Claude מנסה גם להגדיר את הרחבת הדפדפן שלו עבור Chromium, Chrome, Brave, Brave Origin ו-Edge. הגדרת ההרחבה חלה על כל המשתמשים וייתכן שתבקש את סיסמת המערכת שלכם; ביטול או התקנת הרחבה שנכשלה עדיין בוחרת ומפעילה את Claude. הפעילו מחדש את הדפדפן, אפשרו את ההרחבה אם תתבקשו, והתחברו ל-Claude כדי לסיים לחבר אותה. הריצו את `/chrome` ב-Claude כדי לבדוק את החיבור. Firefox ו-Zen לא תומכים בהרחבה זו. אם Claude כבר היה ברירת המחדל שלכם לפני שההגדרה הזו נוספה, בחרו אותו שוב כדי להתקין את ההרחבה.

הכלי [Muse Code](https://dev.meta.ai) — ה-`muse` של Meta — משתמש בבדל mise מותקן מראש כמו הסוכנים האחרים. בחירתו כסוכן ברירת מחדל מתקינה את המפעיל הרשמי של Meta דרך מנוע ה-HTTP של mise. המפעיל מאמת ומעדכן את הקובץ הבינארי המקורי עבור המכונה שלכם.

ברגע שבחרתם, `Super + Shift + Ctrl + A` מפעיל את סוכן ברירת המחדל בחלון טרמינל ייעודי (או מעלה את הבורר אם עדיין לא בחרתם). אפשר גם להפעיל אותו ישירות לתוך משימה עם `omarchy agent prompt "Review this project"`. סוכנים שמופעלים כך רצים ללא השגחה במצבי אל-תעצור-לשאול שלהם, אז היו מוכנים לכך שהם באמת יעשו דברים! ומאחר שסוכנים מסרבים לזכור אמון עבור ספריית הבית שלכם, הפעלות מ-`$HOME` מתחילות במקום זאת ב-`~/Work`.

יש גם קיצורי דרך בטרמינל: `a` מפעיל את סוכן ברירת המחדל בתוך הטרמינל הנוכחי, בעוד ש-`c`, `cx` ו-`cy` מתחילים את OpenCode, Claude Code ו-Codex ישירות (שוב במצבי האישור האוטומטי שלהם). שינויי ערכת נושא מסונכרנים גם לסוכנים: Claude Code, Pi, OpenCode ו-Hermes (ברגע ש-Omarchy התקינה אותו) עוקבים כולם כאשר מחליפים את ערכת הנושא של Omarchy.

### פנל הסוכנים

בשורת התפריט יש אייקון סוכנים. לפני שהגדרתם סוכן, הפנל שלו מדריך אתכם בהתחברות ל-Claude, ל-Codex או ל-Grok, והראשון הופך לסוכן ברירת המחדל שלכם. לאחר מכן, הפנל שם כל מנוי בדף אחד: כל סוכן וחשבון עם התוכנית שלו, מד לכל אחד ממגבלות המושב של 5 שעות והמגבלות השבועיות שלו עם הזמן עד שהוא יתאפס (עברו עם העכבר לאחוז המדויק), או היתרה שנשארה ששולמה מראש, תחת שורה שמסתובבת דרך מה שהשתמשתם בו בכולם, כמו אסימונים השבוע והמודל המשמש ביותר שלכם. תחת _צור משהו_ הוא מציע הנחיות התחלה לערכת נושא, תוסף או אפליקציה חדשים שמוסרים את המשימה לסוכן ברירת המחדל שלכם. אפליקציות נבנות כפי שנבנו Hype, Monologue ו-Omacut של Omarchy עצמה, ב-C++ וב-Qt Quick, בעקבות מיומנות הסוכן omarchy-app, והמהדר וחלקי Qt שהם צריכים מגיעים מותקנים. Claude Code, Codex, Grok ו-Fireworks מכוסים מהקופסה.

לחצו שמאל על אייקון השורה לפנל, לחצו ימין כדי להפעיל את סוכן ברירת המחדל שלכם. רשומות השימוש שמאחוריה מתחדשות כל 15 דקות על ידי `omarchy agent usage-update`, והפנל אפילו יכול למזג שימוש מהמכונות האחרות שלכם באמצעות תיקייה מסונכרנת. ראו את ה-README תחת `$OMARCHY_PATH/shell/plugins/agents/` להגדרות המלאות.

### כמה מנויים

אם אתם משלמים על יותר מתוכנית אחת של Claude, Codex או Grok — Max אישי ואחד לעבודה, למשל — Omarchy יכולה להשאיר את כולם מחוברים ולעבור ביניהם. הוסיפו מנוי עם ה-+ בפנל הסוכנים, שמדריך אתכם בכך ממש שם, או עם `omarchy agent account add claude Work` (או `codex`, או `grok`). הוא מתקין את ה-CLI אם הוא חסר. החשבון הראשון לספק מתחבר דרך הדפדפן הרגיל שלכם, ממש במקום שה-CLI תמיד מחפש. כל אחד אחריו מתחבר דרך חלון פרטי, כך שהחשבון שהדפדפן שלכם כבר מחובר אליו לא יילקט בטעות; התחברו שם כחשבון שמוסיפים, וסגרו כל חלון פרטי שכבר היה פתוח קודם. לעולם אל תתנתקו מה-CLI כדי לעשות זאת: התנתקות מבטלת את ההתחברות השמורה, והחשבון הזה יצטרך להתווסף שוב.

חשבון אחד לכל ספק פעיל, וכל מושב חדש מתחיל כמותו: `cx`, `cy`, `claude` רגיל, `codex` או `grok`, כל דבר שמופעל דרך `omarchy agent`, וסקריפטים או עורכים שמוצאים את ה-CLI על `PATH`. החליפו עם `omarchy agent account use work` (ובחזרה עם `omarchy agent account use main`), או בפנל על ידי לחיצה על מספר חשבון ואחר כך על `Enter` (או על ידי לחיצה על כפתור השימוש שלו). מושבים שכבר רצים נשארים על החשבון שבו התחילו. היסטוריית שיחות, הגדרות, מיומנויות ותוספים משותפים בין חשבונות, כך ש-`claude --continue` באותה תיקייה ממשיך מהנקודה שבה הפסקתם בחשבון החדש.

עם יותר מחשבון אחד, הפנל מציג את מגבלות כל חשבון זו לצד זו, כשהפעיל מסומן. כברירת מחדל Omarchy מודיעה לכם כאשר החשבון הפעיל עובר 95% ממגבלה, ולחיצה על ההתראה מחליפה לחשבון עם הכי הרבה מרווח. עברו עם העכבר על שורת חשבון בפנל ולחצו על ההחלפה האוטומטית שמופיעה ליד שימוש (או לחצו על `m`), או הריצו את `omarchy agent account mode auto`, כדי שהוא יחליף בעצמו במקום זאת; בזמן שהוא דלוק, החלפה אוטומטית תופסת את מקומו של שימוש, ולחיצה נוספת מחזירה להתראה. הוסיפו מספר כדי לשנות את הסף, כגון `omarchy agent account mode auto 90`. אם כל חשבון מעל הסף, תשמעו על כך פעם אחת, יחד עם איזה חשבון מתפנה ראשון. בזמן שחשבון פעיל נמצא בטווח של 15 נקודות מהסף שלו (80% בברירת המחדל), מגבלותיו נבדקות כל שלוש דקות ולא כל 15.

הפקודה `omarchy agent account list` מציגה כל חשבון ואת מגבלותיו העדכניות, `omarchy agent account remove work` שוכחת אחד, ו-`omarchy agent account rename primary Hey` משנה שם של אחד (או לחצו על שם חשבון בפנל). פקודות אלה עובדות על חשבונות סוכן ברירת המחדל שלכם; כדי להגיע לספק האחר, ציינו אותו קודם, כגון `omarchy agent account use codex side`. ההתחברות שכבר הייתה לכם ב-`~/.claude` או ב-`~/.codex` היא החשבון _הראשי_ ונשארת היכן שהיא. חשבון שנשאר ללא שימוש יותר מכשמונה שעות יכול להציג _נדרשת התחברות_; לחצו עליו כדי לחבר את החשבון הזה שוב ממש בפנל, או התחילו מושב בו, שמרענן את ההתחברות בעצמו. שרתי MCP שהיו לכם כאשר חשבון נוסף באים איתו אליו, אבל אלה שמוסיפים מאוחר יותר עם `claude mcp add` מגיעים רק לחשבון שבו הוספתם אותם. Claude Desktop וכלים שהוגדרו עם נתיב מוחלט לקובץ בינארי של CLI לא עוקבים אחר ההחלפה. הגדרה מפורשת של `CLAUDE_CONFIG_DIR`, `CODEX_HOME` או `GROK_HOME` מקבלת עדיפות על החשבון שנבחר.

### אבחון קריסות

Omarchy צופה ב-systemd-coredump לקריסות תהליכים. כאשר משהו חווה שגיאת פילוח, תקבלו התראת "Process crashed" — לחצו עליה, והקריסה נמסרת לסוכן ברירת המחדל שלכם יחד עם מיומנות אבחון-קריסה של Omarchy, המדריכה את הסוכן בקביעת העובדות מהשלכת הליבה ובהחלטה האם הקריסה שווה דיווח במעלה הזרם. אפשר גם להריץ אותה ידנית מול כל PID מ-`coredumpctl list` עם `omarchy agent crash <pid>`.

הצפייה דלוקה כברירת מחדל. כבו אותה תחת _הפעלה > החלפה > לכידת קריסות_ (או עם `omarchy toggle crash-capture`) וההתראות ייפסקו; `omarchy agent crash <pid>` עדיין עובד ידנית.

אפשר גם להשתיק קריסות תוכנית אחר תוכנית, וזה מה שהאבחון מציע לכם בסוף. `omarchy crash mute hyprland` עוצר את ההתראות לתוכנית זו בלבד, `omarchy crash mute hyprland off` מחזיר אותן, ו-`omarchy crash mute` לבדו מפרט מה השתקתם. הוא מקבל את נתיב הקובץ הבינארי באותה שמחה כמו את שמו, כך ש-`omarchy crash mute /usr/bin/hyprland` עושה את אותו דבר. צטטו שם עם רווח בתוכו, כגון `omarchy crash mute 'Some App'`. כל השאר עדיין מודיע, והתוכנית המושתקת עדיין קורסת — זה מסתיר את התזכורת, זה לא מתקן שום דבר.

### אפליקציות שולחן עבודה

תפריט _התקנה > AI_ נושא גם כמה אפליקציות AI גרפיות: אפליקציית שולחן העבודה של ChatGPT, אפליקציית שולחן העבודה של Claude (בטא Linux של Anthropic, עם לשוניות Chat, Cowork ו-Claude Code), Grok Bot לשיחה עם המודלים של xAI, Hermes Desktop, OpenClaw ואפליקציית שולחן העבודה של Perplexity. Grok Bot היא אפליקציית הצ'אט לשולחן עבודה. סוכן הקידוד הוא פקודת `grok`.

Hermes Desktop היא זו שכדאי להכיר, כי למכונה יש Hermes אחד, והוא של האפליקציה: Hermes מותקן אך ורק דרך האפליקציה, ופקודת `hermes` שסוכן ברירת המחדל מפעיל היא של האפליקציה. בחירת Hermes כסוכן ברירת מחדל מתקינה את אותו דבר שערך _התקנה > AI_ מתקין: את החבילה, וסביבת ריצה של Hermes תחת `~/.hermes` שהוגדרה על ידי המתקין של Hermes עצמו, שלוקח כמה דקות בפעם הראשונה. סביבת הריצה הזו היא ה-Hermes האחד שפקודת הטרמינל `hermes`, סוכן ברירת המחדל והאפליקציה כולם משתמשים בו, והיא מעדכנת את עצמה עם `hermes update` ולא מחכה לגרסת Omarchy. התקנתה גם מעניקה ל-Hermes את ערכת הנושא של Omarchy כמעטפת בשם `omarchy`, שכל משטח Hermes עוקב אחריה כאשר מחליפים ערכות נושא; בחרו אחרת תחת הגדרות המראה של Hermes או עם `/skin` אם תעדיפו שלא, ו-Omarchy תשאיר את הבחירה הזו בשקט. הסרת האפליקציה תחת _הסרה > AI_ סוגרת קודם את Hermes, כולל השער, לוקחת את סביבת הריצה הזו איתה, ושומרת את הצ'אטים, הזיכרונות והמיומנויות ש-Hermes כתב לעצמו אלא אם תאמרו אחרת: היא שואלת, כברירת מחדל לא, האם גם הנתונים האלה והגדרות החיבור שלכם צריכים ללכת.

חוויית שולחן העבודה של OpenClaw היא ממשק הבקרה שלו, שנפתח כאפליקציית רשת המגובה בשער מקומי משלו. OpenClaw חי ב-`~/.openclaw` ומעדכן את עצמו: השתמשו בכפתור "Update Gateway" של ממשק הבקרה או הריצו את `openclaw update`, והשער מופעל מחדש על הגרסה החדשה. Omarchy רק בוחרת את הגרסה שממנה מתחילה התקנה חדשה. הסרת OpenClaw תחת _הסרה > AI_ לוקחת איתה את שירות השער ואת האפליקציה ואחר כך שואלת האם גם `~/.openclaw` צריך ללכת, מאחר שהוא מחזיק את הצ'אטים והאישורים שלכם לצד OpenClaw עצמו וזמני הריצה של התוספים שהוא מוריד; ברירת המחדל שומרת אותו, והתקנת OpenClaw שוב קולטת אותו בחזרה.

### מודלי שפה מקומיים

Omarchy ממליצה על שתי דרכים להרצת מודלי LLM מקומיים: LM Studio ו-Ollama. LM Studio מספק ממשק GUI למציאת מודלים פתוחי משקל, להתקנתם ולהרצתם. זו דרך נהדרת להתחיל בקלות. Ollama מציע CLI לעשות זאת באופן דומה. אבל אם אתם חדשים במודלים מקומיים, הייתי מתחיל עם LM Studio. אפשר להתקין כל אחד תחת _התקנה > AI_ בתפריט Omarchy.

### מיומנות Omarchy

מיומנויות סוכן עוזרות לבינה מלאכותית להשתמש בכלים ספציפיים בדרך ספציפית, ו-Omarchy מגיעה עם מיומנות ברירת מחדל להתאמת המערכת. כמו שינוי הגדרת Hyprland שלכם, כוונון השורה, או אפילו יצירת ערכת נושא חדשה מאפס. היא מקושרת סמלית לספריות המיומנויות של Claude Code (`~/.claude/skills`), של Codex (`~/.codex/skills`), של Pi (`~/.pi/agent/skills`), של Antigravity (`~/.gemini/config/skills`), של Hermes (`~/.hermes/skills` וכל `~/.hermes/profiles/*/skills`), ושל המיקום הגנרי `~/.agents/skills`, כך שרוב המסגרות קולטות אותה אוטומטית.

אבל כדאי להתייחס למיומנות זו כניסיונית. מודלים שונים ישתמשו בה להשפעה שונה. כדאי לרוץ קודם במצב תכנון, כך שיהיה לכם מושג מה הסוכן היה רוצה לשנות. ואחר כך להיות מוכנים לשחזר שינויים או אפילו להפעיל את `omarchy reinstall configs`, אם הסוכן יעשה בלאגן מהכול.
