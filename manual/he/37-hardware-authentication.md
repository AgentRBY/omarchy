# אימות חומרה

### אימות טביעת אצבע

מחשבים ניידים רבים מגיעים עם חיישן טביעת אצבע לאימות. תוכלו להשתמש בזה עם Omarchy על ידי הרצת _הגדרה > Security > Fingerprint_ בתפריט Omarchy (`Super + Space`).

זה יתקין את חבילת טביעת האצבע, יאסוף את הטביעה שלכם, יאמת אותה, ותהיו מוכנים להשתמש בטביעת האצבע שלכם כדי לבטל נעילה ממסך הנעילה (שאותו תוכלו להפעיל עם `Super + Ctrl + L`), להיכנס למצב sudo ולאשר הנחיות מערכת.

כאשר מכסה המחשב הנייד סגור, הנחיית טביעת האצבע מדולגת אוטומטית, כך שאתם עוברים ישירות להנחיית הסיסמה במקום לחכות לחיישן שאינכם יכולים להגיע אליו. אם אחרת אתם צריכים לעבוד על מקלדת חיצונית שאין לה חיישן, פשוט לחצו `CTRL + C`, כאשר תתבקשו לטביעת האצבע שלכם במהלך `sudo`.

תוכלו להסיר את אימות טביעת האצבע תחת _הסרה > Security > Fingerprint_ בתפריט Omarchy.

### אימות Fido2

אם אתם משתמשים בהתקן Fido2, תוכלו להגדיר אותו לאימות `sudo` באמצעות _הגדרה > Security > Fido2_ בתפריט Omarchy (`Super + Space`). זה מכסה הנחיות `sudo` והרשאות מערכת, עם זאת, לא ביטול נעילת המחשב שלכם.

תוכלו להסיר את אימות ה-fido2 תחת _הסרה > Security > Fido2_ בתפריט Omarchy.
